First call: GO. The shift from desktop to web, combined with satellite imagery and routing, addresses a clear user desire for accessible, visual navigation despite the stated risks.

Steelman: A free, browser-based map with satellite views and routing will become the default global reference tool because accessibility and superior data outweigh browser performance limits and licensing costs.

Alternatives:
1. Do nothing: Retain desktop-only; cede the web to incumbents as browsers improve.
2. License only: Pay for data but keep the desktop model; limits growth and viral adoption.
3. Free Web (Proposed): High upfront cost and technical debt, but captures the market shift early.

Fit: Aligns with the acquirer's mission to organize information and make it universally accessible. The "free" model trades direct revenue for massive scale and data accumulation.

Pre-mortem: Failure occurs if browser performance remains too poor for a smooth experience, or if licensing costs bankrupt the project before ad revenue or strategic value materializes. This is a one-way door regarding resource allocation; delaying allows competitors to lock in users. Cost of delay is high: the first mover in web-based satellite imagery captures the cultural zeitgeist.

Evidence: The proposal relies on the assumption that browser graphics can improve fast enough (plausible given trajectory) and that the parent company can absorb licensing costs. The lack of a direct revenue model is mitigated by the strategic value of indexing the world's geography and driving search engagement.

Blockers: NONE. The risks (cost, competition, tech limits) are significant but not fatal facts; they are execution hurdles. The "no revenue model" is a strategic choice, not a blocker, given the acquirer's position.

Risks: High burn rate; browser lag frustrating users; incumbents reacting aggressively.

Kill Criteria: If browser frame rates cannot sustain interactive panning within 12 months despite optimization, or if licensing costs exceed 40% of the division's budget without a path to indirect monetization, pivot to a hybrid or data-licensing model.

Leading Metric: Daily Active Users (DAU) and queries per session. Review date: 6 months post-launch.

DECISION: GO
