First call: GO. The shift from desktop to web, combined with satellite imagery and routing, creates a step-change in accessibility and utility that dwarfs current limitations.

**Steelman:** Delivering free, browser-based maps with satellite views and routing removes friction for mass adoption, creating a data moat that justifies licensing costs through indirect value.

**Options:**
1.  **Do nothing:** Retain desktop niche; cede web future to incumbents. High risk of irrelevance.
2.  **Paid Web App:** Reduces user growth; fails to leverage network effects.
3.  **Proposal (Free Web + Satellite):** High upfront cost, but captures maximum market share. Beats "do nothing" on strategic reach.

**Fit:** Aligns with organizing the world's information (assumed north star). Desktop limits scale; web enables it.

**Pre-mortem:** Failure occurs if browser performance cannot handle interactive graphics or if licensing costs bankrupt the project before monetization emerges. However, browser tech evolves rapidly (two-way door on tech stack); licensing is a fixed cost barrier that deters competitors (moat). Cost of delay is losing the definition of the web map standard.

**Evidence:** The acquisition provides the base asset. Browser slowness is a transient technical hurdle, not a fundamental blocker. Competitors exist but lack the specific combination of free access, satellite imagery, and routing at this scale.

**Blockers:** NONE. The cited risks (cost, competition, tech limits) are execution challenges, not factual contradictions.
*   *Licensing cost:* A barrier to entry, not a failure condition if the strategic value is high.
*   *No revenue model:* Indirect monetization (ads, data, ecosystem drive) is a valid strategy for platform plays.
*   *Browser speed:* Solvable via engineering; waiting for perfection guarantees losing the market.

**Risks:** High burn rate before monetization; technical lag in rendering. These become kill criteria: if browser performance does not improve within 12 months or user growth stalls below 1M MAU in year one, pivot or shut down.

**Kill Criteria:** Stop if monthly licensing costs exceed $X without corresponding user growth of Y% quarter-over-quarter after launch. Leading metric: Daily Active Users utilizing route planning.

The proposal survives the attack. The risks are manageable compared to the opportunity cost of inaction.

DECISION: GO
