First call: GO. The shift from desktop to web, combined with satellite imagery and routing, creates a step-change in accessibility and utility that dwarfs the stated risks.

Steelman: By eliminating the download barrier and integrating high-value data layers (satellite, routes) into a free browser experience, the product captures mass-market demand that desktop incumbents cannot serve, monetizing indirectly through search dominance rather than direct licensing fees.

Alternatives:
1. Do nothing: Retain niche desktop share; eventual irrelevance as web standards improve.
2. License to existing players: Cedes strategic control and data advantage; low upside.
3. Paid web service: Friction kills adoption; fails to leverage the acquirer's core search distribution.

Fit: Aligns with a search giant's north star of organizing the world's information and driving query volume. Maps become a primary interface for local search, not a standalone profit center.

Pre-mortem: Failure occurs if browser performance remains too sluggish for panning/zooming or if licensing costs bankrupt the project before ad integration scales. However, browser speed is a transient technical constraint likely to resolve, whereas being absent from the web is permanent. This is a two-way door; features can be scaled back if costs spike, but market presence must be seized now.

Evidence: The acquirer possesses the traffic to amortize data costs via advertising, a model established competitors lack. The "no revenue model" objection ignores that maps drive high-intent search queries, the company's core revenue engine.

Blockers: NONE. The risks (cost, competition, browser speed) are execution challenges, not factual contradictions. Browser slowness is a temporary hurdle; licensing costs are manageable given the strategic value of user data and ad inventory; incumbents are vulnerable to a free, integrated alternative.

Risks: High initial cash burn; potential latency in older browsers. These become kill criteria: if user session time does not exceed desktop benchmarks within 12 months, or if licensing costs exceed 15% of projected ad lift, pivot to a limited API model.

The proposal correctly identifies a paradigm shift. Hesitation based on current browser limits or lack of direct fees misunderstands the platform strategy.

DECISION: GO
