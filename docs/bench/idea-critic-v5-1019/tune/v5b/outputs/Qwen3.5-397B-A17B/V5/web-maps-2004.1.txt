First call: GO. The shift from desktop to browser, combined with satellite imagery and routing, creates a step-change in accessibility and utility that dominates the existing desktop-only status quo, despite known risks.

**Steelman:** A free, browser-based map with satellite views and routing will become the default global reference tool because zero-friction access outweighs technical limitations and licensing costs, enabling scale that justifies future monetization.

**Options:**
1.  **Do nothing:** Retain desktop niche; cede web future to competitors.
2.  **License only:** Add data to desktop; misses the distribution leap of the web.
3.  **Proposed plan:** High upfront cost and technical debt, but captures the entire internet user base.
The proposal beats "do nothing" by unlocking network effects impossible in a downloadable model.

**Fit:** Aligns with the acquirer's core mission to organize information and make it universally accessible. Browser slowness is a transient technical constraint, not a strategic barrier.

**Pre-mortem:** Failure occurs if licensing costs bankrupt the project before ad-revenue scales, or if browser performance remains unusable for panning/zooming. However, these are execution hurdles, not fundamental flaws. The "one-way door" is low; if browser tech fails, we revert to desktop plugins. The cost of delay is catastrophic: a competitor launches first and owns the "map" verb.

**Evidence & Blockers:**
*   *Blockers:* NONE. The risks cited (cost, competition, speed) are industry-standard hurdles for platform shifts, not disqualifiers.
*   *Risks:* High burn rate; unproven ad model for maps; browser rendering limits.
*   *Kill Criteria:* If browser frame rates drop below 10fps after optimization, or if licensing costs exceed 2x projected year-one ad revenue, pivot to a hybrid plugin model.

**Strongest Attack Survived:** The claim that "browsers are too slow" was tested against the trajectory of JavaScript engines and AJAX (emerging now). While currently slow, the architecture allows for incremental optimization, whereas the desktop model cannot optimize for distribution. The speed objection fails to block the strategic necessity of web presence.

**Dissent Ledger:** Licensing costs may delay profitability by 12–18 months.
**Remaining Risk:** Monetization lagging behind infrastructure spend.

DECISION: GO
