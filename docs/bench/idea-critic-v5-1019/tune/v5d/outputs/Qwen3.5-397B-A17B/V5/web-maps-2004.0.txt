First call: NO-GO. The proposal identifies a real need but fails to state an edge; "free" and "browser-based" are distribution choices, not competitive advantages against incumbents with users and capital.

Steelman: A free, browser-native map with satellite imagery and routing could democratize access and leverage the acquirer's search dominance to bypass download friction.

However, the stated facts reveal immediate blockers. First, the economics are inverted: licensing map data and satellite imagery is explicitly "costly," yet there is "no direct revenue model." In 2004, web advertising CPMs were insufficient to cover high-bandwidth satellite imagery costs without a massive, proven scale that the proposal does not demonstrate. Second, the technical premise is flawed; browsers of this era are "slow at interactive graphics," making the core value proposition (smooth map interaction) technically unviable compared to the acquired desktop program. Third, the competitive landscape is hostile; established sites already possess the user base and data relationships this project lacks.

The "better way" is to maintain the desktop application for power users while licensing the search company's existing web traffic to partners, rather than building a costly, slow, free competitor from scratch. The pre-mortem is clear: the project burns cash on licenses, performs poorly in browsers, fails to monetize, and is shut down within 18 months.

While the strategic fit of moving to the web is sound long-term, the specific plan as proposed—free access, expensive data, slow tech, no revenue—is a financial loss generator. The absence of a pilot, cap, or metric is secondary to the fundamental contradiction between high fixed costs and zero revenue. This is not a risk to be managed; it is a broken business model as stated.

Blockers: High licensing costs with no revenue model; browser technology incapable of required performance; no competitive edge over incumbents.
Risks: Execution difficulty, user migration friction.

DECISION: NO-GO
