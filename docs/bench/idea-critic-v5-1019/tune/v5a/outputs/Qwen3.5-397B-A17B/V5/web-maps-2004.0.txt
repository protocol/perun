First call: GO. The shift from desktop to web aligns with the inevitable trajectory of software delivery, and satellite imagery represents a unique data moat that desktop competitors cannot easily replicate.

**Steelman:** Transforming a niche desktop map viewer into a free, browser-based platform with satellite imagery and routing will capture mass market adoption by removing installation friction and offering unprecedented visual context, creating a defensible data asset despite high licensing costs and browser limitations.

**Attack & Options:**
*   **Do Nothing:** Retain desktop-only status. Risk: Obsolescence as users migrate to web apps. Upside: Zero new cost.
*   **Paid Web App:** Charge for access. Risk: High friction prevents critical mass; fails to leverage "free" as a distribution weapon against incumbents.
*   **The Proposal:** Free access monetized later via local search ads or enterprise licensing.
    *   *Cost/Risk:* High upfront licensing; browser performance in 2004 is a genuine technical hurdle (Ajax/Canvas are immature).
    *   *Reversibility:* High. If user growth stalls, the service can be shuttered or pivoted to B2B without physical inventory loss.

**Fit:** Moves the north star from "selling units" to "organizing the world's information" (assumed). A free web tool indexes user intent geographically.

**Pre-mortem:** The project fails if browser latency makes panning/zooming unusable, or if licensing costs bankrupt the unit before ad revenue scales. However, browser speeds are improving exponentially; waiting for "perfect" browsers cedes the market.

**Evidence & Math:** No internal files exist to verify current traffic, but the strategic logic holds: distribution friction (downloads) is the primary killer of desktop utilities. Removing it creates a step-function growth opportunity. Licensing costs are fixed; marginal cost per user is near zero.

**Blockers:** NONE. The technical limitations of 2004 browsers are challenges to be engineered around (e.g., tile pre-fetching), not factual impossibilities. The lack of a *current* revenue model is not a blocker for a platform play aiming for scale first.

**Risks:** High burn rate on imagery licenses; competitor retaliation; browser incompatibility.
**Kill Criterion:** If active daily users do not reach 100,000 within 12 months of launch, or if licensing costs exceed 150% of the allocated budget by Q3, pivot to enterprise-only or terminate.

**Decision:** The strategic advantage of owning the satellite layer and the web interface outweighs the execution risks.

DECISION: GO
