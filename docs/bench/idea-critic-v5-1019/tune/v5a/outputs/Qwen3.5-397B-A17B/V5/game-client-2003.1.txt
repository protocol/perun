First call: GO. The core problems (update delivery, cheating) are unsolvable at scale via physical media; a mandatory client is the only viable technical path.

**Steelman:** A proprietary client is the minimum infrastructure required to maintain game integrity and deliver patches, creating a defensible moat that physical distribution cannot provide.

**Options:**
1.  **Do nothing:** Cheating escalates, support costs for patching via mail/retail explode, franchise value decays.
2.  **Third-party tools:** Cedes control of the user relationship and revenue to competitors.
3.  **Proposed Client:** High initial friction but secures long-term platform control and recurring revenue.
The proposal beats "do nothing" because the status quo guarantees failure against cheaters.

**Fit:** Aligns with the north star of preserving game integrity and maximizing lifetime value per user.

**Pre-mortem:** Failure occurs if the client launches with game-breaking bugs during peak hours, causing a retail exodus before broadband adoption cushions the blow. This is a two-way door; software can be patched or rolled back, though reputation damage is sticky. Cost of delay is high: every month without anti-cheat accelerates player churn.

**Evidence:** The premise that "retail partners may drop games" is a risk, not a blocker, because the developer's "very popular" titles give them leverage; retailers need the hits more than the hits need specific shelf space. Broadband adoption in 2003 is rising; early adopters (the core gaming demographic) are already connected.

**Blockers:** NONE. The risks cited (dislike of accounts, broadband gaps) are adoption headwinds, not functional blockers. The proposal addresses the existential threat (cheating/updates) which outweighs distribution friction.

**Risks:** Retail channel contraction, initial user backlash, competitor cloning. These are managed by making the client indispensable through exclusive features and rapid iteration.

**Kill Criterion:** If active unique users drop >20% within 90 days of launch attributable solely to the client requirement (verified by exit surveys), pause mandatory enforcement and revert to optional for legacy titles. Leading metric: Client install success rate. Review date: 30 days post-launch.

DECISION: GO
