The claim is that installing copy-protection software without clear consent will effectively reduce piracy while maintaining customer trust. The steelman: this is a necessary, immediate defense to stop revenue bleeding from mass copying, assuming customers prioritize access over control of their machines.

However, the proposal fails the "better-way" and "skeptic" tests catastrophically. The mechanism relies on covert installation ("installs itself"), which directly triggers the raised risk of being seen as intrusive and treating customers as thieves. In the software security domain, hiding installation is functionally identical to malware behavior. This guarantees a backlash from security researchers and tech-savvy users, who will publicly expose the hidden components, label the discs as viruses, and likely release cracks that make the protection useless while damaging the brand's reputation permanently.

The "do nothing" alternative or a clear-consent model (where the user explicitly agrees to install limits) is superior. While "do nothing" accepts some copying, the proposed active deception invites a total loss of trust and potential legal liability for installing unauthorized software. The cost of delay (waiting to design a transparent system) is lower than the cost of a public relations disaster and class-action lawsuits.

The pre-mortem is clear: within months, major antivirus vendors will flag these discs as trojans. News outlets will run stories on "record labels spying on fans." The "one-way door" here is the installation of unremovable or hard-to-remove code on millions of private devices; once that trust is broken, it cannot be restored. The proposal assumes customers will tolerate covert system modifications, a premise contradicted by basic user psychology regarding computer security.

There is no kill criterion that saves this; the fundamental approach of covert installation is the failure point. The strongest attack survived is nonexistent because the core mechanism (silent install) is fatal. The only viable path is a transparent, consensual approach or accepting the current loss rate while exploring legal/streaming alternatives.

DECISION: NO-GO
