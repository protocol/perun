**First call: NO-GO.** Forcing a touch-first interface onto hundreds of millions of keyboard-and-mouse PCs, with no rollback path, bets the entire install base on unproven tablet convergence.

**Steelman:** The dominant OS maker must unify desktop and tablet before competitors own touch computing; a single touch-first shell plus an app store is the boldest way to do that.

**Better way:** Ship the new start screen as a **default-on option** alongside the classic desktop, or pilot it on touch hardware first. This reaches the same convergence upside at a fraction of the risk.

**Skeptic:**

- The proposal's own stated risk — users will not want touch on non-touch PCs — is the **core claim inverted**. It is not a risk to mitigate; it is a reason the plan fails as proposed.
- The install base is overwhelmingly non-touch. The interface is designed for a hardware modality most users lack.
- No rollback path means a one-way door on the largest desktop install base in the world.

**Kill criteria:**

- **Corporate adoption:** If enterprise pilot retention drops below 70% in the first quarter, restore the classic start menu as default.
- **App store traction:** Fewer than 5,000 quality tablet apps within 12 months means the ecosystem bet has failed.

**Blockers:**

1. The proposal **concedes its own failure mode** (users won't want touch on non-touch PCs) and answers it with nothing — no pilot, no option, no fallback. A plan whose stated risks include the negation of its core claim, with no mitigation, is a blocker.
2. **No reversibility on a one-way door.** Removing the start menu from all PCs with no rollback path is irreversible at the install-base scale. A cheaper, staged alternative (pilot on touch hardware, ship as opt-in) reaches the same convergence upside without the one-way door.

**Decision: no-go.** The convergence thesis may be sound, but forcing an unproven touch shell onto the entire non-touch install base — with no rollback, no pilot, and no opt-in — is a one-way door bet that does not survive its own stated risks.

DECISION: NO-GO
