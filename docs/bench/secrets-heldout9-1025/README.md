Ninth blind held-out secrets corpus (60 leaks, 60 hard decoys), authored 2026-10-25 without reading any scanner, gate, test, or rival port. Leak values come from a random source (python3 `secrets`), are fictional, and are not valid credentials. Shapes cover many providers (source-control, package registries, AI APIs, cloud, SaaS, databases, message queues) and contexts (.env, CI YAML, shell, Kubernetes and Helm, Terraform, Ansible, XML, logs, URLs, and Java, PHP, Rust, Python and JS source). Decoys are hard look-alikes: hashes, UUIDs, trace ids, documented example keys and test vectors, env-var names without values, secret-manager references, placeholders, public-by-design ids, and certificates.

Format: `secret-leaks.txt` (ids `L001`-`L060`) and `secret-decoys.txt` (ids `D001`-`D060`), each row `id<TAB>text`; a literal backslash-n inside a row means a newline. Every leak value contains `@@` within its first 8 characters (push-protection safe). Rows are data and must never be executed.
