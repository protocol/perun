The risks cited are real but largely transitional or misframed:

- **Browser performance (2004):** Interactive graphics were indeed slow. But the proposal targets a web application, and the underlying technologies were improving rapidly. A lightweight, tiling-based approach to rendering maps can work within browser constraints of the era. This is an engineering challenge, not a fundamental blocker.

- **Established competitors:** Incumbents exist, but "already having users" is not the same as having an unassailable position. A free, no-download product with superior imagery and route planning can differentiate quickly. First-mover disadvantage in maps is overstated; what matters is product quality and accessibility.

- **No direct revenue model:** This is the weakest objection. A free mapping application with broad consumer reach has multiple indirect monetization paths—local advertising, sponsored listings, search integration. The strategic value of owning a maps layer in a search company's ecosystem is substantial even without line-item revenue.

- **Licensing costs:** Legitimate concern. However, the acquired firm presumably already has some data relationships, and a web product dramatically expands distribution, which can improve licensing economics through scale. Satellite imagery licensing is a cost, but also a competitive moat if secured exclusively or early.

The core strategic logic is sound: a search company acquiring a mapping desktop product should move it to the web, make it free, and add high-value features like satellite imagery and route planning. The combination of no-download accessibility, rich imagery, and integration with an existing search platform creates a defensible, high-utility product. The risks are manageable and the opportunity is significant.

DECISION: GO
