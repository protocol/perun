The readout explicitly identifies a denominator error: users were randomized, but the primary metric (conversion) was computed per page view. This violates the principle that the metric's denominator must match the unit of randomization. If a single user generates multiple page views, treating each view as an independent observation inflates the sample size and artificially narrows confidence intervals, leading to false positives.

While the readout confirms adequate power (25,000 users per arm), no peeking occurred, split ratios are balanced (ruling out SRM), and results are consistent across segments (ruling out Simpson's paradox) and time (ruling out novelty effects), the fundamental flaw in how the metric was calculated invalidates the statistical significance of the 7.4% lift. The reported win may be an artifact of counting repeated views rather than a true treatment effect.

Before rolling out, the analysis must be recomputed with the user as the unit of analysis (e.g., did the user convert yes/no?) to ensure the denominator matches the randomized unit.
