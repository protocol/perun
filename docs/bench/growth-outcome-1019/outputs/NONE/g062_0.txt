When an aggregate result contradicts the trends found in every specific subgroup, the overall finding is misleading and likely driven by an imbalance in segment sizes or traffic composition rather than a true causal effect of the change.

The denominator matches the randomized unit (users), so there is no Denominator (DENOM) error. Finally, the lift remained stable over 28 days, suggesting the result is not a transient Novelty (NOVELTY) effect.

Because the aggregate "win" is entirely reversed within every segment, the current conclusion is invalid. The team must investigate the segment-level data before making any rollout decision.
