The readout explicitly identifies three critical methodological errors. First, the team stopped the test the moment the p-value dropped below 0.05 after checking daily, which constitutes **PEEK** (peeking) and invalidates the statistical significance by inflating false positives. Second, although a power calculation was performed, the final sample size (~50k per arm) is double the requirement (25k), so **POWER** is not an issue here; however, the metric definition is flawed. Conversion is computed per page view while users were the randomized unit, violating the denominator requirement (**DENOM**). This mismatch can bias results if users generate unequal page views across arms. Finally, the readout states the lift held steady for 28 days, suggesting the team has already considered and ruled out a short-lived **NOVELTY** effect, so that category is not flagged. There is no evidence of **SRM** as the split is nearly even, and **SIMPSON**'s paradox is explicitly ruled out as trends match across segments. Because PEEK and DENOM errors fundamentally compromise the validity of the reported lift, the results cannot be trusted for a rollout decision.

ERRORS: PEEK, DENOM
DECISION: HOLD
