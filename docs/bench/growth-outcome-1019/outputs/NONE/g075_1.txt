First, the team stopped the test the first day the p-value fell below 0.05 after checking daily; this is **PEEK**ing, which inflates the false positive rate. Second, while the user split is valid, the primary metric divides conversions by sessions while randomization occurred at the user level. Since heavy users generate multiple sessions, this violates the unit of analysis, constituting a **DENOM**inator error. Finally, although the lift persisted for 28 days, the recommendation projects this as a lasting change without addressing whether the initial spike or sustained lift might be a **NOVELTY** effect that could decay over a longer horizon or upon full rollout; however, the text explicitly states the lift held steady, so NOVELTY is not clearly described as an existing error in the data itself, but rather a risk in projection. The most definitive errors present in the description are the early stopping and the metric definition mismatch.

Because the test was stopped early based on interim looks (PEEK) and the metric denominator does not match the randomization unit (DENOM), the reported significance and effect size are unreliable. These issues must be resolved before making a rollout decision.
