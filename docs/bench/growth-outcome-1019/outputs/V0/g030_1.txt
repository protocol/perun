The readout contains a critical denominator error. Users were the unit of randomization, yet the primary metric (conversion) was computed per page view. This violates the principle that the analysis unit must match the randomization unit (DENOM). If a single user generates multiple page views, treating each view as an independent observation inflates the sample size and artificially reduces variance, leading to false positives.

Additionally, while the text states "each arm got 25,000 users," the visitor counts are 50,200 and 50,100. If "visitors" equals "users," there is a slight imbalance, but if "visitors" implies total page views while only 25k unique users were assigned, this reinforces the denominator mismatch. The claim that the result wins in segments does not cure the fundamental flaw in how the primary metric was calculated against the randomized population.

Because the statistical validity of the 7.4% lift is compromised by the mismatched denominator, the result cannot be trusted for a rollout decision without re-analysis using the user as the denominator.

ERRORS: DENOM
DECISION: HOLD
