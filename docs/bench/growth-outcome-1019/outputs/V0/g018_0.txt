The readout describes a critical denominator error. Users were the unit of randomization, yet the primary metric (booking conversion) is computed per page view. If the variant changes the number of page views per user (e.g., by removing a step, users might generate fewer views before booking), the ratio metric becomes biased even if the total bookings per user remain unchanged. This violates the requirement that the metric's denominator must align with the randomized unit to ensure a valid causal claim.

While the sample ratio mismatch is negligible (50,080 vs 49,920 is within chance), stopping rules were pre-committed, power was achieved, and Simpson's paradox is explicitly ruled out by consistent segment results, the denominator mismatch invalidates the statistical significance of the +3.1% lift. The stability over 28 days suggests the effect is real, but the measurement method is flawed. You cannot ship based on a metric that mathematically conflates behavioral changes with conversion changes without recomputing the result using users as the denominator (e.g., % of users who booked).
