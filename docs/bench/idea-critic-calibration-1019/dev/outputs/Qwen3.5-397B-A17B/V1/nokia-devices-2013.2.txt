Steelman: Acquiring the struggling handset manufacturer secures the only dedicated hardware partner for the minority OS, preventing its defection to the dominant rival and enabling tight integration to improve user experience.

However, the claim that ownership fixes the core ecosystem deficit fails scrutiny. The primary failure mode is not hardware switching, but developer abandonment due to low market share. Buying a declining hardware unit with falling sales does not organically generate the app volume needed to compete; it merely converts a variable partnership risk into a fixed operational burden. The "app-ecosystem problem" is a network effect issue, not a supply chain one. Controlling the device does not force developers to write code if the user base remains small.

Alternatives:
1. **Do Nothing/Partner:** Maintain the current relationship. Risk: Manufacturer defects. Cost: Zero integration overhead.
2. **Subsidize Developers:** Directly fund app creation. Cost: Likely lower than €5.4B + integration. Risk: Still requires user base.
3. **Acquisition (Proposed):** Cost: €5.4B + massive integration drag. Risk: Distracts software team with hardware logistics while sales continue to fall.

Pre-mortem: Two years post-acquisition, the combined entity reports larger losses. The software team is bogged down managing factory workflows and union negotiations. Competitors release superior devices on the rival platform. Developers still ignore the OS because the installed base shrank further due to the handset maker's prior momentum loss. The acquisition burned cash that should have funded a pivot or niche dominance.

This is a one-way door with high irreversibility. The cost of delay is low compared to the cost of a failed integration. The proposal assumes hardware control solves a software distribution problem, a category error. The falling sales indicate the brand is already toxic; buying it accelerates the bleed rather than stopping it. The €5.4 billion would be better spent retaining key talent or licensing the OS to other manufacturers to widen the install base without the baggage of a failing device division.

DECISION: NO-GO
