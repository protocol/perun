**Steelman:** A $100 cartoon-house shell on high-end PCs solves home-user intimidation in 1995 before a major OS update arrives.

**Attack:**
1.  **Hardware Mismatch:** The proposal admits home users find computers hard, yet requires a "high-end PC." In 1995, the vast majority of home users possess mid-to-low-range machines lacking the memory for such a graphical shell. The target demographic cannot run the product.
2.  **Imminent Obsolescence:** A "major new operating-system release" is months away. Historically, these releases integrate native usability improvements. Selling a separate $100 layer just before a free, integrated system update renders the product dead-on-arrival.
3.  **Ecosystem Void:** "Few third-party add-ons" means the shell offers no utility beyond the metaphor. Users need to *do* things (write, calculate), not just navigate a cartoon house. Without app support, it is a screensaver, not a productivity tool.
4.  **Audience Alienation:** The "patronizing" risk is real. Buying a PC often implies a desire for competence; a cartoon interface may signal "toy," discouraging adoption by the very adults trying to upskill.

**Better Way:** Do nothing. Wait for the upcoming OS release which will likely address interface concerns natively and support existing hardware. If a shell is truly needed, bundle it with new high-end hardware sales rather than selling it as standalone software to an installed base that cannot run it.

**Kill Criteria:**
*   **Blocker:** The hardware requirement excludes >80% of the target "home user" market.
*   **Blocker:** The timeline overlaps with a free, superior, native alternative.
*   **Metric:** If <20% of current home PCs meet the "high-end" spec, the market is too small to sustain development.

**Conclusion:** The proposal targets a demographic that lacks the hardware to run it, solves a problem the operating system vendor is about to solve for free, and lacks an ecosystem. It is a strategic mismatch.

DECISION: NO-GO
