**Steelman:** A search company can disrupt mature email by offering 100x storage and superior search, monetizing via contextual ads, turning a utility into a data asset.

**Blockers:** NONE. The proposal's cited risks (cost, privacy, incumbents) are execution challenges, not factual contradictions. In 2004, storage costs were dropping rapidly, making 1GB feasible for a cash-rich search firm. Privacy concerns are real but manageable via policy and user value exchange; they do not technically prevent launch. Incumbents' low storage is a vulnerability, not a shield.

**Risks:** High operational cost if ad yield fails; reputational damage if privacy handling is perceived as invasive; slow adoption due to invitation-only friction.

**Edge:** The proposer's core competency is large-scale indexing and ad matching, which incumbents lack. The "free" model with massive storage breaks the existing "delete to survive" user behavior, creating immediate viral demand.

**Better Ways:** Doing nothing cedes the data layer to competitors. A paid model would fail against free incumbents. The invitation-only approach is a valid, low-cost stress test before full scaling.

**Kill Criteria:** If ad revenue per user does not cover storage costs within 18 months, or if privacy backlash causes >5% user churn in the first quarter, pivot to a tiered paid model or halt expansion.

**Decision Logic:** The plan beats "do nothing" by securing a strategic data foothold. It beats alternatives by leveraging unique existing assets (search/ad tech). The risks are monitored via kill criteria, not blockers. The edge is defensible.

**Strongest Attack Survived:** The claim that "storage costs make this impossible" was tested against 2004 hardware trends; costs were falling faster than linear user growth, and the search company's cash flow absorbs initial losses better than any pure-play email competitor.

**Dissent Ledger:** Privacy advocates will object; cost per user is initially negative.
**Remaining Risk:** Regulatory intervention on data scanning.

DECISION: GO
