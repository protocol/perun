**Steelman:** A cartoon-house shell makes computing approachable for novices, creating a new home-user segment before the next OS release.

**Attack:**
1.  **Hardware Mismatch:** The proposal requires a "high-end PC," yet the target is "new home users" who statistically own lower-spec machines. The risk that "it needs more memory than most home PCs have" is not a risk; it is a confirmed blocker based on the proposal's own constraints. The market cannot run the product.
2.  **Cannibalization & Timing:** A "major new operating-system release" is imminent. Launching a $100 stopgap shell months before a native OS update (likely containing similar ease-of-use features) guarantees immediate obsolescence. Customers will not pay for temporary functionality included in their upcoming free/upgrade OS.
3.  **Adoption Friction:** Experienced users (who often influence household purchases) find it "patronizing," while the "few third-party add-ons" limit utility. Without an ecosystem, the "rooms" are empty.

**Alternatives:**
*   *Do Nothing:* Wait for the upcoming OS release to address usability natively. Cost: $0. Risk: Competitors might act (unlikely given hardware constraints).
*   *Software Only:* Release a lightweight guide without the heavy graphical shell. Lower hardware requirements, but less differentiation.

**Pre-mortem:** Six months post-launch, sales are near zero. The installed base is too small to run the software, and those who can run it refuse to buy a $100 wrapper for an OS they know will be replaced shortly. Inventory is scrapped.

**Edge Analysis:** The proposal claims no unique asset to overcome the hardware barrier or the timing cliff. "Strategic necessity" is not an edge when the technical foundation (hardware penetration) does not exist.

**Blockers:**
1.  Target market hardware cannot meet minimum requirements (stated in proposal).
2.  Imminent native OS release renders the paid shell valueless.

**Risks:** User rejection, lack of ecosystem.
**Edge:** None identified.

This fails the basic viability test: the customers cannot run it, and those who can won't buy it given the near-term roadmap. It is a solution for a hardware demographic that does not yet exist, sold at a price point unjustified by its lifespan.

DECISION: NO-GO
