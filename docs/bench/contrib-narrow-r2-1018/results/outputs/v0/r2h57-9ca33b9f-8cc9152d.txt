### Commit Message
```text
fix(search): prevent OOM on unbounded regex repetition in query parser

The query parser previously entered an infinite loop when processing
specific regex patterns lacking anchors, causing heap exhaustion.
This change introduces a depth limit to the recursion and validates
pattern complexity before execution.

Fixes issue #402.
```
