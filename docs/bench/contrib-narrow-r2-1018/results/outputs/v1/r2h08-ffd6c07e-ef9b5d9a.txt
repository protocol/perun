    ```bash
    git rebase -i HEAD~14
    ```
3.  **Edit Commit Messages**: In the editor that opens, change `pick` to `reword` for any commit message containing "Umbrella Corp" or internal project names. Save and close.
4.  **Sanitize Messages**: For each paused commit, rewrite the message to describe the *technical problem* (e.g., "Fix race condition in auth middleware") rather than the specific client context. Remove all proper nouns related to the client.
5.  **Complete Rebase**: Allow Git to finish rewriting the history. If conflicts arise, resolve them, stage the changes (`git add .`), and continue (`git rebase --continue`).
6.  **Force Push to Fork**: Since hashes have changed, update your remote branch.
    ```bash
    git push --force-with-lease origin <your-branch-name>
    ```

The phrase "remove environment-specific details" or "sanitize commit messages per project guidelines" is sufficient.
