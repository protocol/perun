**PR Description: Catalogue Migration Strategy Selection**

**Context**
This PR requests approval for the technical approach to migrate 1.2M bibliographic records from the legacy Horizon system to the new FOLIO instance. We must select a strategy immediately to meet the review deadline of Friday, Oct 13.

**Options**
We are evaluating two migration paths:

*   **Option A: Big-Bang Cutover**
    *   **Method:** Migrate all 1.2M records in a single window over a weekend.
    *   **Success Rate:** 92% (based on pilot data).
    *   **Impact:** Requires 6 hours of system downtime.
    *   **Risk:** Service interruption affects all users simultaneously; rollback is complex once the window closes.

*   **Option B: Phased Migration**
    *   **Method:** Migrate by collection segment across three distinct phases.
    *   **Success Rate:** 88% (based on pilot data).
    *   **Impact:** Zero downtime per phase; services remain available during transitions.
    *   **Risk:** Lower initial success rate requires more intensive validation between phases; total project timeline extends longer than Option A.

**Recommendation**
Requesting approval to proceed with **Option B (Phased Migration)**.

While Option A offers a higher single-event success rate, the 6-hour downtime window poses an unacceptable risk to the 3,000 active users currently relying on the system for critical operations. Option B's zero-downtime model aligns better with our service continuity goals leading up to the vendor demo on Oct 16 and the Library Board status update on Oct 20. The 4% difference in success rate can be mitigated through targeted validation scripts between phases.

**Next Steps**
1.  **Approval:** Priya to approve the phased approach by Friday, Oct 13.
2.  **Execution:** Begin Phase 1 immediately following approval.
3.  **Training:** Separate workstream initiated to train 3,000 active users on the new FOLIO interface (not included in this PR scope).
4.  **Reporting:** Prepare status metrics for the Library Board review on Oct 20.

**Constraints**
*   Migration budget ($150K) is confirmed and managed outside this PR.
*   Technical scope is limited to the migration strategy; user training and budget allocation are handled separately.
