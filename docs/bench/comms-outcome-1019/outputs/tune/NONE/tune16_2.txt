**Reviewer:** @Priya (Model Owner)

### Summary
This PR introduces a new pharmacy demand forecasting model to replace the current baseline. We are proposing the adoption of **Approach B (Regression with Weather Covariates)** over Approach A. Additionally, this update adjusts stock alert thresholds and expands the test suite coverage.

### Proposed Changes

**1. Forecasting Model Selection**
We evaluated two approaches for the new demand model:
*   **Approach A:** Utilizes a moving-average baseline.
*   **Approach B (Recommended):** Utilizes a regression model incorporating weather covariates.

**Performance Comparison:**
Based on the last six months of historical data, Approach B demonstrates a significant improvement in accuracy:
*   **Mean Absolute Error (MAE):** Reduced from **12.4%** (current/approach A baseline) to **9.1%** with Approach B.

**Trade-offs & Constraints for Approach B:**
*   **Compute Resources:** Runtime increases by approximately **2.5x** compared to the baseline.
*   **Data Latency:** The weather data pipeline has a **3-day lag**, which may impact real-time forecasting capabilities.

**2. UI Updates: Stock Alerts**
*   Modified the stock alert threshold logic from **5 days** to **7 days** to align with the improved forecast horizon.

**3. Test Coverage**
*   Expanded the test suite from 180 to **214 cases** to cover new regression logic and edge cases introduced by weather data integration.

### Recommendation
We recommend merging **Approach B**. Despite the increased compute cost and the 3-day weather data latency, the reduction in forecast error (3.3 percentage points) offers substantial value for inventory optimization. The 7-day alert threshold adjustment complements this model by providing a wider buffer for supply chain reactions.
