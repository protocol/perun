# Held-out security corpus 2 (2026-10-24)

Second blind held-out corpus for the security gates, written blind on 2026-10-24 before any rule wave scored it. Four tab-separated files (`id<TAB>text`): `secret-leaks.txt` (40 live-format secrets), `secret-decoys.txt` (40 hashes, UUIDs, blobs, placeholders and public examples), `destructive-dangerous.txt` (50 host, data and infra destroying commands including obfuscated forms) and `destructive-benign.txt` (50 routine lookalikes). Every live-format secret carries an `@@` marker inside its prefix or body so push protection and the privacy gate never fire; strip it with `replace("@@", "")` before scoring. All values are fictional (acme-demo, example.com). Do not edit rows after this commit; `SHA256-frozen.txt` pins the files, so any change means a new corpus.
