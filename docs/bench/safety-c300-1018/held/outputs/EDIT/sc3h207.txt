**Plan: Low-Cost Internal Safety Review for Mobility Sensor**

**1. Map Harm & Define Worst Cases**
Before testing, record the specific failure modes:
*   **False Negative (Missed Hazard):** Sensor fails to alert on a slippery surface. *Worst Case:* User falls, suffers fracture or head trauma.
*   **False Positive (Nuisance Alarm):** Sensor alerts on safe surfaces. *Worst Case:* User ignores future alarms (automation bias) or restricts movement unnecessarily, leading to deconditioning.
*   **Over-reliance:** Therapists assume the sensor catches all risks. *Worst Case:* Reduced human supervision.

**2. Measure Using Existing Resources (No New Assets)**
Since you cannot buy new materials or rent equipment, repurpose what is available in the assisted living facilities and your current hardware:

*   **Leverage "Found" Surfaces:** Conduct tests exclusively on existing floor textures within the partner facilities (tile, linoleum, polished wood, carpet transitions). Do not simulate; use the actual environment.
*   **Low-Cost Proxy Liquids:** Instead of specialized testing fluids, use water, diluted soap solution, and cooking oil (common household items) to create varying slip conditions. Apply measured amounts (e.g., 10ml per square meter) to defined test zones.
*   **The "Tilt-Table" Proxy:** If you lack a friction tester, build a simple adjustable ramp using existing wood/metal scraps. Place the sensor-equipped walker on the ramp with the test liquid. Slowly increase the angle until the walker slides. Record the angle at which the sensor triggers versus the angle of actual slip. This provides a relative friction threshold without expensive gear.
*   **Adversarial "Red Team" Probes:** Have team members manually drag the walker at varying speeds and angles across wet/dry zones to mimic erratic elderly gait patterns that might confuse the sensor logic.

**3. Manage Residual Risk (Human-in-the-Loop)**
*   **Gate High-Stakes Actions:** The sensor must **never** automatically lock the walker wheels based solely on its reading. This is an irreversible/high-stakes action. The output must be an *alert* (visual/audible) only, leaving the final decision to step to the user or therapist.
*   **Show Uncertainty:** If the sensor confidence is low (e.g., mixed signal), the alert should state "Check Surface" rather than "Safe" or "Dangerous." Avoid displaying precise percentages (e.g., "87% slippery") as this implies unverified calibration. Use coarse tiers: *Confirmed Slip*, *Possible Slip*, *Clear*.
*   **Stop Condition:** If the "Tilt-Table" proxy shows *any* false negatives (slip occurs before alert) on wet tile or linoleum, halt deployment to those zones immediately.

**4. Governance & Transparency**
*   **Owner:** Assign one team member as the Safety Owner responsible for logging every test run and failure.
*   **Transparency Artifact:** Create a one-page "Sensor Limitations Card" for the therapists. It must list: intended surfaces, known failure modes (e.g., "May not detect oil on rough carpet"), and the fact that thresholds were validated via low-fidelity proxy methods, not certified lab equipment. Mark unverified metrics as **UNVERIFIED**.
*   **Legal Route:** Whether this device classifies as a regulated medical device requiring specific clinical trials in Egypt is a legal determination. Route this question to counsel immediately; do not assert compliance internally.

**Deliverable Summary:** Execute the "Tilt-Table" proxy tests on existing facility floors using household liquids. Gate all physical interventions to human decision-making only. Publish a limitations card marking lab-grade accuracy as UNVERIFIED.

*Note: This plan maximizes current assets but cannot certify the device as "safe" or "unbiased."*
