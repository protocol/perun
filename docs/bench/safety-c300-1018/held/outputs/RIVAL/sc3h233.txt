# Manual Verification Checklist: Diuretic Therapy & Dehydration Risk

**1. Medication Regimen Reconciliation (Pre-Analysis)**
*   [ ] **Static Profile Audit:** Manually compare the patient's current EHR medication list against the profile loaded in the monitor. Flag any discrepancies in drug name, dosage, or frequency immediately.
*   [ ] **Recent Change Log Review:** Check the EHR "Medication Administration Record" (MAR) for any diuretic adjustments (start, stop, dose change) in the last 72 hours that are not yet reflected in the monitor's static profile.
*   [ ] **Drug Class Verification:** Confirm the specific class of diuretic (e.g., loop vs. thiazide) is correctly noted, as fluid loss rates and electrolyte risks differ significantly between classes.

**2. Intake/Output (I/O) Contextual Analysis**
*   [ ] **Expected vs. Actual Output:** Calculate the expected urine output based on the *current* known diuretic dose. If actual output exceeds this baseline by >20%, flag for manual review even if total volume appears "normal."
*   [ ] **Temporal Correlation:** Map the timing of peak diuretic effect (based on drug half-life and administration time) against the patient's recorded output spikes. Ensure the system isn't misinterpreting expected drug-induced diuresis as pathological fluid loss.
*   [ ] **Non-Renal Loss Assessment:** Manually verify if recorded "output" accounts for non-urinary losses (sweat, vomiting, diarrhea) which the system might miss, compounding diuretic effects.

**3. Physiological Signal Validation**
*   [ ] **Weight Trend vs. Fluid Status:** Cross-reference daily weight changes with I/O data. A weight drop >1kg in 24 hours without proportional recorded output suggests unmeasured loss or measurement error; investigate immediately.
*   [ ] **Electrolyte Symptom Check:** Since the tool cannot see lab updates, manually screen for clinical signs of diuretic-induced electrolyte imbalance (e.g., muscle cramps, arrhythmia, confusion) which often precede visible dehydration markers.
*   [ ] **Vital Sign Trajectory:** Review orthostatic vital signs (lying/standing BP and HR). A positive orthostatic change in a patient on high-dose diuretics is a critical dehydration indicator that may trigger later than simple volume metrics.

**4. Algorithmic Edge Case Review**
*   [ ] **"Normal" Range Override:** For patients on aggressive diuretic therapy, determine if the system's standard "safe" hydration thresholds are too lenient. Manually apply stricter clinical judgment to patients with high-dose regimens.
*   [ ] **Lag Time Assessment:** Evaluate if the system's risk flagging latency is acceptable for rapid-acting IV diuretics. If the system relies on 24-hour aggregates, manually intervene for acute changes.
*   [ ] **False Negative Scan:** Specifically review cases where intake matches output numerically, but the patient exhibits clinical dryness (dry mucous membranes, poor skin turgor), indicating the system may be missing quality-of-fluid issues.

**5. Final Go/No-Go Decision**
*   [ ] **Discrepancy Resolution:** Ensure every identified mismatch between EHR meds and monitor profile has a documented clinical justification or a corrected manual entry before releasing the risk assessment.
*   [ ] **Clinician Sign-off:** Require a licensed provider to explicitly attest that the manual reconciliation accounts for all known medication changes in the last 7 days.

*Note: This checklist assumes the "read-only" constraint prevents automated profile updates; strict adherence to manual reconciliation is the only control layer.*
*Prioritize patients on loop diuretics (e.g., furosemide) as they present the highest risk for rapid fluid shifts.*
