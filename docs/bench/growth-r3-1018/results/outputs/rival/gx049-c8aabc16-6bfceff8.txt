# TaskFlow Custom Workflow Adoption Diagnostic Plan

**Objective:** Differentiate between discoverability (visibility) and usability (friction) as the primary driver of the 25% adoption drop post-November 5th redesign.

**Data Scope:** Interaction logs from October 15–November 4 (Baseline) vs. November 5–November 26 (Post-Launch). Segment specifically for "Existing Users."

### Phase 1: Funnel Decomposition (The "Where")
Break the user journey into three distinct stages to isolate the drop-off point. Calculate conversion rates for each stage in both periods.

1.  **Exposure Rate:** % of active users who loaded a page where the "Custom Workflow" entry point was visible.
    *   *Diagnostic:* If this metric dropped significantly, the feature is buried (Discoverability Issue).
2.  **Click-Through Rate (CTR):** % of exposed users who clicked the entry point.
    *   *Diagnostic:* If Exposure is stable but CTR plummeted, the visual hierarchy or labeling is confusing (Discoverability/Clarity Issue).
3.  **Completion Rate:** % of users who clicked the entry point and successfully saved a workflow.
    *   *Diagnostic:* If CTR is stable but Completion dropped, the configuration interface is broken or too complex (Usability Friction).

### Phase 2: Behavioral Pattern Analysis
Analyze specific interaction signatures within the logs to validate hypotheses.

**Indicators of Discoverability Issues:**
*   **Zero-Entry Sessions:** Increase in sessions where users performed other actions but never navigated near the new menu location.
*   **Search Usage:** Spike in internal search queries for "workflow," "custom," or "automation" followed by no click (indicating they couldn't find the UI element).
*   **Help Center Traffic:** Increase in clicks on "How to create workflows" documentation immediately post-login.

**Indicators of Usability Friction:**
*   **Rage Clicks/Thrashing:** Multiple rapid clicks on non-interactive elements within the workflow builder.
*   **Step Abandonment:** High drop-off at specific configuration steps (e.g., after selecting a trigger but before setting conditions).
*   **Time-on-Task:** Significant increase in time spent on the builder screen without a corresponding increase in completion (indicates confusion).
*   **Error Logs:** Spike in client-side validation errors or failed save attempts during the creation flow.

### Phase 3: Cohort Comparison
Compare behavior between two specific groups to rule out general engagement declines:
*   **Power Users:** Those who created >3 workflows/month previously.
*   **Casual Users:** Those who created 1 workflow/month previously.
*   *Logic:* If Power Users are dropping off at the *Exposure* stage, the navigation change is severe. If they drop off at *Completion*, the new UI likely removed efficiency shortcuts they relied on.

### Decision Matrix for Head of Design

| Primary Drop-Off Point | Key Metric Signal | Recommended Action |
| :--- | :--- | :--- |
| **Exposure** | Significant drop in % users seeing the entry point. | **Revert/Adjust Nav:** Move the entry point higher in the hierarchy or add a dashboard widget. Do not invest in guidance yet. |
| **Click-Through** | Stable exposure, sharp drop in clicks; high search volume. | **UI Clarity Fix:** Rename the menu item, increase icon prominence, or add a tooltip. |
| **Completion** | Stable clicks, sharp drop in saves; high time-on-task/errors. | **Usability Fix:** Simplify the builder steps or restore previous interaction patterns. |
| **All Stages** | Uniform decline across all metrics. | **Guidance Campaign:** Launch in-app tours and contextual help to re-educate users on the new flow. |
