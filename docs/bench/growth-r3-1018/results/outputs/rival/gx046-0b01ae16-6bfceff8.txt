# AquaSmart Activation Event Evaluation Framework

## Objective
Identify which early user behavior best predicts six-month retention to redefine "activation" and optimize the onboarding flow.

## Proposed Activation Candidates
Evaluate these three distinct events as potential activation definitions:
1.  **Setup Complete:** User finishes the initial device setup wizard (connects to Wi-Fi).
2.  **First Manual Water:** User triggers at least one manual watering cycle via the app.
3.  **True Automation:** User creates and saves their first custom watering plan utilizing local weather data.

## Evaluation Methodology: Cohort Retention Analysis

### Step 1: Data Segmentation
Segment all users who received hardware between May 10th and present into three mutually exclusive cohorts based on their *first* achieved milestone within the first 14 days:
*   **Cohort A (Setup Only):** Completed setup but performed no manual or automated watering within 14 days.
*   **Cohort B (Manual First):** Performed a manual water before creating an automated plan.
*   **Cohort C (Auto First):** Created an automated plan without prior manual watering.

*Note: Users who achieved multiple actions should be categorized by the earliest action taken.*

### Step 2: Metric Calculation
For each cohort, calculate the **Month-6 Retention Rate**:
$$ \text{Retention Rate} = \frac{\text{Users active in Month 6}}{\text{Total Users in Cohort}} $$

*Definition of "Active" in Month 6:* Any user who executed at least one watering cycle (manual or auto) or logged into the app to view status during the sixth month post-purchase.

### Step 3: Comparative Analysis
Create a comparison table:

| Activation Definition | Cohort Size | Month-6 Retention Rate | Lift vs. Baseline (Setup Only) |
| :--- | :--- | :--- | :--- |
| **Setup Complete** | (Total Users) | X% | — |
| **Manual Water First** | (Count) | Y% | +/-% |
| **Custom Auto Plan** | (Count) | Z% | +/-% |

### Step 4: Statistical Validation
*   **Significance Testing:** Apply a chi-squared test to determine if the difference in retention rates between cohorts is statistically significant (p < 0.05).
*   **Sample Size Check:** Ensure each cohort has sufficient volume (minimum 100 users recommended) to yield reliable data. If Cohort B or C is too small, combine them for a binary "Any Watering" vs. "Setup Only" comparison first.

## Decision Criteria for Redesign
Select the activation event that meets both conditions:
1.  **Highest Predictive Power:** The event with the highest Month-6 retention rate that is statistically significant.
2.  **Achievability:** The event must be achievable by at least 40% of new users within the current flow (to ensure the goal is not impossibly high).

*   **If "Custom Auto Plan" wins:** Redesign onboarding to aggressively guide users to weather-based scheduling immediately, potentially delaying manual controls.
*   **If "Manual Water First" wins:** Restructure onboarding to encourage a quick "test run" manual cycle to build confidence before introducing complex automation settings.
*   **If "Setup Complete" wins:** The current drop-off is likely due to hardware issues or lack of immediate need, not software complexity; focus on pre-shipment education or hardware reliability instead.

## Immediate Next Steps for Product Design Team
1.  Extract user event logs for May 10–Present.
2.  Run the cohort analysis defined above.
3.  Present the winning metric at the next design sprint planning session to set the primary success metric for the new onboarding flow.

*Ensure "active" status in Month 6 is strictly defined to avoid inflating retention with passive users.*
*If data volume is low, extend the analysis window to include beta testers if their usage patterns match retail users.*
