# EnterpriseCloud Touchpoint Valuation Framework

## Executive Summary
To resolve the conflict between marketing's multi-touch view and sales' last-interaction focus, we will implement a **Weighted Journey Allocation** method. This approach assigns value based on touchpoint position and type without double-counting revenue, satisfying both teams' need for credit while providing the CRO with actionable budget data.

## Methodology: Position-Weighted Value Assignment

### Step 1: Map the Standard Enterprise Journey
Analyze the 300 active opportunities ($12M pipeline) to identify common touchpoint sequences. Categorize touches into three phases:
- **Awareness Phase**: Whitepapers, blog content, organic social
- **Consideration Phase**: Webinars, case studies, comparison guides
- **Decision Phase**: Demos, proposals, executive meetings

### Step 2: Assign Position Weights
Instead of splitting credit equally or giving all to last touch, apply fixed weights based on journey position:

| Journey Phase | Weight | Rationale |
|---------------|--------|-----------|
| First Touch | 30% | Captures awareness drivers (validates marketing's whitepaper hypothesis) |
| Middle Touches | 40% | Distributed across consideration activities |
| Last Touch | 30% | Recognizes sales' closing effort |

**Critical Rule**: Total allocation per deal equals 100% of closed revenue. No double-counting.

### Step 3: Calculate Channel Contribution
For each closed deal, distribute the ARR value across touching channels using the weights above. Aggregate across all deals to show:
- Total value attributed to each channel
- Average touchpoints per won deal
- Channel frequency by journey phase

### Step 4: Measure Incremental Lift Without Holdouts

Since enterprise holdout tests are impractical, use **Cohort Timing Analysis**:

1. **Identify natural variation**: Find periods where specific channels were temporarily unavailable (technical issues, content gaps, seasonal pauses)
2. **Compare conversion rates**: Measure pipeline velocity and win rates during normal vs. reduced-touch periods
3. **Calculate lift**: The difference in outcomes represents the channel's incremental contribution

For whitepapers specifically:
- Compare deals with whitepaper downloads in first 30 days vs. those without
- Control for company size, industry, and source
- Measure difference in win rate and sales cycle length

## Implementation Plan

### Week 1: Data Preparation
- Export all 300 opportunities with complete touchpoint histories
- Tag each touch by type and journey phase
- Apply position weights to calculate attributed value

### Week 2: Analysis & Validation
- Generate channel contribution reports using weighted allocation
- Run cohort timing analysis for key channels
- Validate findings with sales and marketing stakeholders

### Week 3: Budget Recommendations
- Present channel ROI based on attributed value vs. spend
- Identify over/under-invested channels
- Propose Q3 budget reallocation

## Expected Outcomes

**For Marketing**: Early-stage content receives measurable credit (30% first-touch + middle-touch allocation), validating whitepaper investment.

**For Sales**: Last-interaction retains significant weight (30%), acknowledging closing efforts while recognizing earlier contributions.

**For CRO**: Clear view of which channels drive pipeline velocity and revenue, enabling data-driven budget decisions without model complexity.

## Key Metrics to Track
- Attributed revenue by channel (weighted)
- Average touchpoints per won deal
- Channel contribution by journey phase
- Pipeline velocity by touchpoint pattern

This approach provides immediate clarity for Q3 budgeting while building toward more sophisticated measurement as data accumulates.

---
*Note: This framework requires clean touchpoint data; if tracking gaps exist, prioritize fixing those concurrently. Results should be reviewed quarterly and weights adjusted based on observed patterns.*
