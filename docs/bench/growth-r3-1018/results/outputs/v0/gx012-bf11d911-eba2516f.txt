### Key Indicators for Smart FAQ Widget Evaluation

**1. North Star Metric: Net Support Capacity Saved**
Do not measure ticket volume alone. Measure **Net Capacity Saved**, calculated as: *(Tickets Deflected × Avg. Time per Easy Ticket) – (Increase in Avg. Resolution Time × Remaining Ticket Volume)*.
*   **Why:** A drop in volume is vanity if the remaining tickets become so complex that agent hours increase overall. This metric rises only if the widget actually frees up agent time.
*   **Target:** Positive value indicating net hours saved compared to the pre-January 15 baseline.

**2. Input Metric A: Deflection Quality Rate (The "Confusion" Check)**
Measure the percentage of users who interact with the widget and then submit a ticket *within 10 minutes* containing keywords like "didn't work," "confusing," or "still need help."
*   **Why:** This isolates whether the widget is solving problems or creating friction that leads to longer, more frustrated human interactions.
*   **Action:** If this rate exceeds 15% of widget interactions, the logic is likely confusing users rather than helping them.

**3. Input Metric B: Complexity Shift Ratio**
Compare the distribution of ticket tags/categories pre-launch vs. post-launch. Specifically, track the ratio of "Basic/How-To" tickets to "Complex/Bug/Account" tickets among human-served cases.
*   **Why:** Success looks like a sharp drop in "Basic" tickets while "Complex" ticket times remain stable. Failure looks like "Basic" tickets disappearing but "Complex" tickets spiking in duration because users arrive already frustrated or having attempted broken fixes.
*   **Verification:** Pull cohort data for agents handling tickets pre- and post-launch to control for individual agent speed variations.

**4. Guardrail Metric: Customer Satisfaction (CSAT) on Deflected vs. Human Paths**
Segment CSAT scores by users who found an answer in the widget versus those who bypassed it or failed it and reached an agent.
*   **Why:** Volume reduction is not success if it destroys satisfaction. If CSAT drops >10% for the "Widget → Agent" path compared to the "Direct → Agent" path, the widget is damaging the relationship.
