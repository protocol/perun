**Actionable Segmentation for Tuning**

Stop guessing about "unusual locations." Segment the 1,050 daily false positives by these three dimensions to find the leak:
1.  **Merchant Category Code (MCC):** Are false positives concentrated in specific verticals (e.g., travel, digital goods, groceries)? A spike in one MCC indicates a rule too sensitive to that sector, not a global model failure.
2.  **Velocity vs. Location:** Cross-tabulate "New Location" against "Transaction Frequency." If the model flags a loyal customer's first purchase in a new city, it is over-weighting location and ignoring history. If it flags high-frequency transactions in a new location, the logic may be sound but the threshold too low.
3.  **Customer Tenure:** Segment by account age. Flagging a 5-year customer creates significantly higher churn risk than flagging a 5-day-old account. If >40% of false positives are from tenants >1 year, the model is attacking your core retention base.
