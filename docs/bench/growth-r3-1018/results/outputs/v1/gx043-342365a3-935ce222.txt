**Diagnostic Report: Referral Funnel Discrepancy (Oct 1–7)**

**Executive Summary**
The 210% spike in invites (5,000 → 15,500) with flat conversions (~450) indicates a collapse in the **Activation** stage of the referral funnel, not necessarily a technical tracking failure. The conversion rate dropped from ~9% to ~2.9%. Before assuming infrastructure failure, we must isolate whether the drop is caused by invalid recipient data, email deliverability blocks, or a broken landing page experience.

**Immediate Data Pulls (Required by Wednesday EOD)**
To present a remediation plan to the board, pull these four specific datasets from our analytics and email provider:

1.  **Invitee Domain & Syntax Validation:** Segment the 15,500 invites by domain validity and syntax.
    *   *Question Answered:* Are users sending invites to invalid/botted addresses (e.g., typo-squatting, disposable domains)?
    *   *Action Trigger:* If >40% are invalid, the issue is user behavior or input validation, not delivery. Fix: Add real-time email verification at the point of invite.

2.  **Email Delivery & Bounce Rates:** Correlate invite timestamps with SMTP logs for hard/soft bounces and spam complaints.
    *   *Question Answered:* Did the volume spike trigger provider throttling or spam filtering?
    *   *Action Trigger:* If bounce rate >5% or block rate spiked, the issue is deliverability. Fix: Pause sends, warm up IPs, and sanitize the list.

3.  **Landing Page Drop-off by Referrer Source:** Compare bounce rates and time-on-page for traffic arriving via referral links vs. direct/organic traffic for the same week.
    *   *Question Answered:* Did the landing page experience degrade specifically for referred users (e.g., broken deep links, slow load times on specific devices)?
    *   *Action Trigger:* If referral bounce rate is >20% higher than baseline, the issue is the landing page. Fix: Audit deep link parameters and mobile rendering.

4.  **Sender Cohort Analysis:** Identify if the spike originated from a specific user segment (e.g., one power user, a bot network, or a specific corporate domain).
    *   *Question Answered:* Is this organic growth or an abuse vector?
    *   *Action Trigger:* If >50% of invites come from <1% of users, it is likely abuse. Fix: Implement rate limiting and CAPTCHA on the invite flow.

**Recommended Remediation Paths**
Based on the data above, the board presentation will propose one of three paths:
*   **Path A (Data Quality):** If invites are invalid, implement input validation and restrict invites to verified corporate domains.
*   **Path B (Deliverability):** If emails are blocked, engage the provider for reputation repair and switch to a transactional-only queue for referrals.
*   **Path C (Product Friction):** If landing page drop-off is high, roll back recent UI changes to the referral landing page and fix deep-link routing.
