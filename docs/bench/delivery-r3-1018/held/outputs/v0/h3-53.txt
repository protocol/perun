**Delivery Plan: Parallel Log Aggregation Cutover**

**Lanes & Serialization**
Work splits into three serialized phases; no parallel writes to production config.
1.  **Lane A (Config & Guardrails):** Implement dual-write logic in `infra-core`, add latency circuit breaker (200ms threshold), and define the "pause" automation. *Writer: Builder.*
2.  **Lane B (Backfill Engine):** Develop the weekly historical batch job for NovaFlow. *Writer: Builder (distinct worktree).*
3.  **Lane C (Verification Suite):** Build the zero-data-loss comparison tool and query parity tests. *Writer: QA (independent).*

*Serialization:* Lane A must merge and deploy before Lane B starts backfill. Lane C runs continuously against Lane A's output. Lane B requires a separate maintenance window deployment.

**Gates & Checks**
*   **G1 Spec:** Freeze requirements: 7-year retention, 90-day dual-write, 200ms latency cap. Pin base SHA before coding.
*   **G3 Design:** Architectural Decision Record (ADR) detailing the irreversible backfill point and rollback limits. Must be signed by Security Architect.
*   **G4 Implement:** Code changes in isolated worktrees. Unit tests for latency logic included.
*   **G5 Verify (Staging):**
    *   Deploy Lane A to staging.
    *   Run synthetic load; assert latency <200ms.
    *   Trigger known flaky network check; if signature matches Thursday issue, ignore. Otherwise, block.
    *   **QA Receipt:** Lane C confirms 100% event match between LegacyStream and NovaFlow in staging.
*   **G6 Review:**
    *   **Security Architect:** Reviews data flow, retention compliance, and irreversibility risks.
    *   **Site Reliability Lead:** Reviews latency guards and CI impact.
    *   *Constraint:* Independent review only; Builder cannot approve.
*   **G7 Integrate:** Merge to integration branch. Trigger CI once (cost control). Wait for 45m pipeline.
*   **G8 Release (Human Gate):**
    *   **Decision 1:** Approve dual-write toggle for next Tuesday.
    *   **Decision 2:** Authorize Sunday maintenance window for schema changes (if any).
    *   **Decision 3:** Authorize start of historical backfill (Lane B) only after 90-day verification report is green.

**Review Strategy**
*   **Builder** implements logic.
*   **QA** executes Lane C verification independently on the exact merged SHA.
*   **Security Architect** and **Site Reliability Lead** perform mandatory human review on the PR. No self-merging.

**Landing & Rollback**
*   **Merge:** PR merges only after both human approvals and green CI (ignoring known flake).
*   **Deployment:**
    *   *Tuesday:* Enable dual-write (Lane A). Monitor latency dashboard. Auto-pause triggers if >200ms.
    *   *Weekly:* Manual trigger for backfill batches (Lane B) post-verification.
*   **Rollback:**
    *   *Pre-Backfill:* Revert PR to disable NovaFlow ingestion. LegacyStream remains sole source.
    *   *Post-Backfill Start:* **No rollback possible** per repo facts. Mitigation involves fixing forward in NovaFlow; LegacyStream data remains intact for 90 days as a read-only audit trail.
*   **Completion:** Ticket closes only when the Compliance Officer accepts the "Zero Data Loss" report generated by Lane C after the 90-day window.

**Risk Controls**
*   **CI Cost:** Pre-merge local validation required to prevent unnecessary 15-credit builds.
*   **Flake Handling:** Explicitly document network check signature in PR body to prevent false red gates.
*   **Irreversibility:** Clear warning banner in PR description regarding the backfill point of no return.
