**Ruling: Scope is fixed to 'billing-reporting' and 'audit-log' only.** "Real-time-trading" and "user-checkout" are strictly excluded from this change set to mitigate latency risk. Any automation touching them is a failure.
**Ruling: Rollback is human-gated, not automatic.** Automatic rollback based on CPU alerts risks thrashing during transient spikes. Alerts will trigger a page to the on-call engineer who must execute the rollback script within 15 minutes.
**Ruling: CI runs once per candidate SHA.** To respect the $12 cost and 45-minute duration, we will validate locally and in a staging fork before triggering the single production pipeline run.
