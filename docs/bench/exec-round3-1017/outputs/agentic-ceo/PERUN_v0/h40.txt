1.  **Stream B: Beachfront‑Partner API Integration (Weeks 1–4).** Start here. It is the shortest stream and a hard dependency for the dynamic pricing engine to function with new inventory. Resolve the $50k licensing fee immediately upon commencement to avoid mid-project stoppage.
2.  **Stream C: Mobile‑First UI (Weeks 1–8).** Run parallel to Stream B. The UI requires the API data structure to be finalized but does not need the pricing logic to be complete for initial scaffolding. This maximizes parallel throughput.
3.  **Stream A: Dynamic‑Pricing Engine (Weeks 5–12).** Start after the API schema is locked (end of Week 4). This prevents rework if the partner API changes data fields. Total timeline remains 12 weeks, hitting the May 15 target for the internal QA window.
