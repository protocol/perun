# FlexPass Rollout Plan for Maya

**Recommended Order of Work**
1.  **Immediate (Weeks 1–2): Analytics Foundation.** Secure the $15k license and resolve the unknown API integration cost. *Reason:* You cannot measure the pilot’s success or the 5% price lift target without this data pipeline.
2.  **Parallel (Weeks 3–14): App Build & Pilot Prep.** Begin the 6-week mobile app build ($120k budget). Simultaneously, prepare downtown/midtown sites for the Sept 1 pilot (staff training, signage).
3.  **Execution (Sept 1 – Oct 15): Pilot Launch.** Run the pricing experiment strictly in the two sites while the app nears completion.
4.  **Go/No-Go (Oct 16): Full Rollout Decision.** Evaluate pilot data against success metrics before enabling FlexPass network-wide.

**Deferral Strategy**
*   **Defer:** Network-wide marketing push and non-essential UI polish on the app. Wait for pilot validation to ensure messaging resonates before spending broader marketing budget.
*   **Do Not Defer:** The API integration. Without it, the pilot is blind.

**Required Human Sign-Offs**
1.  **Before App Build Starts:** CFO approval on the final API integration cost (currently unknown) to confirm total project budget remains viable.
2.  **Before Sept 1 Pilot Launch:** Maya’s explicit sign-off on the final pricing tiers after reviewing a dry-run of the dashboard data.
3.  **Before Network-Wide Release:** CEO/COO joint approval based on pilot results (see kill switches below).

**Failure Modes & Kill Switches**
Stop or pivot immediately if:
*   **Occupancy Drop:** Site occupancy falls below **70%** for two consecutive weeks during the pilot (indicates price sensitivity is higher than modeled).
*   **Revenue Miss:** Pilot sites fail to achieve at least a **3% revenue uplift** by Oct 1 (missing the 5% target suggests the 8% booking boost assumption is flawed).
*   **Technical Block:** API integration cannot be resolved within 3 weeks, risking the ability to measure churn impact.

**Note:** The unknown API integration cost is the single biggest risk to the timeline; prioritize vendor technical discovery this week. Current $45k MRR per site provides a solid baseline, but the 2% churn reduction assumption must be validated by the pilot before promising board-level results.
