**Decision:** Start the **compliance audit** immediately as the critical path item, followed in parallel by the case-management integration, while deferring the "document-auto-populate" feature until post-pilot.

**Figures:** $80k (feature) + $15k (audit) + $250k (budget) leaves $155k unallocated; however, the 4-week integration and 6-week feature total 10 weeks of dev time, exceeding the 90-day pilot window if done sequentially. The $75k revenue target assumes 100% adoption of all three firms; at current 12% churn, realistic pilot revenue is closer to $66k ($75k * 0.88). The unknown API cost creates an uncapped variable expense that must be resolved before the pilot signs.

**Failure Modes:**
1.  **Regulatory Block:** The audit reveals the AI cannot legally handle intake data without specific certifications, halting the pilot entirely.
2.  **Integration Drag:** The 4-week assumption slips due to legacy firm systems, pushing the pilot start past the quarter and missing the revenue target.
3.  **Unit Economics Collapse:** Unpriced API usage exceeds $15 per transaction, erasing margins on the $75k revenue goal.

**Halt Triggers:**
*   **Value:** Pilot adoption <30% (1 of 3 firms) by Day 45.
*   **Date:** Compliance audit not signed off by [Current Date + 2 weeks].
*   **Action:** Immediate pause on dev spend; re-scope to manual intake support only.

**Fallback Trigger:**
*   **Value:** API costs confirmed >$10/transaction.
*   **Date:** Upon vendor quote receipt (before pilot launch).
*   **Action:** Switch to batch-processing mode to reduce call frequency, accepting a 24-hour delay in document generation.

**Note:** The "document-auto-populate" feature is deferred because its 6-week build time jeopardizes the 90-day pilot timeline and consumes 32% of the budget for a non-core differentiator at this stage. The unknown API pricing is a critical risk that must be quantified before any firm signs a pilot agreement.
