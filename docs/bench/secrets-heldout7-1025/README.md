Seventh blind held-out secrets corpus (60 leaks, 60 hard decoys), authored 2026-10-25 without reading any scanner, gate, test, banlist, allowlist, scorer, or any other corpus's rows or results; only the heldout-4 README and file layout were consulted, for format. Leak values are random-looking and use real vendor prefixes where they exist, with no placeholder words inside the values. They are generated from a random source, are fictional, and are not valid credentials. Decoys are hard look-alikes: hashes, UUIDs, public keys, checksums, env var references, redacted values, and public-by-design identifiers. File types covered: .env, config, CI YAML, Dockerfile, IaC, notebooks, logs, source in several languages, and Kubernetes secrets in base64.

Format: `secret-leaks.txt` (ids `L001`-`L060`) and `secret-decoys.txt` (ids `D001`-`D060`), each row `id<TAB>text`; a literal backslash-n inside a row means a newline. GitHub push protection note: rows whose token shape GitHub would match (Stripe, AWS, GitHub, Slack, OpenAI, SendGrid, GitLab, Twilio, Azure, Datadog, Postmark, Mailgun, Google, PEM private keys, and other vendor-prefixed tokens, including one decoy) carry a literal `@@` right after the vendor prefix. Scorers strip `@@` before scoring. Leak values are random, so none is a valid credential.

Frozen by SHA256 (`SHA256-frozen.txt`) and preregistered in `ledger.jsonl` before any scoring; not scored at authoring time.
