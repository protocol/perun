First call: GO. The shift from desktop to web, combined with satellite imagery and routing, creates a step-change in utility that outweighs the stated risks for a search company with distribution leverage.

**Steelman:** Leveraging existing search distribution to launch a free, browser-based map service with satellite imagery and routing will capture massive user value and data, establishing a defensive moat despite high initial licensing costs and technical browser limitations.

**Options:**
1.  **Do nothing:** Retain small desktop niche; cede web mapping to incumbents; lose strategic relevance.
2.  **License only:** Sell data to others; low margin, no user relationship.
3.  **Proposed Plan:** High cost and technical risk, but offers unlimited scale, direct user engagement, and data feedback loops impossible for desktop software. It beats "do nothing" by transforming a tool into a platform.

**Fit:** Aligns with a search company's north star of organizing information and capturing user intent. Web delivery matches the "ordinary browser" trend, removing friction.

**Pre-mortem:** Failure occurs if browser performance makes the UI unusable or licensing costs bankrupt the project before ad revenue scales. However, browser speed is a transient constraint (Moore's Law), while licensing is a solvable business negotiation. The cost of delay is ceding the "local intent" vertical to competitors.

**Evidence:** The proposal relies on the assumption that browser graphics can improve (historically true) and that users prefer free access over installed software (behavioral trend). No internal contradictions exist in the logic; the risks are execution hurdles, not fundamental flaws.

**Blockers:** NONE. The lack of a direct revenue model is not a blocker for a search company; indirect value via ad targeting and ecosystem lockout is the actual model. Technical slowness is a hurdle, not a stopper.

**Risks:** High burn rate on imagery licenses; potential for clunky initial UX due to browser limits. These are managed by phasing the rollout and leveraging the parent company's cash flow.

**Kill Criteria:** If browser frame rates remain below 15fps after 12 months of optimization, or if licensing costs exceed 40% of projected ad attribution value within 18 months, pivot to a data-licensing-only model.

**Leading Metric:** Daily Active Users (DAU) and queries per session. Review date: Q4 2005.

DECISION: GO
