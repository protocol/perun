**Steelman:** Converting the desktop tool to a free web app with satellite imagery and routing creates a ubiquitous, zero-friction utility that leverages the acquirer's search dominance to monopolize local intent, despite 2004 browser limitations.

**Skeptic:** The claim assumes browser graphics can handle smooth panning/zooming of large imagery in 2004 without plugins, which current mainstream browsers cannot do natively at scale. Licensing costs for global satellite data are unverified; if per-view fees apply, "free" access creates infinite liability. The "no revenue model" is a fatal gap; without a clear path to monetize via ads or enterprise API, this burns cash against established competitors who already monetize traffic.

**Better-Way:** Instead of a full global launch, license data for a single high-value metro area to prove the ad-revenue model and technical feasibility. Alternatively, keep the desktop client for heavy users and offer a limited web viewer only for route planning, deferring expensive satellite streaming until bandwidth costs drop. "Do nothing" preserves capital while the acquirer integrates search data into existing map partners.

**Kill Criteria:** This is a one-way door regarding brand reputation and licensing commitments. If the prototype cannot render 10x10km imagery tiles in under 2 seconds on a standard 2004 corporate PC, the user experience fails. If no advertiser commits to local intent ads within 6 months, the revenue hypothesis is false.

**Pre-mortem:** The project fails because bandwidth costs exceed ad yield, or because the interface is too sluggish compared to the installed desktop base, causing users to abandon the web version immediately. The "free" model attracts low-value traffic that cannot subsidize the expensive imagery licenses.

**Decision:** The proposal lacks a verified revenue mechanism to cover high fixed licensing costs and ignores the severe technical constraints of 2004 browsers for rich graphics. It bets the firm's integration capital on an unproven ad model and untested technical performance. The risk of massive operating losses without a pivot strategy is too high.

DECISION: NO-GO
