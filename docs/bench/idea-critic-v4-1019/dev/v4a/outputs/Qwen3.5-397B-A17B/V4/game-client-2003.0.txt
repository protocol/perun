First call: GO. The core failure mode (no updates, rampant cheating) threatens the franchise's lifespan more than distribution friction.

Steelman: A mandatory client is the only viable mechanism to enforce integrity and deliver patches in a physical-media era, creating a defensible moat that later monetizes via a platform.

**Blockers:** NONE. The proposal acknowledges constraints (broadband, retail friction) but treats them as adoption hurdles, not logical impossibilities. In 2003, broadband is growing; the alternative (dead games due to cheats) guarantees failure regardless of distribution channel.

**Risks:**
1.  **Retail Revolt:** Partners may drop boxed SKUs. *Mitigation:* The long-term value of a living game outweighs short-term shelf space loss; digital sales will eventually compensate.
2.  **User Friction:** Mandatory accounts/downloads annoy users. *Mitigation:* Cheating annoys them more; the "must-play" nature of popular titles forces compliance.
3.  **Execution Bug Risk:** Early client bugs could crater trust. *Mitigation:* This is an execution risk, not a strategic blocker; rigorous testing is required, but the strategy remains sound.
4.  **Competitor Copying:** Others may build similar clients. *Mitigation:* First-mover advantage with an existing hit franchise creates a network effect that is hard to dislodge.

**Pre-mortem:** The project fails if the client is so unstable at launch that it prevents legitimate players from accessing the game they bought, causing a PR firestorm before the anti-cheat benefits are felt.

**Kill Criteria:** If the client cannot support 99% uptime for legitimate users within the first 30 days, or if cheat detection false positives exceed 1%, the rollout must pause for remediation.

**Leading Metric:** Percentage of active unique users successfully updating and playing via the client within 60 days of launch. Review date: 90 days post-launch.

The proposal correctly identifies that controlling the software environment is existential for a multiplayer-focused developer. The risks are manageable operational challenges, not strategic deal-breakers. The potential upside (a persistent platform) transforms the business model from one-off sales to recurring engagement.

DECISION: GO
