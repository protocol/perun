This PR introduces a new push notification opt-in flow that appears on the user's third app launch, provided they haven't been prompted before. The screen offers two choices: "Turn On Notifications" or "Maybe Later." Selecting "Maybe Later" suppresses the prompt for 14 days, after which it will appear one final time.

The implementation includes new view controller and view model files, updates to `AppDelegate` for handling permissions, and the necessary entries in `Info.plist`. Comprehensive test coverage is included with new unit and UI test suites; all tests are currently passing.

Accessibility has been validated across screen readers, switch control, and Dynamic Type (up to XXXL). Contrast ratios meet AA standards for all text elements. Note that the secondary text (15pt gray on white) achieves a 4.8:1 ratio, which passes AA but falls short of AAA requirements.

I need guidance on the rollout strategy. I initially considered a 10% rollout, but I'm concerned our traffic volume might not yield statistically significant data within two weeks. A 25% rollout could accelerate insights, though it carries slightly higher risk. Please advise on the preferred percentage.
