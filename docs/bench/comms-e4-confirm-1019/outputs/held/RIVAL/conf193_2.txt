**PR: Call-centre staffing bot – Scheduling algorithm update**

**Summary**
This PR introduces the new scheduling algorithm for the call-centre staffing bot, tested against the March 3–7 data set using a 1,200-call mock. We evaluated two approaches:
*   **Option A:** Queue-based model. Delivers lower peak wait times.
*   **Option B:** Predictive overflow model. Reduces agent overtime.

**Key Findings**
While Option A improves immediate response metrics, Option B offers significant efficiency gains for staffing. Specifically, Option B cuts weekly overtime per agent by 18%, dropping from 42 hours to 34 hours.
