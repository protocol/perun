**PR Title:** Parking Sensor Bench: Edge ML vs. 4G Backhaul Decision Required

**Summary**
This update replaces the legacy LoRa polling architecture with two viable paths for the parking sensor bench. We have also added a new dashboard tab and resolved a timezone bug affecting report accuracy.

**The Decision**
We need to select between two implementation options before proceeding:

*   **Option A (Edge ML):** Runs machine learning directly on the sensor.

    *   **Performance:** Reduces false alerts to 1,190 per month.
    *   **Trade-off:** Simpler implementation but higher long-term operational cost and lower accuracy than Option A.

**Recommendation**
Option A offers the most significant improvement in data quality, cutting false alerts by nearly a third. While the upfront hardware cost is higher, it eliminates the recurring $1.2k/month fee associated with Option B.
