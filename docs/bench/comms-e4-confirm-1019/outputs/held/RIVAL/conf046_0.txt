**Title:** AGV Charging Scheduler: Dynamic Slot Allocation (Option A) vs. Fixed Heuristic (Option B)

**Summary**
This PR proposes switching the AGV charging scheduler from fixed slot scheduling (Option B) to dynamic slot allocation with predictive demand (Option A). While Option B is simpler, Option A reduces average charging wait times from 14 minutes to 9 minutes and cuts total daily idle charger time by 18%.

**Key Metrics & Benchmarks**
*   **Wait Time:** Option A reduces average wait from 14m to 9m.
*   **Efficiency:** Option A reduces daily idle charger time by 18%.
*   **Load Testing:** Test suite passed for both approaches. Benchmark results for 10k and 20k order volumes are included in the attached logs.

**Dependencies & Constraints**
*   **Telemetry:** Option A requires the new telemetry feed (v2.1), which is currently deployed in staging.
*   **Hardware:** Note that chargers 12–14 are offline until 5 Oct due to maintenance. This constraint is external to this code change but impacts overall capacity planning.

**Rollback Plan**
If Option A exhibits instability in production, we will revert to Option B (fixed slot scheduling) immediately. The configuration flag allows for an instant switch without redeployment.
