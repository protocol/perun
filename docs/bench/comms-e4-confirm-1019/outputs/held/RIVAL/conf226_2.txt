## PR Description: Demand-Sensing Model Implementation

This PR introduces the new demand-sensing model with two implementation paths for evaluation:

**Option A (Recommended):** Rolling 28-day window using exponential smoothing.
**Option B:** 90-day seasonal baseline using regression.

### Performance Comparison
Testing against the last three months of data shows Option A reduces MAPE from 8.4% to 6.1%, while Option B achieves 7.2%. The pilot covers 214 SKUs.

### Operational Considerations
Option A requires weekly retraining at approximately $1.2K per run. Option B runs monthly, offering lower operational costs but reduced accuracy.
