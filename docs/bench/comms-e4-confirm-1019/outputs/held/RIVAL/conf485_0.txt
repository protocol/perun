**PR: Night-time humidity setpoint strategy (East Side trial)**

This PR proposes a change to the night-time humidity control logic based on March trial data from the East Side greenhouse. The diff touches 14 files, though only 3 contain actual logic changes; the remainder are configuration updates and test fixtures.

We are deciding between two approaches for the setpoint:

*   **Option A:** Retain the current dew-point threshold of 12.5°C. This approach is simpler but resulted in condensation issues on February 14 and February 22.
*   **Option B:** Shift to a relative-humidity cap of 85%. March sensor data indicates this would reduce fan runtime by 18% (dropping from 6.2 to 5.1 hours/day on average). However, it requires 9% more energy for active dehumidification.

Please review the trade-off between fan wear (Option B) versus energy efficiency and simplicity (Option A) and approve the preferred approach. Note that the $4,300 budget required for sensor recalibration is still pending approval and is not included in this PR.

We need a decision by Thursday, March 28, to finalize the deployment schedule.
