We need to select an approach for the fleet depot bidirectional charging rollout to meet the grid operator's connection study deadline on April 22.

**The Constraint**
Nightly charging demand is 3.1 MWh for 40 buses. Our existing grid connection caps at 2.4 MW, creating a shortfall if we rely solely on grid power during peak windows.

**The Options**
*   **Approach A:** Retain the existing 2.4 MW grid connection and install a 1.2 MWh battery system. The battery bridges the gap between grid capacity and the 3.1 MWh demand.
*   **Approach B:** Upgrade the transformer to handle the full load immediately, eliminating the need for a battery. Estimated cost is $180k.

**Recommendation: Approach A (Battery Integration)**
I recommend proceeding with Approach A. While Approach B offers a simpler infrastructure profile, Approach A aligns better with our strategic goals and financial constraints:

1.  **Funding Eligibility:** The CFO confirmed we can access the EV incentive fund, but the application deadline is May 5. Battery storage systems typically qualify for these specific grants, whereas a standard transformer upgrade often does not. Securing this funding could offset the battery cost, making Approach A financially superior to the $180k upfront spend for Option B.
2.  **Operational Resilience:** Adding storage provides buffer capacity beyond just nightly charging. It allows for load shaving during peak tariff hours and offers backup power capability, which a direct grid upgrade cannot provide.
3.  **Driver Workflow:** The depot manager noted drivers prefer slow-charging profiles. A battery-assisted system facilitates controlled, slower charging rates without risking grid overloads, directly supporting this operational preference.
