**PR: Night-time humidity setpoint strategy (East Side trial)**

This PR proposes a change to the night-time humidity control logic based on March trial data from the East Side greenhouse. The diff touches 14 files, though only 3 contain actual logic changes; the rest are configuration and test updates.

We are deciding between two approaches for the setpoint:

*   **Option A:** Maintain the current dew-point threshold of 12.5°C. This is simpler to implement but previously resulted in condensation issues on February 14 and 22.
*   **Option B:** Shift to a relative-humidity cap of 85%. March sensor data indicates this would reduce fan runtime by 18% (dropping from 6.2 to 5.1 hours/day on average). However, it requires 9% more energy for active dehumidification.

Please review the trade-off between reduced fan wear (Option B) versus lower dehumidification energy costs and implementation simplicity (Option A). Note that the $4,300 budget required for sensor recalibration is still pending approval and is not included in this PR.

We need a decision on which approach to merge by Thursday, March 28. Please approve the PR with your preferred option or request changes if further analysis is needed.
