**PR: Parking Sensor Bench – Edge ML vs. 4G Backhaul Decision**

**Summary**
This PR replaces the legacy LoRa polling architecture with two proposed options to reduce false alerts. It also introduces a new dashboard tab and resolves a reported timezone bug.

**The Decision**
We need to select one of the following approaches for deployment across three sites:

*   **Option A: Edge ML (Sensor-side processing)**
    *   **Cost:** +$12k for compute hardware per site. Vendor quote totals $47.5k for all three sites (includes training).
    *   **Performance:** Reduces false alerts by 31% (from 1,400/mo to 968/mo).
    *   **Trade-off:** Adds 15ms latency.
*   **Option B: Central Server (4G backhaul)**
    *   **Cost:** $8k network kit per site + $1.2k/mo ongoing per site.
    *   **Performance:** Reduces false alerts to 1,190/mo.
    *   **Trade-off:** Simpler implementation, but lower accuracy than Option A.

**Recommendation**
Option A offers the most significant operational improvement with a 31% reduction in false alerts, though it requires higher upfront capital. Option B lowers initial hardware costs but incurs recurring monthly fees and delivers fewer accuracy gains.
