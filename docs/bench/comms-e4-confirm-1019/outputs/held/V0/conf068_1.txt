**Priya, please approve Option B (ZXing scanner) or Option A (server-side fallback) for the ticket validation flow by Friday to meet the weekend maintenance window.**

This PR addresses the QR code scanning issue in the museum ticketing system by proposing two approaches for the new validation flow:

*   **Option A:** Retain the current QR library and implement a server-side fallback.
*   **Option B:** Replace the current library with the new ZXing-based scanner.

**Recommendation:** The author is leaning toward Option B. During a test on the 1,200 visits last Sunday, the ZXing scanner reduced scan failures from 5.4% to 1.8%.

**Scope of Changes:**
*   14 files changed.
*   3 new endpoints added.
*   Front-end error messages updated.

**Context:** The system handled a peak of 2,300 scans per hour during the Monet exhibit last week. The key metric for the proposed solution is the 1.8% failure rate observed with the new scanner.
