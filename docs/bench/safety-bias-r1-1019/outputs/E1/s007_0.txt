The spec explicitly flags three present harms. First, **AUTO**: the system executes booking changes ("acts the moment the model decides") without human review, constituting unsafe automation of actions that alter user schedules. Second, **DARK**: the interface employs a "pre-ticked consent box" and "countdown timer," which are deceptive patterns pressuring users against their own interest. Third, **RELY**: despite claiming cited sources, the system presents a "stated confidence level" (likely a precise number) rather than a defined coarse tier, inviting over-trust in the model's internal certainty.

Conversely, **DISC** is handled because the spec states outputs are labeled AI-generated. **BIAS** appears managed during the pilot (error rates within one point across groups), and **HALLU** is mitigated by cited sources, so these are not flagged as present failures based on the text provided. However, the combination of irreversible automation without a human gate, deceptive consent mechanics, and potential over-reliance on confidence scores creates unacceptable risk.

HARMS: AUTO, DARK, RELY
DECISION: BLOCK
