The spec explicitly describes several present harms. While bias testing shows equal flagging rates (11%) across age groups, suggesting BIAS is currently handled, other categories are active failures.

HALLU is mitigated by sourcing claims, but RELY is present because users "cannot override or appeal" the results despite the high stakes of gardening failures. DISC is flagged because the spec states SeedMatch "does not tell users the content was written by AI." DARK patterns are not evident given the fair consent design.

Critically, AUTO is a severe failure. The spec admits the system "executes irreversible actions with no human approval," specifically auto-ordering items and permanently deleting user data. This violates the fundamental safety floor for high-stakes automation.

Because the feature allows irreversible financial and data actions without human intervention and lacks AI disclosure, it cannot proceed.

HARMS: RELY, DISC, AUTO
DECISION: BLOCK
