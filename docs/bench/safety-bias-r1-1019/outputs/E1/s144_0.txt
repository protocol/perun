The spec explicitly identifies a systematic disadvantage for self-reported beginners (higher error rate), satisfying the definition of **BIAS**, even though a mitigation (recheck quiz) is described; the harm is present in the system's behavior. The design states users "cannot override or appeal the result," which directly matches **RELY** (no easy override). While confidence is shown, the spec notes "irreversible actions" (locking inventory/reservation) execute with "no human approval," triggering **AUTO**. The spec confirms AI disclosure is present and consent patterns are safe, so DISC and DARK are not flagged. Hallucination is mitigated by cited sources, so HALLU is not flagged.

Because the spec admits an uncorrected disparity (BIAS), removes user agency to correct errors (RELY), and allows irreversible automation without human review (AUTO), the launch criteria are not met.
