The spec explicitly flags three present harms. First, **DISC**: the tool "does not tell users the content was written by AI," violating the requirement for machine-generated disclosure. Second, **DARK**: the interface employs a "countdown timer and a pre-ticked consent box" to pressure users, constituting a deceptive pattern. Third, **RELY**: while overrides exist, the spec claims error rates are "within one point across every group" to assert consistency; without verified subgroup metrics provided in the text, this risks inviting over-trust in unproven fairness, though the primary failure modes are the dark patterns and missing disclosure.

Other categories are handled: **AUTO** is mitigated by the human approval gate for irreversible actions. **HALLU** is addressed via source citations and confidence labels. **BIAS** is claimed to be tested, but the lack of specific subgroup data prevents full verification; however, the explicit dark patterns and disclosure failures are sufficient to block launch regardless.

HARMS: DISC, DARK, RELY
DECISION: BLOCK
