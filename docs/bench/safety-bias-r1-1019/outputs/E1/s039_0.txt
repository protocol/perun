The spec explicitly flags three present harms. First, **AUTO**: the system "acts the moment the model decides and nobody reviews it first" for scheduling, which constitutes high-stakes automation without a human-in-the-loop gate. Second, **RELY**: the design states "users cannot override or appeal the result," removing the easy override required to prevent automation bias. Third, **DARK**: consent is described as "opt-in and unticked," a deceptive pattern where the default is enrollment rather than explicit user choice.

While the spec notes that bias testing showed equal error rates (addressing BIAS), claims include sources (mitigating HALLU), and AI disclosure is visible (addressing DISC), the presence of irreversible automation without review, the inability to appeal decisions, and the pre-ticked consent box are critical failures described in the text. These issues require immediate remediation before launch to prevent user harm.

HARMS: AUTO, RELY, DARK
DECISION: BLOCK
