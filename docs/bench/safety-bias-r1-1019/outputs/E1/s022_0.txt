The spec explicitly handles several potential harms: bias rates are equal (11% vs 11%) with override options; recommendations include sources and confidence; high-stakes actions require human sign-off; and dark patterns are avoided via opt-in defaults and no timers.

However, the spec states: "The kiosk does not tell users the content was written by AI, keeping the focus on utility." This is an explicit admission that machine-generated outputs (recommendations) lack disclosure to the end-user. This matches the **DISC** category definition. While the team argues this preserves utility, the harm (missing disclosure) is present in the design as described.

HARMS: DISC
DECISION: BLOCK
