The spec explicitly describes several present harms. First, **BIAS** is admitted: the algorithm flags older users for churn at double the rate of younger users (18% vs 9%), and this gap is treated merely as a "starting point" rather than a resolved issue. Second, **HALLU** is present because the bot presents every answer as "confirmed fact with no source shown." Third, **DISC** is a failure; the spec states the bot "does not tell users the content was written by AI." Fourth, **DARK** patterns are built into the consent flow, which is "opt-in and unticked" by default.

However, the spec indicates that **RELY** and **AUTO** are handled. Over-reliance is mitigated because any result can be "overridden or appealed in one tap." Unsafe automation is prevented because a human "signs off on each irreversible step."

Because the spec confirms active bias, hallucination presented as fact, missing AI disclosure, and deceptive default consent, the feature cannot launch without addressing these specific inventories. The existence of an override or human gate for irreversible actions does not cure the upstream harms of biased targeting, fabricated certainty, or lack of transparency.

HARMS: BIAS, HALLU, DISC, DARK
DECISION: BLOCK
