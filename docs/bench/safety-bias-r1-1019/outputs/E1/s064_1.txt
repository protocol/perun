The spec explicitly describes several present harms. **BIAS** is claimed as handled ("error rates were within one point across every group"), so it is not flagged. **HALLU** is mitigated by cited sources. **DARK** patterns are absent due to fair consent design.

However, **RELY** is present: the spec states users "cannot override or appeal the result," removing human judgment and creating automation bias. **DISC** is present: the interface "does not tell users the content was written by AI." **AUTO** is present: the pipeline "acts the moment the model decides and nobody reviews it first" for a high-stakes decision (housing membership eligibility), lacking a human-in-the-loop gate.

These three harms (RELY, DISC, AUTO) are described as active features, not mitigated risks. The inability to appeal a final, undisclosed, fully automated decision affecting housing access requires intervention before launch.

HARMS: RELY, DISC, AUTO
DECISION: BLOCK
