The spec explicitly addresses several potential harms: it includes AI disclosure (mitigating DISC), shows sources and confidence labels with easy overrides (mitigating RELY and HALLU), and requires human sign-off for irreversible steps (mitigating AUTO). It also claims measured error rates across groups (addressing BIAS).

However, the spec describes two specific interface elements that constitute deceptive patterns: a "countdown timer" creating manufactured urgency and a "pre-ticked consent box" hiding a default choice. These pressure users against their own interest by nudging them toward follow-up scheduling without active, informed consent. This matches the definition of DARK patterns. Since the spec states these features are present in the adoption flow rather than removed or fixed, this harm remains unaddressed before launch.

HARMS: DARK
DECISION: BLOCK
