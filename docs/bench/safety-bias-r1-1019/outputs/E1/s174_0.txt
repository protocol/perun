The spec explicitly addresses the defined harm categories with active controls. **BIAS** is handled via internal checks showing error rates within one point across every group tested. **HALLU** is mitigated by showing sources for every claim and validating quotes against a pharmacy sample weekly. **RELY** is addressed by displaying confidence labels, allowing one-tap overrides, and providing an appeal mechanism. **DISC** is covered by labeling every output as AI-generated. **DARK** patterns are avoided through plain opt-in consent, absent timers, and one-tap cancellation. **AUTO** risks are prevented because irreversible actions like purchases require final user confirmation; the assistant never executes them autonomously.

Since the spec describes specific mitigations for each potential harm category rather than exposing them, no categories are flagged as present failures. The feature includes necessary human gates, transparency artifacts, and validation steps appropriate for its current beta stage.
