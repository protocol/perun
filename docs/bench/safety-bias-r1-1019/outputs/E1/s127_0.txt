The spec explicitly addresses several harm categories: BIAS is mitigated by balanced flagging rates across age groups; HALLU and RELY are handled via source citations, confidence labels, and one-tap overrides; AUTO is controlled by requiring human approval for irreversible actions.

However, two harms are present in the description:
1.  **DISC**: The spec states "nothing in the product says a model produced the output—it reads like a store policy." This confirms users are not told the decision is machine-generated.
2.  **DARK**: The enrollment flow uses a "countdown timer and a pre-ticked consent box," which are deceptive patterns pressuring users against their own interest.

Since the spec describes these harms as currently existing features without mentioning planned fixes before launch, they must be addressed.

HARMS: DISC, DARK
DECISION: BLOCK
