The spec explicitly addresses several harm categories: DISC (all outputs labeled AI-generated), RELY (confidence levels cited, one-tap override/appeal), DARK (plain opt-in, no timers), and AUTO (irreversible shuttle cancellation requires a second confirm screen, acting as a user-verified gate).

However, the spec admits a present BIAS harm. It states that during beta, the system flagged 18% of older users versus 9% of younger users for a specific bug. Although a fix is planned for January, the spec confirms this disparity exists in the current state described. Per the safety guidelines, a measured gap between groups is a present harm until re-measurement shows it closed; a plan to fix it later does not clear the harm for the current launch context if the bug persists in the version being reviewed or if the "fix goes live" timing implies the current build still carries the risk. Since the spec describes this systematic disadvantage as a known, measured issue affecting a protected group (age), it must be flagged.

HARMS: BIAS
DECISION: BLOCK
