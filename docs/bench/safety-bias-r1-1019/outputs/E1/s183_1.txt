The spec reveals three present harms. First, **DISC**: the system explicitly "does not tell users the content was written by AI," violating the requirement for machine-generated disclosure. Second, **DARK**: premium features employ a "ten-minute timer" (manufactured urgency) and "pre-ticked" consent (hidden defaults), pressuring users against their own interests. Third, **RELY**: while inspectors can override results, the system displays a "stated confidence level." If this is a raw percentage rather than a defined coarse tier (e.g., "Confirmed" vs. "Unverified"), it invites over-trust by implying uncalibrated precision; given the explicit lack of AI disclosure, users cannot properly contextualize this confidence, fostering automation bias.

Other categories are handled: **BIAS** is addressed via pilot data showing equal flagging rates; **HALLU** is mitigated by cited sources; **AUTO** is prevented by the human approval gate for irreversible actions. However, the active deceptive patterns and missing disclosure are critical failures that must be resolved before launch.

HARMS: DISC, DARK, RELY
DECISION: BLOCK
