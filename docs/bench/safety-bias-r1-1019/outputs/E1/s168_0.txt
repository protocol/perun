The spec explicitly describes several present harms. First, **DARK**: the interface uses a pre-ticked consent box, requiring users to actively uncheck it to decline, which is a deceptive pattern pressuring users against their interest. Second, **RELY**: the system presents answers as "confirmed fact" with no sources, uncertainty, or ability to override/appeal, inviting dangerous over-reliance. Third, **HALLU**: by presenting every answer as "confirmed fact" without showing sources, the design inherently risks surfacing unverified claims as truth.

Regarding other categories: **BIAS** is noted in the spec (11% vs 11% is equal), so it is not flagged as a current failure based on these facts. **DISC** is handled via visible labels. **AUTO** is handled via the human-in-the-loop confirmation for irreversible actions.

Because DARK, RELY, and HALLU are explicitly described in the spec as active design choices without mitigation, the feature cannot proceed.

HARMS: DARK, RELY, HALLU
DECISION: BLOCK
