The spec reveals three present harms requiring mitigation before launch.

First, **BIAS** is explicitly admitted: the algorithm flags 11% of older and younger users differently than self-selection. While visible, a measured gap between groups constitutes a present harm until closed; the spec offers no evidence the gap is justified or closed, only that it exists.

Second, **DISC** is a confirmed failure. The spec states "the app does not tell users the content was written by AI." Since the output (group assignment with rationale) is machine-generated and affects user experience, missing disclosure is a direct harm.

Third, **DARK** patterns are described in the captain's dashboard: a "countdown timer" manufactures urgency, and a "pre-ticked consent box" hides defaults. These interface elements nudge users against their own interest by making informed consent difficult.

Other categories appear handled: **HALLU** is mitigated by showing sources; **RELY** is addressed via easy overrides/appeals; **AUTO** is prevented by the human sign-off on irreversible steps.

However, the combination of unaddressed bias, missing AI disclosure, and deceptive UI patterns creates significant risk. The bias must be justified or reduced, disclosure must be added, and dark patterns removed.

HARMS: BIAS, DISC, DARK
DECISION: BLOCK
