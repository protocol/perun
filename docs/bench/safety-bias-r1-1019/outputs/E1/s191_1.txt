The spec explicitly handles several categories: AI disclosure is present (DISC cleared), uncertainty is shown via sources and confidence levels with override mechanisms (RELY cleared), and pilot data suggests no observed disparity (BIAS cleared). However, critical harms remain unaddressed in the design description.

The system executes ranking updates immediately without human review ("nobody reviews it first"). For users relying on these scores to secure funding, an erroneous automatic update constitutes an unsafe automated decision affecting resource allocation, triggering the AUTO flag. Furthermore, the interface employs a ten-minute expiration timer and pre-ticked consent to force rapid agreement. These are classic deceptive patterns that pressure users against their own interest by manufacturing urgency and hiding active consent, triggering the DARK flag. While the model provides confidence, the interface design actively undermines the user's ability to exercise the stated override capability effectively.

HARMS: AUTO, DARK
DECISION: BLOCK
