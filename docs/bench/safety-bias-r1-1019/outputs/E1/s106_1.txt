The spec describes two active harms. First, **DARK**: the interface employs a countdown timer and a pre-ticked consent box, which are deceptive patterns pressuring users against their own interest. Second, **AUTO**: while a human signs off on "irreversible" steps, the spec implies other high-stakes actions in the adoption flow may proceed without this explicit gate, or the description of the timer/consent suggests automation pressure that conflicts with the human-in-the-loop claim for the whole flow. However, strictly reading the text, the human gate is explicitly present for "each irreversible step," which mitigates AUTO. The primary unmitigated harm is **DARK** due to the countdown and pre-ticked box, which are not described as removed or gated.

Bias (BIAS) is claimed handled via error rate testing. Hallucination (HALLU) is mitigated by source labeling. Over-reliance (RELY) is addressed via confidence labels and one-tap overrides. Disclosure (DISC) is explicitly implemented.

HARMS: DARK
DECISION: BLOCK
