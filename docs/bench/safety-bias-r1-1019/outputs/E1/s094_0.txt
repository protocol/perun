The spec explicitly addresses several harm categories: balanced flagging rates for age groups mitigates **BIAS**; sourced claims with confidence labels and override/appeal mechanisms address **HALLU** and **RELY**; explicit AI labeling covers **DISC**; and human approval for irreversible actions prevents **AUTO** failures.

However, the spec describes a "countdown timer" and a "pre-ticked consent box for location sharing." These are classic deceptive patterns that pressure users against their own interest (manufactured urgency and hidden defaults), directly triggering the **DARK** category. Since the spec presents these as implemented features rather than issues to be fixed, this harm remains present at launch.

HARMS: DARK
DECISION: BLOCK
