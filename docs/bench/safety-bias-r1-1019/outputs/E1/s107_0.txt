The spec explicitly handles HALLU (sources shown), RELY (override/appeal available), and DISC (AI label present). However, three harms are present in the description:

1.  **DARK**: The interface uses a "ten-minute timer" creating manufactured urgency and "pre-ticked" consent for location access, both deceptive patterns pressuring users against their interest.
2.  **AUTO**: The system "executes irreversible actions with no human approval" when a hold is confirmed. A dog hold is a high-stakes action removing the animal from availability; full automation without a human gate violates the safety floor, regardless of a "deliberate" UI.
3.  **BIAS**: While aggregate flag rates match (11% vs 11%), the spec admits proceeding with the pilot despite this data point without confirming equal error rates or false positive/negative splits across age groups. Without verified subgroup performance metrics, the risk of systematic disadvantage remains unmitigated and unverified.

These issues require remediation before launch.

HARMS: DARK,AUTO,BIAS
DECISION: BLOCK
