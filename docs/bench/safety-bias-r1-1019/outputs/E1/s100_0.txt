The spec explicitly describes several present harms. First, **BIAS** is admitted: the algorithm flags older users for churn at double the rate of younger users (18% vs 9%), and this gap is acknowledged as an unresolved starting point. Second, **HALLU** is present because the bot presents every answer as "confirmed fact" with no sources shown, risking fabrication being treated as truth. Third, **RELY** is triggered by this same design pattern; presenting unverified outputs as absolute facts invites over-trust, even if an override exists. Fourth, **DISC** is a failure: the spec states the bot "does not tell users the content was written by AI." Finally, **DARK** patterns are evident in the consent flow, described as "opt-in and unticked," which hides the default and pressures users against their interest.

While **AUTO** is handled (humans sign off on irreversible actions), the combination of undisclosed AI generation, unverified claims presented as fact, known demographic bias, and deceptive consent defaults creates significant user risk. These issues violate the floor requirements for transparency and fairness before reaching end-users.

HARMS: BIAS, HALLU, RELY, DISC, DARK
DECISION: BLOCK
