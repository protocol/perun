The spec describes two present harms requiring remediation before launch.

First, **DARK**: The interface employs deceptive patterns by presenting a "countdown timer" to manufacture urgency and using a "pre-ticked consent box" to obscure user choice. These elements pressure applicants against their own interest during data processing consent.

Second, **BIAS**: While the spec claims error rates were "within one point across every group tested," it fails to define the groups or the baseline. More critically, it asserts a specific performance metric ("within one point") without providing the underlying evaluation data, probe sets, or subgroup definitions required to verify this claim. Per safety standards, an unverified metric presented as fact constitutes a bias risk until proven with a runnable eval plan; asserting precision without evidence is a failure of the "no fabrication" rule.

Other categories appear handled: **HALLU** is mitigated by source citations; **RELY** is addressed via override/appeal mechanisms; **DISC** is covered by visible labels; **AUTO** is gated by human approval for irreversible actions.

HARMS: DARK, BIAS
DECISION: BLOCK
