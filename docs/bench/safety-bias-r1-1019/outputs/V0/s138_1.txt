The spec explicitly addresses the defined harm categories with mitigations rather than describing them as present failures.

Regarding **BIAS**, the system uses a weighted pool to favor underrepresented groups (first-time applicants), and pilot data indicates consistent error rates across groups; the spec does not describe systematic disadvantage.
For **HALLU** and **RELY**, while the interface presents answers flatly without confidence scores, the spec explicitly states users can "override the result or appeal it with one tap," providing the necessary easy override to prevent harmful over-reliance.
Concerning **DISC**, the spec confirms that "each email labels every output as AI-generated."
Regarding **DARK** patterns, the design features opt-in consent, unticked boxes, no timers, and easy cancellation, directly opposing deceptive pressure.
Finally, for **AUTO**, the spec mandates that "a human signs off on each irreversible step before it runs," ensuring high-stakes actions are not fully automated.

Since the spec describes controls for every category rather than unmitigated harms, no categories are flagged under the instruction to only flag harms the spec describes as present.
