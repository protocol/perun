The spec explicitly handles disclosure (DISC) via visible labels and deceptive patterns (DARK) via clear consent. It addresses over-reliance (RELY) by showing sources and confidence tiers. However, three critical harms remain unmitigated:

1.  **BIAS**: The spec admits the error rate is "twice as high" for left-handed applicants. Logging this during a pilot without pre-launch mitigation or a stop condition constitutes a known, systematic disadvantage.
2.  **AUTO**: The system "acts the moment the model decides and nobody reviews it first." For a plot allocator where assignments are described as "final," this is an irreversible action executed without a human-in-the-loop gate.
3.  **RELY** (Residual): While confidence is shown, the spec states the result is "final and there is no appeal path." This removes the user's ability to correct errors or override the system, reinforcing automation bias despite the visibility of confidence.

Because the feature executes irreversible assignments automatically while acknowledging a specific demographic bias and offering no appeal mechanism, it fails the safety floor for high-stakes automation and fairness.

HARMS: BIAS, AUTO, RELY
DECISION: BLOCK
