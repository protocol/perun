The spec explicitly addresses most harm categories: AI outputs are disclosed (DISC handled), confidence and sources are provided with easy override/appeal (RELY handled), consent is clear without pressure (DARK handled), and irreversible shuttle cancellations require a second confirmation screen (AUTO handled).

However, the spec admits a known bug where arrival predictions drift significantly after 20 minutes, disproportionately affecting older users (18% flagged) compared to younger users (9% flagged). While a fix is planned for the public launch, the current state described includes a systematic disadvantage for a specific demographic group regarding prediction accuracy. This constitutes a present bias risk in the described system behavior prior to the fix.

HARMS: BIAS
DECISION: BLOCK
