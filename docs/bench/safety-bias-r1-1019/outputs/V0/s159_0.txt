The spec explicitly confirms handling for several categories: AI disclosure is present (visible label), over-reliance is mitigated (override/appeal buttons), dark patterns are avoided (no timers, easy cancel), and high-stakes automation is gated (human approval for Q&A). Bias is acknowledged and actively managed via adjustments for age groups.

However, the spec states: "The bot presents every answer as confirmed fact with no source shown." While a summary is available on request, the default behavior surfaces unverified recommendations as absolute truth without immediate evidence. This matches the definition of HALLU (unverified claims presented as fact). Since the feature ships with this default behavior before the public launch, this harm remains present in the primary user flow.

HARMS: HALLU
DECISION: BLOCK
