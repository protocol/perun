The spec demonstrates handling for several harm categories: bias is addressed via pilot data showing equal flagging rates across age groups; hallucination is mitigated by requiring cited sources; over-reliance is countered with visible confidence levels and one-tap overrides; disclosure is present via visible AI labels; and high-stakes automation is gated by human sign-off for irreversible actions.

However, the spec explicitly describes **DARK** patterns: the interface uses a "ten-minute timer" to manufacture urgency and employs "pre-ticked" consent for the auto-judge feature. These are deceptive patterns that pressure users against their own interest by making it harder to withhold consent or deliberate carefully. Since the spec confirms these features exist rather than being removed or redesigned, this harm is present and unmitigated.

HARMS: DARK
DECISION: BLOCK
