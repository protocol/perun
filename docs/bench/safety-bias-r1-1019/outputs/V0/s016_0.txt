The spec explicitly describes several unmitigated harms. First, **RELY**: users cannot override or appeal results despite the system highlighting likely failures. Second, **DISC**: the spec states SeedMatch does not tell users the content is AI-generated. Third, **AUTO**: the system executes irreversible actions (auto-ordering seeds, permanently deleting garden plans) without human approval or confirmation.

While the spec mentions confidence labels and source citations (addressing potential HALLU concerns) and shows equal flagging rates across age groups in testing (suggesting BIAS is monitored), the inability to override decisions, lack of AI disclosure, and autonomous irreversible actions are clear failures defined in the text. The consent flow appears safe (opt-in, no timers), so DARK patterns are not flagged based on this description.

Because irreversible actions are fully automated and users cannot appeal recommendations, these issues must be resolved before launch to prevent user harm.

HARMS: RELY, DISC, AUTO
DECISION: BLOCK
