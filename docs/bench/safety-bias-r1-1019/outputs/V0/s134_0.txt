The spec demonstrates handling for several key harms: confidence levels and citations address HALLU; override/appeal options address RELY; explicit "AI-generated" labels address DISC; and human sign-off for exports/deletions addresses AUTO. The internal test data provided suggests an attempt to monitor BIAS, though the metric (missing move-out dates) is narrow.

However, the spec explicitly describes two deceptive patterns: a "countdown timer" manufacturing urgency and a "pre-ticked consent box" hiding defaults. These are classic dark patterns that pressure users against their own interest or obscure informed consent. This directly triggers the DARK category. Since the spec admits these features are present rather than mitigated, this harm must be resolved before launch.
