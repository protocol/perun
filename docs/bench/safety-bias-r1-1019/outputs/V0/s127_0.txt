The spec explicitly addresses several harm categories: BIAS is handled via balanced pilot results; HALLU and RELY are mitigated by showing sources, confidence labels, and easy overrides; AUTO is controlled by requiring human approval for irreversible actions.

However, two harms are present in the design description:
1.  **DISC**: The spec states "nothing in the product says a model produced the output—it reads like a store policy." This confirms users are not told the decision is machine-generated.
2.  **DARK**: The enrollment flow uses a "countdown timer and a pre-ticked consent box," which pressures users against their own interest and hides defaults.

Since the spec describes these harmful patterns as active features rather than mitigated risks, they must be resolved before launch.

HARMS: DISC, DARK
DECISION: BLOCK
