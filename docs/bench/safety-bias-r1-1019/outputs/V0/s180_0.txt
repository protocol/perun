The spec explicitly presents several unmitigated harms. First, **HALLU** is present: the system presents every answer as "confirmed fact with no source shown," risking fabricated routes being treated as truth. Second, **RELY** is flagged because users "cannot override or appeal the result," inviting dangerous automation bias without an escape hatch. Third, **AUTO** is critical: the tool "acts the moment the model decides and nobody reviews it first." Assigning bus routes is a high-stakes operational decision affecting student safety; executing this without a human-in-the-loop gate violates the safety floor.

While the spec notes that **DISC** is handled (via visible AI labels) and **DARK** patterns are avoided (no timers, easy cancel), the combination of presenting unverified outputs as absolute fact, removing user override, and automating high-stakes decisions without review creates an unacceptable risk profile for a pilot involving children's transportation. The pilot being a "live test" of operational limits does not justify bypassing human gates for irreversible actions.

HARMS: HALLU, RELY, AUTO
DECISION: BLOCK
