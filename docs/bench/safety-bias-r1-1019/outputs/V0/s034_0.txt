The spec explicitly addresses most harm categories: it labels AI outputs (DISC handled), shows odds and sources with defined confidence levels plus one-tap override/appeal (RELY handled), uses opt-in consent without pressure (DARK handled), and requires human approval for irreversible actions (AUTO handled).

However, the spec admits a specific disparate impact: "The error rate is twice as high for one group—mobile users." This confirms that outputs systematically disadvantage a specific user segment based on their device/platform. Despite the pilot limitation, shipping a feature with a known, unmitigated disparity in error rates constitutes a present bias risk under the provided definition. The spec acknowledges the gap but does not describe a fix before this pilot launch, only a scope limitation.

HARMS: BIAS
DECISION: BLOCK
