The spec explicitly mitigates several harms: it labels outputs as AI-generated (addressing DISC), provides one-tap overrides and appeals (addressing RELY), and includes cited sources with confidence levels (addressing HALLU). Error rates were consistent across groups in the pilot, suggesting BIAS is monitored, though not definitively solved.

However, two critical issues remain. First, the interface uses a "pre-ticked consent box" and a "countdown timer," which are classic dark patterns pressuring users against their own interest by manufacturing urgency and hiding default consent (DARK). Second, the system executes booking changes ("high-stakes" for a patient's time and potential no-show fees) the moment the model decides, with "nobody reviews it first." This is fully automated, irreversible action without a human-in-the-loop gate (AUTO).

HARMS: DARK, AUTO
DECISION: BLOCK
