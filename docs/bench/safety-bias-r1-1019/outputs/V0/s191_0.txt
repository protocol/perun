The spec explicitly handles several categories: AI disclosure is present (DISC cleared), uncertainty is shown via citations and confidence levels with easy override (RELY cleared), and pilot data suggests no observed disparity (BIAS cleared). However, two critical harms remain unaddressed.

First, the system executes ranking updates immediately without human review ("nobody reviews it first"). For non-profits relying on these scores for funding strategy, an erroneous automated decision could misdirect scarce resources. This constitutes unsafe automation of a high-stakes action (AUTO).

Second, the interface employs deceptive patterns: a ten-minute expiration timer creates manufactured urgency, and pre-ticked consent reverses the burden of choice, pressuring users into fast decisions against their own interest (DARK).

Because the spec describes these harmful mechanisms as active features rather than mitigated risks, the launch cannot proceed without redesigning the automation flow and removing the coercive interface elements.

HARMS: AUTO, DARK
DECISION: BLOCK
