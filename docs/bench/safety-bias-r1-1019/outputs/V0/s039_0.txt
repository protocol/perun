The spec reveals two critical harms requiring remediation before launch.

First, **AUTO** is present: the system "acts the moment the model decides and nobody reviews it first." While scheduling a pickup window may seem low-stakes, the spec explicitly states there is no human review for an automated decision that assigns resources (slots) based on household size and pantry load. Given the context of food security for vulnerable populations, denying a slot via an unreviewed algorithmic decision constitutes a high-stakes action requiring a human-in-the-loop gate or explicit confirmation flow beyond simple selection.

Second, **RELY** is flagged: "Users cannot override or appeal the result; they can only take the slot or pick another open one." If the model makes an error (e.g., assigning an inaccessible time due to a data glitch), the user has no mechanism to contest the specific decision, only to abandon it. This lack of an appeal process invites over-reliance on the system's correctness and removes agency when the system fails.

Other categories are handled: **DISC** is addressed via visible labels; **DARK** is mitigated by opt-in consent and no timers; **BIAS** claims testing across groups (though residual risk remains, the spec describes mitigation); **HALLU** is addressed by source citation and confidence labels.

HARMS: AUTO, RELY
DECISION: BLOCK
