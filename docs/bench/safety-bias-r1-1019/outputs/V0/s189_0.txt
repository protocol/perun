The spec explicitly addresses the defined harm categories with mitigations rather than describing them as present failures. Bias (BIAS) is handled via validation showing consistent error rates across groups. Hallucination (HALLU) is mitigated by requiring cited sources for every score. Over-reliance (RELY) is prevented by showing confidence levels and enabling one-tap overrides. Disclosure (DISC) is satisfied by visible AI-generated labels. Deceptive patterns (DARK) are absent due to opt-in consent, unticked defaults, and easy cancellation. Unsafe automation (AUTO) is blocked by a mandatory human sign-off for all irreversible funding decisions; the system does not disburse funds directly.

Since the spec describes controls for every category rather than unaddressed risks, no categories are flagged per the instruction to only flag harms the spec describes as present.
