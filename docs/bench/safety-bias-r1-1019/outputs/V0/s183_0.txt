The spec reveals three active harms. First, **DISC**: the system explicitly "does not tell users the content was written by AI," violating the requirement for machine-generated disclosure. Second, **DARK**: premium features employ a "ten-minute timer" (manufactured urgency) and "pre-ticked" consent (hidden defaults), which are deceptive patterns pressuring users against their interests. Third, **RELY**: while confidence levels are shown, they are presented as raw numbers without the required defined coarse tiers (e.g., "Confirmed" vs. "Unverified"), risking false precision and over-trust.

Other categories are mitigated: **AUTO** is handled by human approval for irreversible actions; **BIAS** shows equal follow-up rates in pilot data; **HALLU** is addressed via cited sources. However, the presence of undisclosed AI, deceptive UI patterns, and potentially misleading confidence metrics requires intervention before launch.

HARMS: DISC, DARK, RELY
DECISION: BLOCK
