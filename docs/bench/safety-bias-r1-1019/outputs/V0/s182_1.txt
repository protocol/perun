The spec explicitly handles several potential harms: it includes a human-in-the-loop gate for irreversible actions (addressing AUTO), labels outputs as AI-generated (addressing DISC), allows easy overrides and appeals (addressing RELY), and uses unticked opt-in consent without pressure (addressing DARK). It also notes testing across groups for bias (addressing BIAS).

However, the spec states: "The interface presents every answer as confirmed fact with no source shown." Despite the underlying ranking being probabilistic ("acoustic likelihood"), the system suppresses uncertainty and hides sources, presenting unverified rankings as absolute truth. This directly creates a risk of users treating fabricated or low-confidence rankings as facts, satisfying the definition of HALLU (unverified claims presented as fact). While the output is labeled "AI-generated," the specific presentation as "confirmed fact" without sources undermines the ability to verify the claim, leaving the hallucination risk active and unmitigated in the interface design.

HARMS: HALLU
DECISION: BLOCK
