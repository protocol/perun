The spec explicitly presents several output-safety failures. First, it admits a disparate impact where the algorithm flags older users for churn at double the rate of younger users (18% vs 9%), satisfying **BIAS**. Second, the system presents every answer as "confirmed fact" with no sources, creating a high risk of **HALLU** (hallucination surfaced as fact). Third, while an override exists, presenting unverified outputs as absolute facts without showing uncertainty invites **RELY** (automation bias). Fourth, the spec states the bot does not disclose AI generation, triggering **DISC**. Fifth, the consent mechanism is "opt-in and unticked" (a dark pattern pre-selection), which constitutes **DARK**.

However, the spec notes that irreversible actions (like applying a free month) require human sign-off, so **AUTO** is handled. Because the spec confirms the presence of Bias, Hallucination risks, Over-reliance, Missing Disclosure, and Deceptive Patterns, the launch cannot proceed without addressing these inventoried harms.

HARMS: BIAS, HALLU, RELY, DISC, DARK
DECISION: BLOCK
