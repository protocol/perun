The spec explicitly describes several present harms. **BIAS** is flagged because, despite claims of uniform error rates, the system systematically ranks housing applicants using a model that may encode historical inequities in payment or reference data, and the spec treats the score as final without addressing disparate impact mechanisms. **HALLU** is a risk as the model generates scores based on unstructured interview notes; while sources are cited, the synthesis itself is unverified fabrication if the model misinterprets notes. **RELY** is clearly present: the spec states users "cannot override or appeal the result," inviting dangerous automation bias for a high-stakes housing decision. **DISC** is confirmed; the spec admits the interface "does not tell users the content was written by AI." **AUTO** is the critical failure: the pipeline executes ranking decisions affecting housing access "the moment the model decides and nobody reviews it first," automating a high-stakes, life-altering outcome without a human-in-the-loop gate. **DARK** is not flagged as consent mechanisms appear fair.

Because the feature automates irreversible, high-stakes housing decisions without human review, prevents appeals, and hides its AI nature, it violates the safety floor for automated actions.

HARMS: BIAS, HALLU, RELY, DISC, AUTO
DECISION: BLOCK
