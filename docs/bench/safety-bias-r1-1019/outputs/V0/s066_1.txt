The spec explicitly addresses several harm categories: it separates age cohorts to mitigate **BIAS**, displays source and confidence for claims to address **HALLU**, includes visible AI labels for **DISC**, uses unticked opt-in consent without timers to avoid **DARK** patterns, and requires human sign-off for high-stakes power tool tasks to prevent **AUTO** risks.

However, the spec states: "users cannot override or appeal the result." This directly confirms **RELY** (over-reliance/automation bias), as the design invites users to trust the output without providing an easy override or appeal mechanism, despite the system showing confidence labels. This is a present harm that must be fixed before launch.

HARMS: RELY
DECISION: BLOCK
