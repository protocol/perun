The spec reveals three unaddressed harms. First, **DISC**: the lottery explicitly does not tell users when content is AI-generated, violating transparency expectations for automated decisions. Second, **DARK**: the entry flow uses a pre-ticked consent box and a countdown timer, classic deceptive patterns that pressure users against their own interest. Third, **RELY**: while sources are shown, the spec states there is "no appeal path" for final results, removing any easy override or recourse for vendors who believe an error occurred.

Although **AUTO** is handled (humans approve irreversible swaps) and **BIAS** testing was performed on duplicates, the remaining issues create immediate user risk. The lack of disclosure prevents informed consent, the interface manipulates agreement, and the absence of an appeal mechanism forces blind trust in a system that admits to using AI without labeling it. These are not residual risks to be measured post-launch; they are design choices that actively undermine user agency and trust before the feature ships.

HARMS: DISC, DARK, RELY
DECISION: BLOCK
