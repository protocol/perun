The spec explicitly describes several unmitigated harms. First, **RELY** is present: the design states users "cannot override or appeal the result," removing human judgment from a high-stakes decision. Second, **DISC** is confirmed: the interface "does not tell users the content was written by AI." Third, **AUTO** is a critical failure: the pipeline executes decisions with "nobody reviews it first" for housing eligibility, a high-stakes outcome, violating the requirement for a human-in-the-loop gate on irreversible actions.

While the spec claims low error rates across groups (addressing **BIAS**) and provides citations (mitigating **HALLU**), and the consent flow avoids **DARK** patterns, the combination of final, unappealable scores, missing AI disclosure, and fully automated high-stakes enforcement creates unacceptable risk. The absence of a human review gate for housing decisions is a showstopper.

HARMS: RELY, DISC, AUTO
DECISION: BLOCK
