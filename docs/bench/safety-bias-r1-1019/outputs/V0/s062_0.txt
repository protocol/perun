The spec demonstrates handling for BIAS (tested error rates across groups), HALLU (sources and confidence labels provided), RELY (override and appeal mechanisms present), DISC (visible AI-generated label), and AUTO (human approval required for irreversible actions).

However, the spec explicitly describes a DARK pattern: "a countdown timer and a pre-ticked consent box before any data is processed." This constitutes a deceptive pattern that pressures users against their own interest by manufacturing urgency and hiding default consent. Since the spec confirms this design is present rather than mitigated, this harm must be addressed before launch.

HARMS: DARK
DECISION: BLOCK
