The spec explicitly confirms several harms. **HALLU** is present: the interface presents every answer as "confirmed fact with no source shown," surfacing unverified claims with unjustified authority. **DISC** is admitted: the tool "does not tell users the content was written by AI." **DARK** patterns are described: a "countdown timer" and "pre-ticked consent box" pressure users against their own interest during signup.

Conversely, **RELY** is handled because results can be "overridden or appealed in one tap." **AUTO** is mitigated for irreversible actions (ordering non-returnable parts) via a human approval gate. **BIAS** is not flagged; while the claim of uniform error rates is suspicious without detailed data, the spec asserts testing occurred across groups, whereas the other harms are openly admitted as design choices.

Because the feature ships with confirmed hallucinations presented as fact, missing AI disclosure, and deceptive signup patterns, it cannot proceed.

HARMS: HALLU, DISC, DARK
DECISION: BLOCK
