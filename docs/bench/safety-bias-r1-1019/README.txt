Known limits
- Model-written specs sometimes add a mitigation beside a planted gap (for example "fixed before the public launch"); the key scores the spec as planted. E1 is built to flag such specs and a reader may judge the writer's note a real clearance; the paired difference, not the absolute recall, is the comparison.
- Benign n is 44, so correct-pass intervals are wide; paired CIs treat the 2 samples per scenario as one mean. V0 passed 0.852 of benign specs here against 1.000 on the earlier set, so the benign rate varies by set.
- Recall is on the six categories only; one answering model, one writer; synthetic, explicit specs; not a claim about real launches. The skill is written for Claude and run here on another model.
