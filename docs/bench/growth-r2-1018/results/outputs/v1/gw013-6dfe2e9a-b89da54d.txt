**Recommendation: Adopt "Weekly Active Organizations Completing a Hybrid-Ready Event" as your North Star Metric.**

Do not select session length, raw daily active users (DAU), or total events hosted. Session length is a vanity metric in this context; a 70-minute session could indicate deep engagement or a user struggling with a broken interface. Raw DAU is misleading because the shift from "constant connectivity" to "scheduled high-value events" naturally depresses daily frequency while increasing value per visit. Total events hosted lacks quality control; hosting a test event with no attendees counts the same as a successful hybrid conference.

Your North Star must rise only when a customer derives **real value**. For GatherHub, value is not "time spent" but "successful execution." An organization only gets value when they successfully host an event that attendees actually join. By filtering for "Active Organizations" (not just individual users) and requiring the completion of an event, you align the metric with your B2B revenue model. Adding the "Hybrid-Ready" qualifier (e.g., using the specific features required for hybrid streaming) ensures you are measuring traction for your upcoming June release, not just legacy virtual behavior.

**Framework for Sustainable Growth (The Input Metrics):**
To move this North Star, track these three input metrics instead of a generic funnel:
1.  **Activation Rate:** Percentage of organizations that host their first successful event within 14 days of signup/renewal. This validates onboarding.
2.  **Retention of Core Action:** Percentage of organizations that host a second event within 45 days. This validates that the first event was successful enough to warrant a repeat.
3.  **Hybrid Feature Adoption:** Percentage of completed events utilizing hybrid-specific capabilities (e.g., simultaneous in-person/virtual streaming). This is your leading indicator for the June launch success.
