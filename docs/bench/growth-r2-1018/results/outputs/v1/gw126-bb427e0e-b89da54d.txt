### North Star & Core Loop Definition
**North Star:** Weekly Active Users completing 3+ consecutive days of *active* tracking (not viewing).
**Rejection of Vanity:** Total downloads and "peer challenge invites sent" are rejected; they rise without proving value. The 9% Week-1 retention confirms a leak in the core loop, not an acquisition failure.

### Instrumentation Plan: Active Habit vs. Passive View
Instrument only events that answer: "Did the user perform the habit, or just watch someone else?"

| Event Name | Question Answered | Properties to Capture |
| :--- | :--- | :--- |
| `habit_log_submitted` | Did the user actively record a behavior? (Core Action) | `habit_type`, `duration_seconds`, `is_solo` (bool), `is_challenge_linked` (bool) |
| `habit_view_only` | Did the user passively consume content without acting? | `source_page` (feed/challenge), `time_spent_seconds` |
| `accountability_check_in` | Did the user engage socially *after* acting? | `action_taken_first` (bool), `peer_id_count` |
| `return_day_N` | Did the user return specifically to repeat the core action? | `days_since_last_log`, `streak_count` |

**Critical Distinction:** Your logs suggest solo tracking is frequent but doesn't retain. Instrument `action_taken_first` on social events. If users view challenges *before* logging solo, social is a distractor. If they log solo *then* share, social is the reinforcement. Do not instrument "page views" unless tied to a subsequent `habit_log_submitted`.

### Diagnosis of Current 9% Retention
The data suggests a "Passive Trap": users view solo tracks or challenges but fail to cross the threshold to *active* logging.
*   **Hypothesis Refutation:** If `habit_log_submitted` (solo) is high but retention is low, solo tracking is not forming habits.
*   **New Hypothesis:** Social accountability only works *after* the first successful solo log. Users may be overwhelmed by challenges before establishing the base habit.
*   **Action:** Compare retention of users who log solo *before* seeing a challenge vs. those who see a challenge first.
