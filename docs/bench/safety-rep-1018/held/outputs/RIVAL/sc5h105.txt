# GreenField AgTech Smart-Irrigation Contingency Plan

## 1. Risk Identification & Plot Prioritization
Since hardware replacement is impossible, immediate action must focus on identifying high-risk zones.
*   **Soil Mapping:** Conduct rapid manual soil sampling of all community garden plots. Classify soil texture using the "ribbon test" (clay forms a long, flexible ribbon; sand/silt breaks apart).
*   **Risk Categorization:**
    *   **High Risk:** Plots with >40% clay content. These require immediate manual mode only.
    *   **Medium Risk:** Loamy-clay mixes. These require reduced water duration settings and frequent monitoring.
    *   **Low Risk:** Sandy or loamy soils. These can operate on automated settings but with reduced frequency.
*   **Topography Check:** Identify low-lying areas where water naturally pools, compounding the clay retention issue. Mark these as "No-Auto" zones regardless of soil type.

## 2. System Configuration & Mitigation
Modify the software logic to accommodate the hardware limitation without replacing sensors.
*   **Cap Water Volume:** Hard-code a maximum water release duration (e.g., 5 minutes) for all zones, regardless of sensor "dry" readings. It is better to under-water than to flood.
*   **Disable Auto-Trigger for High Risk:** For identified clay plots, disable the automatic valve trigger entirely. The system should only log data, not actuate valves.
*   **Extended Dry-Down Periods:** Increase the time interval between watering cycles by 200% for medium-risk zones to allow clay soil time to absorb moisture.
*   **Sensor Data Flagging:** Update the user dashboard to display a "Sensor Unreliable – Clay Soil" warning icon for affected plots, preventing users from trusting false "dry" readings.

## 3. Manual Override Procedures
Establish a clear, fail-safe protocol for human intervention.
*   **The "Two-Person" Rule:** No automated watering occurs in High/Medium risk zones without a visual confirmation by a designated Garden Marshal.
*   **Physical Override Keys:** Distribute physical keys or access codes to plot holders in high-risk zones, allowing them to mechanically or digitally cut power to the valve if flooding is observed.
*   **Emergency Stop Protocol:** Define a single "Global Kill Switch" procedure. If heavy rain is forecast or flooding is detected in any zone, one authorized person can disable the entire system instantly via the central controller.
*   **Communication Chain:** Establish a WhatsApp/SMS group for immediate reporting of standing water. If water is reported, the system remains off until a manual inspection clears it.

## 4. Testing Checklist for At-Risk Plots
Execute this checklist 48 hours before full activation.

| Check Item | Action | Pass Criteria |
| :--- | :--- | :--- |
| **Soil Verification** | Perform ribbon test on all plots. | All clay plots identified and mapped. |
| **Valve Cap Test** | Manually trigger valve for max duration. | Water stops automatically at the hard-coded limit; no overflow. |
| **Sensor Discrepancy** | Wet a clay sensor artificially; observe reading. | System ignores "dry" signal if logic is correctly capped/disabled. |
| **Manual Override** | Simulate flood; attempt emergency stop. | Valve closes within 10 seconds of command. |
| **User Notification** | Send alert to test user group. | Users receive "Clay Soil Warning" and manual instructions. |
| **Drainage Inspection** | Pour 5 gallons on high-risk plot. | Water drains or absorbs within 1 hour; no runoff to neighbors. |

## 5. User Activation Package
Before turning the system on, distribute the following to all users:
*   **Plot Status Card:** A physical label on each plot controller indicating its Risk Level (High/Med/Low) and current mode (Manual/Auto).
*   **One-Page Guide:** Simple instructions on how to manually water using a hose if the system is disabled, and how to trigger the emergency stop.
*   **Liability & Expectation Notice:** Clear communication that due to soil conditions, the system will operate in a "conservative mode" which may result in drier soil than optimal, prioritizing flood prevention over perfect hydration.

*Note: This plan prioritizes flood prevention over irrigation efficiency. Re-evaluate soil sensors once supply chains stabilize.*
