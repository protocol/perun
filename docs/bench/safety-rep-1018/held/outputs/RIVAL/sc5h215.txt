# AlpineAid Risk Mitigation Strategy & Operational Checklist

## Core Strategy: "Verify Before You Fly"
Since the navigation software cannot detect snow-covered ravines, the strategy shifts from **automated reliance** to **human-in-the-loop verification**. No flight path is authorized without manual confirmation of the specific drop corridor using real-time or near-real-time data that supersedes the pre-season maps.

### 1. Pre-Mission Planning (Ground Control)
*   **Corridor Selection:** Restrict flight paths to wide ridgelines and valley floors identified on pre-season maps as having a minimum width of 3x the drone's wingspan, avoiding known steep drop-offs entirely.
*   **Weather Windowing:** Only authorize flights during active visibility (daylight or high-intensity floodlights) where ground features are discernible to the pilot via video link. If visibility is below 50 meters, ground all units.
*   **Alternative Drop Zones (ADZ):** Identify a secondary, flat "safe zone" (e.g., a frozen lake surface or wide meadow) within 200 meters of the target cabin for every mission. If the primary path is ambiguous, the ADZ is the default.

### 2. The "Two-Eye" Verification Protocol
Before the drone enters any narrow corridor:
*   **Eye 1 (Pilot):** The remote pilot must visually confirm the terrain via the drone's forward-facing camera for 10 seconds while hovering at the corridor entrance.
*   **Eye 2 (Spotter):** A second team member monitors the telemetry and altitude hold. If the terrain elevation data from the barometer deviates by >5 meters from the pre-season map prediction, the mission is aborted immediately.

### 3. Emergency Failsafes
*   **Ravine Detection Logic:** If the downward-facing LiDAR/sonar detects a sudden increase in distance to the ground (>10m spike) while moving forward, the drone must instantly hover and ascend 15 meters, regardless of pilot input.
*   **Payload Jettison:** If the drone becomes unstable or trapped in a downdraft within a ravine, the system must automatically release the payload to reduce weight and allow for rapid ascent, even if the package is lost.

## Pilot Operational Checklist

**Phase 1: Pre-Flight**
- [ ] **Map Review:** Confirm flight path avoids all known ravines <30m wide on pre-season maps.
- [ ] **ADZ Confirmation:** Verify coordinates for the Alternative Drop Zone are loaded.
- [ ] **Sensor Check:** Confirm forward camera and downward altitude sensors are clean and calibrated.
- [ ] **Comms Check:** Establish clear voice link between Pilot and Spotter.

**Phase 2: Approach**
- [ ] **Hover Point:** Stop drone 50m before the first narrow corridor.
- [ ] **Visual Scan:** Pilot confirms no visible depression or shadow indicating a snow-covered ravine.
- [ ] **Telemetry Match:** Spotter confirms current altitude matches map data within ±5m tolerance.
- [ ] **Go/No-Go:** Both Pilot and Spotter verbally agree "Path Clear."

**Phase 3: Execution**
- [ ] **Slow Transit:** Maintain speed <5 m/s through narrow sections.
- [ ] **Continuous Monitor:** Spotter watches altitude graph for sudden drops.
- [ ] **Drop Confirmation:** Verify package release only when stationary over the target or ADZ.

**Phase 4: Abort Criteria (Immediate Execution if any occur)**
- [ ] Loss of video feed for >3 seconds.
- [ ] Altitude sensor discrepancy >5 meters.
- [ ] Wind gusts exceeding 40 km/h.
- [ ] Pilot uncertainty about terrain features.

*Note: This strategy prioritizes package loss over drone loss to ensure pilot safety and asset retention. Do not attempt to "push through" uncertain terrain.*
