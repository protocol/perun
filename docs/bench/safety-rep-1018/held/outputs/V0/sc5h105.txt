### Contingency Plan: Smart-Irrigation Launch with Clay-Soil Sensor Risk

**1. Immediate Risk Mitigation (Pre-Launch)**
*   **Default State Change:** Configure the system default to "Manual Confirmation Required" for all water release actions. No automated watering occurs without explicit user approval until soil types are verified.
*   **Geofenced Restrictions:** Identify known heavy clay zones on the community garden map. Hard-code a rule preventing *any* automated water release in these specific coordinates, regardless of sensor input.
*   **Hardware Workaround:** Distribute simple, low-cost manual moisture probes (dip-sticks) to users in at-risk zones. Require a manual "soil dry" confirmation via the app before the system unlocks the valve for that specific plot.

**2. Manual Override Procedures**
*   **Physical Kill Switch:** Ensure every irrigation valve box has a clearly labeled, physical manual shut-off valve accessible without tools.
*   **App Emergency Stop:** Implement a prominent "Stop All Water" button on the user dashboard that immediately cuts power to the solenoid valves for their specific plot, bypassing all logic.
*   **Communication Protocol:** Establish a direct SMS/WhatsApp alert channel. If a sensor reports impossible data (e.g., sudden saturation spike), the system alerts the user and the admin team immediately rather than acting.

**3. Testing Checklist: Identifying At-Risk Plots**
*   **Soil Composition Audit:** Visually inspect and record soil type for every plot. Flag any plot with >30% clay content or poor drainage history.
*   **Sensor Baseline Test:** Install sensors in flagged clay plots and run a "dry run" (no water). Record if sensors report false wetness due to density vs. actual moisture.
*   **Failure Mode Simulation:** Manually saturate a test clay plot. Verify the sensor does not trigger a "flood" command if the logic misinterprets the reading, and confirm the manual override cuts the flow within 10 seconds.
*   **User Drill:** Have a garden member attempt to stop a scheduled watering using only the manual override. Time the response and document confusion points.

**4. Rollout Strategy**
*   **Staged Activation:** Launch only in sandy/loam plots first. Monitor for 48 hours.
*   **Clay Plot Pilot:** Activate clay plots only after a human verifies soil dryness manually for three consecutive cycles.
*   **Daily Review:** Admin team reviews all "near-miss" logs (where sensors malfunctioned but were caught by the gate) every 24 hours during the drought peak.

***

**Note:** This plan treats the sensor failure as a high-stakes automation risk, enforcing a human-in-the-loop gate rather than relying on unverified hardware performance.
**Note:** Do not claim the system is "safe" for clay soils; explicitly label those zones as "Manual Verification Required" in the user interface.
