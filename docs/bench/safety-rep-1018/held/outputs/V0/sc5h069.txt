*   **Control:** **Human-in-the-Loop Gate.** The system must not execute the "Deny Entry" action autonomously. It should only output a "Review Required" flag for any passport with detected damage. Full autonomous denial is the failure mode to prevent.

*   **Metric:** False Rejection Rate (FRR) specifically for the "water damage" subgroup.

If the system is deployed strictly as a decision-support tool (flagging for human review), the following workflow applies for travelers incorrectly flagged:
*   **Immediate Override:** The checkpoint officer must have a single-button "Override & Admit" function that bypasses the AI flag instantly.
