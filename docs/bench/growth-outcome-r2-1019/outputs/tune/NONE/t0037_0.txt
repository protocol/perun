The readout contains multiple critical errors. First, SRM is present: treatment has significantly fewer sessions (64k vs 78k) despite similar user counts, indicating logging issues or differential drop-out. Second, PEEK applies: the test ran only 6 days (Nov 1–6) against a planned 14-day duration. Third, SIMPSON's paradox is evident: while the pooled result favors treatment, the desktop segment shows a lower conversion rate for treatment (11.4%) than control (12.4%), and the mobile segment also favors control (4.2% vs 4.7%); the aggregate reversal is driven by the skewed device mix. Finally, DENOM is violated because the metric (order conversion) uses sessions as the denominator, but randomization occurred at the user level.
