The user split is 123,015 vs 120,615. A chi-squared test confirms this deviation from 50/50 is statistically significant (p < 0.001), indicating Sample Ratio Mismatch (SRM). Additionally, the metric denominator is sessions (e.g., 3,690/165,625), but randomization occurred by user ID. This violates the unit of analysis, constituting a Denominator error (DENOM). While the test ran for the planned 30 days and daily lifts appear stable without clear fading, the SRM and DENOM issues invalidate the reported p-value and lift estimate. These errors must be resolved before trusting the results.

ERRORS: SRM, DENOM
DECISION: HOLD
