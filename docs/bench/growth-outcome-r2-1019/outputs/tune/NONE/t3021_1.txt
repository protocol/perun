The randomization unit is user ID, but the metric denominator is sessions (45,903 vs 41,131), violating the unit of analysis. This is a DENOM error. Additionally, the arm sizes (45,903 vs 41,131) differ significantly from the expected 50/50 split (~43,517 each). A difference of ~2,400 users is far beyond chance for this sample size, indicating Sample Ratio Mismatch (SRM). The daily lift shows fluctuation but no clear fading trend to flag NOVELTY. Segments (desktop/mobile) both show positive lifts, so no SIMPSON paradox. The test ran for the planned duration, so no PEEK. While power might be affected by SRM, the primary explicit errors are denominator mismatch and assignment imbalance.
