The user split is nearly 50/50 (37,564 vs 37,620), ruling out SRM. The test ran for the planned 21 days, so no PEEK. However, segmenting by device reveals Simpson's Paradox: Desktop shows a lift (~3.1% vs ~4.8%), but Mobile shows a significant drop (~1.4% vs ~1.3%). The pooled result claims a massive 25% lift, reversing the negative mobile trend. Additionally, the metric denominator appears to be sessions (e.g., 1,127/48,876 ≈ 2.3%), while randomization was by user ID, violating the unit of analysis (DENOM). The daily lift is stable, not fading, so NOVELTY does not apply. Power is sufficient given the sample sizes.
