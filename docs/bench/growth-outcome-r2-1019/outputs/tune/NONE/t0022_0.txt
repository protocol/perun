The user split (56,637 vs 56,323) is statistically consistent with a 50/50 randomization, ruling out SRM. The test ran for 16 days against a 14-day plan, so PEEK is not indicated by early stopping. Both arms exceed the sample size required for the target lift, eliminating POWER concerns. Segment-level calculations (Desktop: ~13.2% vs ~14.2%; Mobile: ~4.9% vs ~5.3%) show the treatment winning in both strata, matching the pooled direction, so no SIMPSON paradox exists. However, the metric "order conversion rate" is calculated using orders divided by users (e.g., 4,531/56,637), while the denominator for a true conversion rate should be sessions or visits, not the randomized user unit, especially given the massive session count discrepancy (72k vs 57k). This indicates DENOM. The daily lift fluctuates without a clear fading trend, so NOVELTY is not evident.
