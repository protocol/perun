The user split is nearly 50/50 (160,002 vs 160,276), ruling out SRM. The test ran for the planned 21 days, so no PEEK. Daily lifts fluctuate but show no clear fading trend, so no NOVELTY. Segment analysis shows consistent positive lifts in both desktop and mobile, ruling out SIMPSON.

However, the metric is "order conversion rate." The reported rates (2.304% and 3.007%) match orders divided by **sessions** (e.g., 4,800/208,355 ≈ 2.3%), not users. Since randomization occurred by **user id**, using sessions as the denominator violates the unit of randomization, introducing bias if users have different session counts across arms. This is a DENOM error.

ERRORS: DENOM
DECISION: HOLD
