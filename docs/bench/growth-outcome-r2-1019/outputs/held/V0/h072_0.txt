SRM: The arm sizes (79,206 vs 74,854) differ by ~5.5%. With ~154k total users, the standard error for a 50/50 split is ~0.13%. A 5.5% deviation is ~42 standard deviations away, indicating a broken assignment or logging mechanism, invalidating the test.

PEEK: Not explicitly confirmed as the cause for stopping, but the SRM makes the p-value unreliable regardless.

POWER: Sample sizes are sufficient for the target lift; power is not the primary failure mode here.

SIMPSON: Desktop lift is ~7.4%; Mobile lift is ~7.5%. The pooled lift (6.9%) is lower due to the denominator mismatch (sessions vs users), but the direction does not reverse.

DENOM: Randomization was by user ID, but metrics use sessions. If user session counts differ between arms (likely given the SRM in sessions), this biases the conversion rate.

NOVELTY: Daily lift fades from ~12% to ~3%, yet the projection assumes the final 6.9% average persists for 12 months.

ERRORS: SRM, DENOM, NOVELTY
DECISION: HOLD
