The readout contains critical flaws. First, **SRM**: with ~141k total sessions, a 50/50 split expects ~70.5k per arm. The observed 75,479 vs 65,657 is a massive deviation (~14% relative difference), indicating broken randomization or logging; results are invalid. Second, **PEEK**: the test ran 18 days against a planned 28-day duration. Stopping early based on significance inflates false positives. Third, **DENOM**: users were randomized by user ID, but the metric uses sessions. If users generate different session counts across arms, the denominator is wrong. Finally, **NOVELTY**: daily lift drops sharply at the end (20.2% → 12.3%), yet the team projects this as lasting.
