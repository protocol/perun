The readout contains critical analysis errors. First, **SRM** (Sample Ratio Mismatch): with ~152k total sessions, a 50/50 split should yield ~76k per arm. The actual split (81,907 vs 70,196) deviates by over 11k users, far exceeding chance limits, indicating broken randomization or logging. Second, **DENOM**: the metric uses "sessions" as the denominator, but users were randomized by "user ID." If users generated multiple sessions, the independence assumption is violated. Third, **PEEK**: the test ran 29 days against a 28-day plan, and the daily lift data suggests monitoring occurred; combined with SRM, the p-value is unreliable. Finally, **POWER**: while the sample is large, the SRM invalidates the power calculation entirely.
