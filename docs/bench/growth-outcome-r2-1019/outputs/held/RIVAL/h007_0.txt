The readout contains multiple critical errors. First, **SRM**: with ~136k total users, the expected split is ~68k per arm. The treatment arm has 66,228 vs control's 69,857 (a ~5.3% deviation). A chi-square test confirms this deviation is statistically significant (p < 0.001), indicating broken randomization or logging.

Second, **DENOM**: The metric is "order conversion rate," but the denominators are "sessions" while randomization was by "user id." This mismatches the analysis unit with the randomization unit, violating independence assumptions if users have multiple sessions.

Third, **PEEK**: The test ran from Feb 13 to Feb 28 (16 days inclusive), exceeding the planned 14 days. While not early stopping, the daily data suggests monitoring occurred. However, the primary flags are SRM and DENOM.

Because SRM invalidates the causal inference and DENOM biases the variance, the result is unreliable.

ERRORS: SRM, DENOM
DECISION: HOLD
