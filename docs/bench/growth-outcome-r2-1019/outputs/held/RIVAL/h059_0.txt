The readout contains critical analysis errors. First, SRM: the arm sizes (96,728 vs 86,308) deviate significantly from the planned 50/50 split, indicating broken assignment or logging. Second, DENOM: the metric uses "sessions" as the denominator, but users were randomized by user ID; if users generated multiple sessions, the unit of analysis does not match the unit of randomization. Third, SIMPSON: calculating segment rates reveals Desktop Control (8.60%) vs Treatment (9.07%) and Mobile Control (2.63%) vs Treatment (2.77%). While both segments show positive lift, the aggregate rates (3.79% vs 4.47%) are heavily skewed by the unequal session distribution across devices, confirming paradoxical aggregation driven by the SRM.
