ERRORS: DENOM, PEEK
DECISION: HOLD

The randomization unit is user ID, but the arm sizes and conversion rates are calculated using sessions (DENOM). This invalidates the statistical test because multiple sessions per user violate the independence assumption. Additionally, the test ran for 21 days but the readout date is March 27, indicating the results were reviewed or the test stopped before the planned duration concluded (PEEK), inflating the false positive risk. The daily lift shows variability but no clear fading trend to suggest NOVELTY issues yet. Segment data (desktop/mobile) aligns with the aggregate direction, ruling out SIMPSON. Without correcting the unit of analysis and adhering to the stopping rule, the rollout decision is premature.
