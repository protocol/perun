The randomization unit is user ID, but the metric denominator is sessions. Since a single user can generate multiple sessions, using sessions as the denominator violates the independence assumption and mismatches the randomization unit. This is a DENOM error.

The arm sizes (60,235 vs 61,545) are close to 50/50; a chi-squared check suggests this deviation is plausible by chance, so SRM is not flagged. The test ran for the planned 14 days, so PEEK is not flagged. Daily lift is stable, not fading, so NOVELTY is not flagged. Segment calculations (desktop: ~9.7% vs ~10.2%; mobile: ~3.8% vs ~4.0%) both show positive lifts, consistent with the pooled result, so SIMPSON is not flagged. Power appears sufficient given the large sample sizes and significant p-value.
