The arm sizes (33,421 vs 36,003) differ significantly from the 50/50 split; expected ~34,712 each, this deviation suggests Sample Ratio Mismatch (SRM). Regarding power, the baseline is 8% with a target 10% lift (0.8% absolute). Detecting this requires ~25k users per arm; both arms exceed this, so it is not underpowered. The metric (orders/sessions) matches the randomization unit (users/sessions), so no denominator error. Segment data does not show reversed trends (no Simpson's paradox). Daily lift shows fluctuation but no clear fading trend to prove novelty wear-off within the short window.
