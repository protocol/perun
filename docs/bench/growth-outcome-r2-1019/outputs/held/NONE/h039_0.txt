The randomization unit is user ID, but the metric denominator is sessions (DENOM), which biases results if users generate different session counts per arm. The daily lift shows a clear downward trend from 9.5% to ~2%, indicating a novelty effect that is fading, yet the team projects the current partial lift over twelve months (NOVELTY). While the p-value is non-significant (0.1232), the primary errors lie in the metric definition and the unrealistic projection of a decaying effect. The sample sizes appear balanced enough to avoid SRM, and the test ran for the planned duration.
