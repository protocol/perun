The data reveals multiple critical errors. Second, DENOM applies because users were randomized by user ID, but the primary metric uses sessions as the denominator, violating the unit of analysis. Third, PEEK is evident as the test ran for only 9 days against a planned 14-day duration. Finally, NOVELTY is flagged because the daily lift shows no fading trend, yet the team projects this short-term spike over twelve months without justification for sustainability. These issues invalidate the current results.
