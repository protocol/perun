The readout shows a clear Sample Ratio Mismatch (SRM). With ~671k total sessions, a 50/50 split should yield ~335k per arm. The observed counts (357,855 vs 313,758) differ by over 44k, a deviation far exceeding chance limits, indicating broken assignment or logging. Additionally, the analysis suffers from a Denominator error (DENOM): users were randomized by user ID, but the metric uses sessions as the denominator. Since users can generate multiple sessions, this violates the unit of randomization. While daily lift fluctuates, it does not show a consistent fade to confirm NOVELTY without more context. The SRM and DENOM errors invalidate the statistical results.
