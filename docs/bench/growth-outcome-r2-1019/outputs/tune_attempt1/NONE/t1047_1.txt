**SRM**: The difference in users is $|13,454 - 13,418| = 36$. The denominator is $\sqrt{13,454 + 13,418} = \sqrt{26,872} \approx 163.9$. The ratio is $36 / 163.9 \approx 0.22$. Since $0.22 < 3.5$, there is no Sample Ratio Mismatch.

**POWER**: Baseline $p_1 = 0.08$. Target $p_2 = 0.08 \times 1.08 = 0.0864$.
Numerator: $7.85 \times [0.08(0.92) + 0.0864(0.9136)] = 7.85 \times [0.0736 + 0.0789] = 7.85 \times 0.1525 \approx 1.197$.
Denominator: $(0.0864 - 0.08)^2 = (0.0064)^2 = 0.00004096$.
Required $n = 1.197 / 0.00004096 \approx 29,224$ per arm.
Threshold for underpowered: $0.9 \times 29,224 = 26,302$.
Actual smaller arm (control) is 13,418. Since $13,418 < 26,302$, the test is **underpowered**.

**PEEK**: Start date Feb 18, End date Mar 1. Duration is 11 days (Feb 18–28 is 11 days; if inclusive of Mar 1, it is 12 days. Even assuming 12 days).
Planned duration: 21 days. Threshold: $0.8 \times 21 = 16.8$ days.
Actual days (11 or 12) $< 16.8$. The test **stopped early**.

**DENOM**: Reported control rate: $1,073 / 16,775 \approx 0.06396$ (6.396%). Reported treatment rate: $1,152 / 14,216 \approx 0.08104$ (8.104%).
The report divides orders by sessions. Since randomization was by user, this is the **wrong denominator**.

$26.5$ is not below $14.2$. No fading detected by this rule.
