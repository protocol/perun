**SRM**: The difference in users is $|20,981 - 20,887| = 94$. The denominator is $\sqrt{20,981 + 20,887} = \sqrt{41,868} \approx 204.6$. The ratio is $94 / 204.6 \approx 0.46$. Since $0.46 < 3.5$, there is no sample ratio mismatch.

**POWER**: The baseline rate $p_1 = 0.08$. The target lift is 10%, so $p_2 = 0.08 \times 1.10 = 0.088$.
The required sample size per arm is:
$n = 7.85 \times \frac{0.08(0.92) + 0.088(0.912)}{(0.088 - 0.08)^2}$
$n = 7.85 \times \frac{0.0736 + 0.080256}{0.000064} = 7.85 \times \frac{0.153856}{0.000064} \approx 18,879$.
The threshold for being underpowered is $0.9 \times 18,879 \approx 16,991$.
The smaller arm (control) has 20,887 users. Since $20,887 > 16,991$, the test is sufficiently powered.

**DENOM**: The reported control rate is $5.92\%$.

Orders / Sessions = $1,671 / 28,226 \approx 0.0592$ ($5.92\%$).
The reported rate matches Orders/Sessions. Since users were the randomized unit, the denominator is wrong. **Flag DENOM**.

**SIMPSON**:
