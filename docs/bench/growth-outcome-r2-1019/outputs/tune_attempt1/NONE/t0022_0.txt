**SRM**: The difference in users is $|56,323 - 56,637| = 314$. The denominator is $\sqrt{56,323 + 56,637} = \sqrt{112,960} \approx 336$. The ratio is $314 / 336 \approx 0.93$. Since $0.93 < 3.5$, there is no Sample Ratio Mismatch.

**POWER**: Baseline $p_1 = 0.08$. Target $p_2 = 0.08 \times 1.08 = 0.0864$.

Denominator: $(0.0864 - 0.08)^2 = 0.0064^2 = 0.00004096$.
Required $n = 1.203 / 0.00004096 \approx 29,370$.
The smaller arm (treatment) has 56,323 users. The threshold is $0.9 \times 29,370 = 26,433$. Since $56,323 > 26,433$, the test is not underpowered.

**PEEK**: Duration from July 4 to July 20 is 16 days. Planned duration is 14 days. The threshold is $0.8 \times 14 = 11.2$ days. Since $16 > 11.2$, the test did not stop early.

**DENOM**: The metric is order conversion rate with users as the unit.

The reported rates match orders divided by sessions, not users. Since users were the randomized unit, this is the wrong denominator.
