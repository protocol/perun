**SRM**: The difference in users is $|35,385 - 35,669| = 284$. The denominator is $\sqrt{35,385 + 35,669} = \sqrt{71,054} \approx 266.6$. The ratio is $284 / 266.6 \approx 1.07$. Since $1.07 < 3.5$, there is no Sample Ratio Mismatch.

**POWER**: The baseline rate $p_1 = 0.05$ and target lift is 10%, so $p_2 = 0.055$.
Required $n = 7.85 \times \frac{0.05(0.95) + 0.055(0.945)}{(0.005)^2} = 7.85 \times \frac{0.0475 + 0.051975}{0.000025} = 7.85 \times 3979 \approx 31,235$.
The threshold is $0.9 \times 31,235 \approx 28,112$. The smaller arm (treatment) has 35,385 users, which is greater than 28,112. The test is adequately powered.

**PEEK**: The experiment ran from Jan 10 to Feb 7. January has 31 days, so Jan 10–31 is 22 days. Feb 1–7 is 7 days. Total run time = 29 days.
The threshold is $0.8 \times 28 = 22.4$ days. Since $29 > 22.4$, the test was not stopped early.

**DENOM**: The reported control rate is $3.884\%$.
Calculating orders/users: $1,783 / 35,669 \approx 0.0500$ (5.00%).
Calculating orders/sessions: $1,783 / 45,903 \approx 0.03884$ (3.884%).
The reported rate matches orders/sessions, but users were the randomized unit. This is a denominator error.

**SIMPSON**:
Pooled lift: Treatment ($1,854/35,385 \approx 5.24\%$) > Control ($1,783/35,669 \approx 5.00\%$). Lift is positive.
Desktop: Treatment ($1,261/14,191 \approx 8.89\%$) > Control ($1,213/14,305 \approx 8.48\%$). Lift is positive.
Mobile: Treatment ($593/21,194 \approx 2.80\%$) > Control ($570/21,364 \approx 2.67\%$). Lift is positive.
Since the lift is positive in all segments, there is no Simpson's paradox.

**NOVELTY**:
First 3 days mean: $(14.5 + 13.6 + 13.8) / 3 = 13.97$. Half of this is $\approx 6.99$.
Last 3 days mean: $(18.6 + 16.8 + 16.8) / 3 = 17.4$.
Since $17.4$ is not below $6.99$, the lift is not fading according to this rule.

Only the DENOM error is present. Using sessions instead of users for the conversion rate invalidates the statistical inference because the randomization unit was the user. This must be fixed before making a rollout decision.

ERRORS: DENOM
DECISION: HOLD
