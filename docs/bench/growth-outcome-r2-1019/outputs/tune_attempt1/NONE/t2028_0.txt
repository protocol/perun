**SRM**: The difference in users is $|259,899 - 259,699| = 200$. The denominator is $\sqrt{259,899 + 259,699} = \sqrt{519,598} \approx 721$. The ratio is $200 / 721 \approx 0.28$. Since $0.28 < 3.5$, there is no SRM.

**POWER**: Baseline $p_1 = 0.03$. Target lift 5% implies $p_2 = 0.03 \times 1.05 = 0.0315$.
Required $n = 7.85 \times \frac{0.03(0.97) + 0.0315(0.9685)}{(0.0015)^2} = 7.85 \times \frac{0.0291 + 0.0305}{0.00000225} = 7.85 \times 26,489 \approx 207,938$.
The threshold is $0.9 \times 207,938 \approx 187,144$. The smaller arm has 259,699 users, which is greater than 187,144. The test is powered.

**PEEK**: Duration from Aug 2 to Aug 30 is 28 days. Planned duration is 28 days. $28 \ge 0.8 \times 28$ (22.4). The test ran long enough.

**DENOM**: Control reported rate is $2.324\%$. Calculating orders/sessions: $7,791 / 335,229 \approx 0.02324$ ($2.324\%$). Calculating orders/users: $7,791 / 259,699 \approx 0.0300$ ($3.00\%$). The reported rate matches orders/sessions, not orders/users. Since randomization was by user, this is the wrong denominator. Flagged.
