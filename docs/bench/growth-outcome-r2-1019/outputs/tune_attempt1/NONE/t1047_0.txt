**SRM**: The difference in users is $|13,454 - 13,418| = 36$. The denominator is $\sqrt{13,454 + 13,418} = \sqrt{26,872} \approx 163.9$. The ratio is $36 / 163.9 \approx 0.22$. This is less than 3.5, so no SRM.

**POWER**: Baseline $p_1 = 0.08$. Target lift 8% means $p_2 = 0.08 \times 1.08 = 0.0864$.
Numerator: $7.85 \times [0.08(0.92) + 0.0864(0.9136)] = 7.85 \times [0.0736 + 0.0789] = 7.85 \times 0.1525 \approx 1.197$.
Denominator: $(0.0864 - 0.08)^2 = (0.0064)^2 = 0.00004096$.
Required $n = 1.197 / 0.00004096 \approx 29,224$ per arm.
Threshold for underpowered: $0.9 \times 29,224 = 26,301$.
Actual smaller arm (control) has 13,418 users. Since $13,418 < 26,301$, the test is underpowered. **Flag POWER**.
