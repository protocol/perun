**SRM**: The difference in users is $|226,169 - 225,943| = 226$. The denominator is $\sqrt{226,169 + 225,943} = \sqrt{452,112} \approx 672.4$. The ratio is $226 / 672.4 \approx 0.34$. This is less than 3.5. No SRM.

**POWER**: Baseline $p_1 = 0.05$. Target $p_2 = 0.05 \times 1.05 = 0.0525$.
Numerator: $7.85 \times (0.05 \times 0.95 + 0.0525 \times 0.9475) \approx 7.85 \times (0.0475 + 0.04974) \approx 0.763$.
Denominator: $(0.0525 - 0.05)^2 = 0.0025^2 = 0.00000625$.
Required $n = 0.763 / 0.00000625 \approx 122,080$.
The smaller arm has 225,943 users. The threshold is $0.9 \times 122,080 = 109,872$. Since $225,943 > 109,872$, the test is powered. No POWER error.

**PEEK**: Duration from Aug 1 to Aug 23 is 22 days. Planned was 21 days.
Threshold: $0.8 \times 21 = 16.8$ days. Since $22 > 16.8$, the test ran long enough. No PEEK error.

**DENOM**: Control reported rate is 3.598%.
Calculation using sessions: $11,297 / 313,939 \approx 0.0360$ (3.60%).
Calculation using users: $11,297 / 225,943 \approx 0.0500$ (5.00%).
The reported 3.598% matches the sessions denominator, not the user denominator (the randomization unit). This is an error. Flag DENOM.
