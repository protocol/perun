**SRM**: The difference in users is $|21,656 - 21,474| = 182$. The denominator is $\sqrt{21,656 + 21,474} = \sqrt{43,130} \approx 207.7$. The ratio is $182 / 207.7 \approx 0.88$. This is less than 3.5, so no mismatch.

**POWER**: Baseline $p_1 = 0.08$. Target $p_2 = 0.08 \times 1.10 = 0.088$.
Numerator: $7.85 \times (0.08 \times 0.92 + 0.088 \times 0.912) = 7.85 \times (0.0736 + 0.080256) \approx 1.208$.
Denominator: $(0.088 - 0.08)^2 = 0.000064$.
Required $n = 1.208 / 0.000064 \approx 18,875$.
The smaller arm (control) has 21,474 users. The threshold is $0.9 \times 18,875 = 16,987.5$. Since $21,474 > 16,987.5$, the test is powered.

**PEEK**: Start date 2026-09-25 to readout 2026-10-10 is 15 days inclusive (or 14 full intervals). The planned duration is 14 days. The actual duration (15) is not fewer than $0.8 \times 14 = 11.2$. The test ran long enough.

**DENOM**: The reported control rate is $1,718 / 32,127 \approx 0.05347$ (5.347%). The readout reports 5.348%. If calculated by users ($1,718 / 21,474$), the rate would be ~8.0%. The report clearly divides orders by sessions, but users were the randomized unit. This is an error.

**SIMPSON**: 
Desktop Control Rate: $1,286 / 10,714 \approx 12.00\%$. Desktop Treatment Rate: $1,362 / 10,804 \approx 12.61\%$. Lift is positive.
Mobile Control Rate: $432 / 10,760 \approx 4.01\%$. Mobile Treatment Rate: $458 / 10,852 \approx 4.22\%$. Lift is positive.
Since both segments show positive lift, there is no paradox.

**NOVELTY**: 
First 3 days mean: $(18.9 + 15.9 + 13.5) / 3 = 16.1$. Half of this is $8.05$.
Last 3 days (days 13-15): $(17.6 + 14.4 + 13.4) / 3 = 15.13$.
$15.13$ is not below $8.05$. The lift is not fading significantly by this metric.

Only the DENOM error is confirmed. Using sessions instead of users as the denominator invalidates the statistical inference because the variance calculation assumes user-level randomization.
