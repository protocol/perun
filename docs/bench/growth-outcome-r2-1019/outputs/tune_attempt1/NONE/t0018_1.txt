**SRM**: The difference in users is $|406,514 - 407,274| = 760$. The sum is $813,788$. The metric is $760 / \sqrt{813,788} \approx 760 / 902 = 0.84$. Since $0.84 < 3.5$, there is no Sample Ratio Mismatch.

**POWER**: The baseline rate $p_1 = 0.03$ and target lift is 5%, so $p_2 = 0.03 \times 1.05 = 0.0315$.
Required $n$ per arm:
Numerator: $7.85 \times [0.03(0.97) + 0.0315(0.9685)] = 7.85 \times [0.0291 + 0.0305] = 7.85 \times 0.0596 \approx 0.468$.
Denominator: $(0.0315 - 0.03)^2 = (0.0015)^2 = 0.00000225$.
$n \approx 0.468 / 0.00000225 \approx 208,000$.
The threshold is $0.9 \times 208,000 = 187,200$. The smaller arm (treatment) has 406,514 users, which is well above the threshold. The test is not underpowered.

**PEEK**: The experiment ran from March 11 to April 1. March has 31 days. Days run: $(31 - 11 + 1) + 1 = 22$ days. Planned duration is 21 days. Since $22 \ge 0.8 \times 21$ ($16.8$), the test was not stopped early.
