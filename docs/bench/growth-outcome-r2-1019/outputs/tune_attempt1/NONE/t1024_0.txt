**SRM**: The difference in users is $|107,442 - 107,572| = 130$. The denominator is $\sqrt{107,442 + 107,572} = \sqrt{215,014} \approx 463.7$. The ratio is $130 / 463.7 \approx 0.28$. Since $0.28 < 3.5$, there is no sample ratio mismatch.

**POWER**: The baseline rate $p_1 = 0.08$ and target lift is 5%, so $p_2 = 0.08 \times 1.05 = 0.084$.
Required $n = 7.85 \times \frac{0.08(0.92) + 0.084(0.916)}{(0.004)^2} = 7.85 \times \frac{0.0736 + 0.076944}{0.000016} = 7.85 \times 9409 \approx 73,861$.
The threshold for being underpowered is $0.9 \times 73,861 \approx 66,475$. The smaller arm has 107,442 users, which is well above this threshold. The test is adequately powered.

**PEEK**: The experiment ran from May 18 to June 8. Counting inclusive days: May (14 days) + June (8 days) = 22 days. The planned duration was 21 days. Since $22 \ge 0.8 \times 21$ (16.8), the test was not stopped early.

**DENOM**: The reported control conversion rate is 5.418%.
Calculating Orders/Users: $8,605 / 107,572 \approx 0.0800$ (8.00%).
Calculating Orders/Sessions: $8,605 / 158,837 \approx 0.05418$ (5.418%).
The reported rate matches Orders/Sessions, but users were the randomized unit. This is a denominator error.

**SIMPSON**:
Pooled Lift: Treatment rate ($9,061/107,442 \approx 8.43\%$) > Control rate ($8.00\%$). Lift is positive.
Desktop Lift: Control $6,383/52,693 \approx 12.11\%$; Treatment $6,721/52,630 \approx 12.77\%$. Lift is positive.
Mobile Lift: Control $2,222/54,879 \approx 4.05\%$; Treatment $2,340/54,812 \approx 4.27\%$. Lift is positive.
Since the lift is positive in all segments, there is no Simpson's paradox.

**NOVELTY**:
First 3 days mean: $(16.7 + 17.2 + 13.2) / 3 = 15.7\%$.
Last 3 days mean: $(19.7 + 22.5 + 21.4) / 3 = 21.2\%$.
The last mean (21.2) is not below half the first mean ($15.7 / 2 = 7.85$). The lift is not fading by this metric.

Only the DENOM category flag applies. Using sessions instead of users for the conversion rate invalidates the statistical inference because the randomization unit was the user. This must be fixed before making a rollout decision.

ERRORS: DENOM
DECISION: HOLD
