**SRM**: The difference in users is $|36,993 - 37,105| = 112$. The denominator is $\sqrt{36,993 + 37,105} = \sqrt{74,098} \approx 272.2$. The ratio is $112 / 272.2 \approx 0.41$. Since $0.41 < 3.5$, there is no Sample Ratio Mismatch.

**POWER**: Baseline $p_1 = 0.08$. Target $p_2 = 0.08 \times 1.08 = 0.0864$.
Numerator: $7.85 \times (0.08 \times 0.92 + 0.0864 \times 0.9136) = 7.85 \times (0.0736 + 0.0789) \approx 1.199$.
Denominator: $(0.0864 - 0.08)^2 = 0.0064^2 = 0.00004096$.
Required $n \approx 1.199 / 0.00004096 \approx 29,272$.
Threshold for underpowered: $0.9 \times 29,272 \approx 26,345$.
The smaller arm (treatment) has 36,993 users, which is greater than 26,345. The test is not underpowered.

**PEEK**: Duration from July 11 to July 25 is 14 days. Planned duration is 14 days.
Threshold: $0.8 \times 14 = 11.2$. Since $14 \ge 11.2$, the test was not stopped early.

**DENOM**: Randomization was by user. Reported control rate is $5.417\%$.
Orders / Sessions (Control): $2,968 / 54,789 \approx 0.05417$ ($5.417\%$).
Orders / Users (Control): $2,968 / 37,105 \approx 0.0800$ ($8.00\%$).
The reported rate matches the session denominator, not the user denominator. This is an error.

**SIMPSON**:
Pooled Lift: Treatment ($3,152/36,993 \approx 8.52\%$) vs Control ($2,968/37,105 \approx 8.00\%$). Lift is positive.
Desktop Lift: Treatment ($2,370/17,640 \approx 13.44\%$) vs Control ($2,232/17,694 \approx 12.61\%$). Lift is positive.
Mobile Lift: Treatment ($782/19,353 \approx 4.04\%$) vs Control ($736/19,411 \approx 3.79\%$). Lift is positive.
Since lifts are positive in all segments, there is no Simpson's Paradox.

**NOVELTY**:
First 3 days mean: $(18.4 + 20.0 + 18.3) / 3 = 18.9$. Half is $9.45$.
Last 3 days mean: $(19.5 + 17.9 + 17.1) / 3 = 18.17$.
$18.17$ is not below $9.45$. No fading trend detected by this rule.

Only the DENOM error is present. Using sessions instead of users as the denominator invalidates the statistical inference because the randomization unit was the user. This must be fixed before making a rollout decision.
