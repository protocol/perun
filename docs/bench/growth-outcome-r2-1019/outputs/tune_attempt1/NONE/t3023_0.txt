**SRM**: The difference in users is $|42,525 - 42,259| = 266$. The denominator is $\sqrt{42,525 + 42,259} = \sqrt{84,784} \approx 291.2$. The ratio is $266 / 291.2 \approx 0.91$. Since $0.91 < 3.5$, there is no sample ratio mismatch.

**POWER**: Baseline $p_1 = 0.04$. Target lift 8% implies $p_2 = 0.04 \times 1.08 = 0.0432$.
Numerator: $7.85 \times [0.04(0.96) + 0.0432(0.9568)] = 7.85 \times [0.0384 + 0.04133] \approx 0.6259$.
Denominator: $(0.0432 - 0.04)^2 = (0.0032)^2 = 0.00001024$.
Required $n = 0.6259 / 0.00001024 \approx 61,123$ users per arm.
The smaller arm (control) has 42,259 users. The threshold is $0.9 \times 61,123 = 55,011$.
Since $42,259 < 55,011$, the test is underpowered. **Flag POWER**.

**PEEK**: Start date 2026-08-03 to readout 2026-08-18 is 15 days inclusive (or 15 days elapsed if counting start to end). Planned duration is 14 days.
Actual days (15) vs $0.8 \times 14 = 11.2$. Since $15 \ge 11.2$, the test was not stopped early.

Since the reported rate matches the user-based calculation, the denominator is correct.
