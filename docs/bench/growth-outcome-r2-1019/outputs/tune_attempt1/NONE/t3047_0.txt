**SRM**: The difference in users is $|36,445 - 35,473| = 972$. The denominator is $\sqrt{36,445 + 35,473} = \sqrt{71,918} \approx 268.2$. The ratio is $972 / 268.2 \approx 3.62$. Since $3.62 \ge 3.5$, SRM is flagged.

**POWER**: Baseline $p_1 = 0.05$. Target $p_2 = 0.05 \times 1.10 = 0.055$.
Numerator: $7.85 \times (0.05 \times 0.95 + 0.055 \times 0.945) = 7.85 \times (0.0475 + 0.051975) \approx 0.7809$.
Denominator: $(0.055 - 0.05)^2 = 0.000025$.
Required $n = 0.7809 / 0.000025 \approx 31,236$.
Threshold is $0.9 \times 31,236 = 28,112$. The smaller arm (control) has 35,473 users, which is above the threshold. POWER is not flagged.
