**SRM**: The difference in users is $|44,378 - 44,634| = 256$. The denominator is $\sqrt{44,378 + 44,634} = \sqrt{89,012} \approx 298.3$. The ratio is $256 / 298.3 \approx 0.86$. Since $0.86 < 3.5$, there is no Sample Ratio Mismatch.

**POWER**: Baseline $p_1 = 0.08$. Target $p_2 = 0.08 \times 1.08 = 0.0864$.
Required $n = 7.85 \times \frac{0.08(0.92) + 0.0864(0.9136)}{(0.0064)^2} = 7.85 \times \frac{0.0736 + 0.0789}{0.00004096} \approx 7.85 \times 3723 \approx 29,226$.
The threshold for "underpowered" is $0.9 \times 29,226 \approx 26,303$. The smaller arm (treatment) has 44,378 users, which is well above 26,303. The test is adequately powered.

**PEEK**: The experiment ran from Aug 3 to Aug 11, which is 8 days. The planned duration was 14 days. The threshold is $0.8 \times 14 = 11.2$ days. Since $8 < 11.2$, the test stopped early. **Flag PEEK**.

**DENOM**: Control reported rate: $3,571 / 59,617 \approx 0.0599$ (5.99%). Treatment reported rate: $3,712 / 49,962 \approx 0.0743$ (7.43%). The readout matches orders/sessions. Since randomization was by user, using sessions as the denominator is incorrect. **Flag DENOM**.
