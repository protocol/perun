**SRM**: The difference in users is $|47,538 - 47,718| = 180$. The denominator is $\sqrt{47,538 + 47,718} = \sqrt{95,256} \approx 308.6$. The ratio is $180 / 308.6 \approx 0.58$. This is less than 3.5, so no SRM.

**POWER**: Baseline $p_1 = 0.05$. Target $p_2 = 0.05 \times 1.10 = 0.055$.
Variance term: $0.05(0.95) + 0.055(0.945) = 0.0475 + 0.051975 = 0.099475$.
Difference squared: $(0.055 - 0.05)^2 = 0.000025$.
Required $n = 7.85 \times (0.099475 / 0.000025) = 7.85 \times 3979 = 31,235$.
Threshold for underpowered: $0.9 \times 31,235 = 28,111$.
The smaller arm (treatment) has 47,538 users, which is well above 28,111. No POWER issue.
