**SRM**: The difference in users is $|5,540 - 5,612| = 72$. The denominator is $\sqrt{5,540 + 5,612} = \sqrt{11,152} \approx 105.6$. The ratio is $72 / 105.6 \approx 0.68$. This is less than 3.5, so no SRM.

**POWER**: Baseline $p_1 = 0.08$. Target $p_2 = 0.08 \times 1.10 = 0.088$.
Variance term: $0.08(0.92) + 0.088(0.912) = 0.0736 + 0.080256 = 0.153856$.
Difference squared: $(0.088 - 0.08)^2 = 0.000064$.
Required $n = 7.85 \times (0.153856 / 0.000064) \approx 18,865$ per arm.
The smaller arm (treatment) has 5,540 users. The threshold is $0.9 \times 18,865 = 16,978$. Since $5,540 < 16,978$, the test is underpowered. **Flag POWER**.

**PEEK**: Duration from June 16 to July 16 is 30 days. Planned was 28 days.
Threshold: $0.8 \times 28 = 22.4$ days. Since $30 > 22.4$, the test ran long enough. No PEEK.

**DENOM**: Control reported rate is $449 / 8,091 \approx 5.549\%$. Treatment is $470 / 6,406 \approx 7.337\%$.
The readout calculates conversion as Orders/Sessions. However, randomization was by User ID. The denominator should be Users. **Flag DENOM**.
