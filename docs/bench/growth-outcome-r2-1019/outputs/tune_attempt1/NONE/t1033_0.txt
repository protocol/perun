**SRM**: The difference in users is $|59,368 - 59,288| = 80$. The denominator is $\sqrt{59,368 + 59,288} = \sqrt{118,656} \approx 344.46$. The ratio is $80 / 344.46 \approx 0.23$. Since $0.23 < 3.5$, there is no Sample Ratio Mismatch.

**POWER**: Baseline $p_1 = 0.04$. Target $p_2 = 0.04 \times 1.10 = 0.044$.

The threshold for being underpowered is $0.9 \times 39,478 \approx 35,530$. The smaller arm (control) has 59,288 users, which is well above 35,530. The test is not underpowered.
