**SRM**: The difference in users is $|59,599 - 61,691| = 2,092$. The denominator is $\sqrt{59,599 + 61,691} = \sqrt{121,290} \approx 348.27$. The ratio is $2,092 / 348.27 \approx 6.01$. Since $6.01 \ge 3.5$, SRM is flagged.

**POWER**: Baseline $p_1 = 0.05$. Target $p_2 = 0.05 \times 1.10 = 0.055$.
Variance term: $0.05(0.95) + 0.055(0.945) = 0.0475 + 0.051975 = 0.099475$.
Difference squared: $(0.055 - 0.05)^2 = 0.000025$.
Required $n = 7.85 \times (0.099475 / 0.000025) = 7.85 \times 3,979 = 31,235$.
Threshold for underpowered: $0.9 \times 31,235 = 28,111$.
The smaller arm (treatment) has 59,599 users. Since $59,599 > 28,111$, the test is sufficiently powered. POWER is not flagged.

**PEEK**: Duration from Feb 9 to Feb 22 is 13 days (inclusive count or simply $22-9=13$ days elapsed). Planned is 28 days.
Threshold: $0.8 \times 28 = 22.4$ days.
Actual days (13) < 22.4. PEEK is flagged.

**DENOM**: Randomization unit is users. Reported control rate is $3,085 / 61,691 \approx 5.001\%$. This matches the readout. The readout does not claim to use sessions. DENOM is not flagged.
