**SRM**: The difference in users is $|146,746 - 146,340| = 406$. The denominator is $\sqrt{146,746 + 146,340} = \sqrt{293,086} \approx 541.4$. The ratio is $406 / 541.4 \approx 0.75$. Since $0.75 < 3.5$, there is no Sample Ratio Mismatch.

**POWER**: Baseline $p_1 = 0.06$. Target $p_2 = 0.06 \times 1.05 = 0.063$.

The threshold is $0.9 \times 100,654 \approx 90,589$. The smaller arm (control) has 146,340 users, which is well above the threshold. The test is not underpowered.

**PEEK**: The experiment ran from Oct 7 to Oct 15, which is 8 days. The planned duration was 14 days. The threshold is $0.8 \times 14 = 11.2$ days. Since $8 < 11.2$, the test was stopped early. **Flag PEEK**.
