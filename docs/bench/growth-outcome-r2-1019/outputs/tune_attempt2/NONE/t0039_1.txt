**SRM**: The planned split is 50/50. Total users = 91,215 + 90,945 = 182,160. Expected per arm = 91,080.
Control deviation: (91,215 - 91,080) / 91,080 ≈ 0.15%.
Treatment deviation: (90,945 - 91,080) / 91,080 ≈ -0.15%.
This difference is well within random chance for this sample size. No SRM.

**PEEK**: Planned duration was 28 days. The readout date is 2026-02-21, and the start was 2026-02-08.
Duration = 13 days.
The test was stopped at roughly 46% of the planned duration (13/28). Stopping early based on interim results inflates false positives. This is a PEEK error.

**POWER**: The smaller arm (treatment) has 90,945 users.
Baseline = 5%, Target lift = 8% (absolute change ≈ 0.4%).
With n ≈ 90k per arm, alpha 0.05, and baseline 5%, the detectable lift is far smaller than 8%. The study is not underpowered; if anything, it is overpowered for the target, which exacerbates the risk from peeking. No POWER error.

**SIMPSON**: Let's check conversion rates by segment.
Desktop Control: 2,984 / 35,713 ≈ 8.35%
Desktop Treatment: 3,167 / 35,607 ≈ 8.89% (Lift positive)
Mobile Control: 1,577 / 55,502 ≈ 2.84%
Mobile Treatment: 1,674 / 55,338 ≈ 3.02% (Lift positive)
Both segments show a positive lift. The pooled result is also positive. No reversal occurs. No SIMPSON error.

**DENOM**: Randomization unit is "user id". The metric is "order conversion rate".
Reported Control Rate: 4,561 orders / 91,215 users = 5.00%.
However, the readout reports control conversion as 3.729%.
Let's check sessions as the denominator: 4,561 / 122,311 ≈ 3.729%.
The reported metric uses "sessions" as the denominator, but users were randomized. If a user has multiple sessions, this violates the independence assumption unless analyzed carefully, but strictly speaking, the denominator (sessions) does not match the randomization unit (users). This is a DENOM error.

**NOVELTY**: Daily lift drops from 89.3% (Day 1) to ~9.9% (Day 13).
The trend shows a sharp decay. The team projects the current aggregate lift (35.3%) for the next 12 months. Given the rapid fade from ~90% to ~10% in two weeks, projecting the high aggregate average forward ignores the fading effect, likely overestimating long-term value. This indicates a NOVELTY error.

ERRORS: PEEK, DENOM, NOVELTY
DECISION: HOLD
