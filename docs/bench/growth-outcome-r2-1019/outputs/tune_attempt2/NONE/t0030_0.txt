**SRM Check**: Total users are 452,112. Expected per arm is 226,056. Observed: Control 225,943, Treatment 226,169. The difference is negligible (~0.05%), well within chance. No SRM.

**PEEK Check**: Planned duration was 21 days (ending ~Aug 22). The readout date is Aug 23, and daily data is provided for 22 days. The test ran for the full planned duration (or one day extra). There is no evidence of early stopping based on the dates provided. No PEEK.

**POWER Check**: The test detected a massive 33.4% lift with huge sample sizes (>225k per arm). The target was only 5%. The test is vastly overpowered, not underpowered. No POWER error.

**SIMPSON Check**: Let's calculate segment conversion rates (Orders/Users).
Desktop Control: 7,767 / 99,135 ≈ 7.83%. Desktop Treatment: 8,212 / 99,234 ≈ 8.28%. (Lift positive)
Mobile Control: 3,530 / 126,808 ≈ 2.78%. Mobile Treatment: 3,732 / 126,935 ≈ 2.94%. (Lift positive)
Both segments show a positive lift consistent with the pooled result. No reversal occurs. No SIMPSON.

**DENOM Check**: Randomization unit is "user id". The metric is "order conversion rate".
Control Rate Calculation: 11,297 orders / 225,943 users = 5.00%.
Treatment Rate Calculation: 11,944 orders / 226,169 users = 5.28%.
True Relative Lift: (5.28 - 5.00) / 5.00 = 5.6%.
The readout reports Control 3.598% and Treatment 4.8%.
Where did 3.598% come from? 11,297 orders / 313,939 sessions = 3.598%.
The reported metric divides orders by *sessions*, but users were randomized. Since session counts differ significantly between arms (Control ~314k vs Treatment ~249k), using sessions as the denominator biases the result. This is a clear denominator mismatch. **DENOM flagged**.

**NOVELTY Check**: Daily lift starts at 81.9% and decays steadily to 7.7% by day 22. The team projects the current reported aggregate lift (inflated by early days) for the next twelve months. This ignores the clear fading trend, assuming a transient novelty effect is permanent. **NOVELTY flagged**.

ERRORS: DENOM, NOVELTY
DECISION: HOLD
