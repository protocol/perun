**SRM Check**: Total users = 35,820 (Control) + 34,868 (Treatment) = 70,688. Expected per arm = 35,344.
Difference = |35,820 - 35,344| = 476.
Standard Error for proportion (p=0.5) = $\sqrt{70688 \times 0.5 \times 0.5} \approx 133$.
Z-score = $476 / 133 \approx 3.58$. A Z-score > 1.96 indicates a significant deviation from the 50/50 split. The assignment or logging is broken.

**PEEK Check**: Planned duration was 21 days. The readout date (Jan 31) is exactly 21 days after the start (Jan 10). Daily data is provided for all 21 days. There is no evidence of early stopping.

**POWER Check**: The test achieved a p-value of 0.2277, failing to reach significance. While the test might be underpowered to detect the specific 10% target if the true effect is smaller, "underpowered" usually refers to a design flaw before running. However, the primary error here is the SRM which invalidates the power calculation itself. We flag SRM as the definitive breakage.

**SIMPSON Check**:
Control Rate Desktop: $1283/16791 \approx 7.64\%$. Treatment Rate Desktop: $1299/16345 \approx 7.95\%$. (Lift positive)
Control Rate Mobile: $508/19029 \approx 2.67\%$. Treatment Rate Mobile: $514/18523 \approx 2.77\%$. (Lift positive)
Both segments show a positive lift, consistent with the pooled result. No paradox.

**DENOM Check**: Randomization was by user ID. The metric is "order conversion rate." The counts provided for the metric calculation (orders) are aggregated by users in the breakdown. Assuming "conversion rate" implies orders per user (or sessions per user leading to orders), the denominator aligns with the randomization unit (users). No clear mismatch shown in the numbers provided.

**NOVELTY Check**: The daily lift fluctuates between 3.4% and 4.8% with no clear downward trend over the 21 days. The projection applies the current observed lift, not an inflated early spike.

The Sample Ratio Mismatch (SRM) is severe (Z > 3.5). This indicates that the randomization mechanism failed or data logging is incomplete for one arm. Any statistical result (including the p-value and lift) derived from these groups is invalid because the groups are not comparable. The decision to roll out cannot be made on broken data.

ERRORS: SRM
DECISION: HOLD
