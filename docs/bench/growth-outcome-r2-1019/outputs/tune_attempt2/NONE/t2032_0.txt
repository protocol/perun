**SRM Check**: Total users = 148,729 (Control) + 148,841 (Treatment) = 297,570. Expected per arm = 148,785. The difference is only 56 users, well within random chance. No SRM.

**PEEK Check**: Started 2026-06-02, planned 14 days. Final readout 2026-06-16 is exactly 14 days later. The test ran the full duration. No PEEK.

**POWER Check**: Baseline 5%, target lift 5% (absolute 0.25%). With ~148k users per arm, the sample size is vastly larger than required for 80% power at alpha 0.05 for this effect size. No POWER issue.

**SIMPSON Check**:
Control Rate Desktop: 4,890 / 55,332 ≈ 8.84%
Treatment Rate Desktop: 5,485 / 65,082 ≈ 8.43%
(Lift is negative on Desktop)

Control Rate Mobile: 2,547 / 93,397 ≈ 2.73%
Treatment Rate Mobile: 2,178 / 83,759 ≈ 2.60%
(Lift is negative on Mobile)

Overall Reported: Control 5.0%, Treatment 5.148% (Positive lift).
The aggregate shows a positive lift, but both segments (Desktop and Mobile) show a negative lift. This is a clear reversal caused by the imbalance in device mix (Treatment has more high-converting Desktop users). This is **SIMPSON**.

**DENOM Check**: Randomized by user id. Metric is order conversion rate. The readout implies orders per user (7,437/148,729 ≈ 5.0%). The denominator matches the randomization unit. No DENOM.

**NOVELTY Check**: Daily lift drops from 5.8% to 0.6% over the two weeks, showing a clear fading trend. However, the team projects the current reported average (3.0%) for the next twelve months without adjusting for the decay. This assumes a fleeting novelty effect is permanent. This is **NOVELTY**.

ERRORS: SIMPSON, NOVELTY
DECISION: HOLD
