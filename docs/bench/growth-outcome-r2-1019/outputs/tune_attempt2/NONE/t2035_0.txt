**SRM Check**: Total users = 48,643 (Control) + 48,543 (Treatment) = 97,186. Expected per arm = 48,593.
Difference = 100 users.
Standard Error for proportion $p=0.5$ is $\sqrt{0.5 \times 0.5 / 97186} \approx 0.0016$.
Observed proportion difference = $100 / 97186 \approx 0.001$.
This is less than 1 standard error. The split is statistically consistent with 50/50. No SRM.

**PEEK Check**: Started Oct 8, ended Nov 6. Duration = 29 days. Planned = 28 days.
The test ran slightly longer than planned, not shorter. No evidence of early stopping. No PEEK.

**POWER Check**: The test detected a significant result (p=0.0). While the observed lift (19.6%) exceeded the target (8%), the sample size was sufficient to detect the effect that occurred. Power calculations regarding *target* lift do not invalidate a significant result found with the *actual* data. No POWER error flagged based on these numbers alone.

**SIMPSON Check**:
Control Rate Desktop: $920 / 17,527 \approx 5.25\%$
Treatment Rate Desktop: $978 / 17,491 \approx 5.59\%$ (Lift positive)
Control Rate Mobile: $539 / 31,116 \approx 1.73\%$
Treatment Rate Mobile: $573 / 31,052 \approx 1.85\%$ (Lift positive)
Both segments show positive lift, matching the pooled direction. No SIMPSON.

**DENOM Check**: Randomization unit = User ID. Metric = Order Conversion Rate.
Reported Control Rate: $1,459 \text{ orders} / 48,643 \text{ users} = 2.999\%$.
Reported Treatment Rate: $1,551 \text{ orders} / 48,543 \text{ users} = 3.195\%$.
The readout reports: Control 2.083%, Treatment 2.491%.
These reported percentages do not match orders/users.
Let's check orders/sessions:
Control: $1,459 / 70,038 = 2.083\%$.
Treatment: $1,551 / 62,261 = 2.491\%$.
The metric denominator is **Sessions**, but randomization was by **User**. Users in the control arm had more sessions per user ($1.44$) than treatment ($1.28$). This violates the unit of analysis. **DENOM** error confirmed.

**NOVELTY Check**: Daily lift fluctuates (14.6% to 24.1%) but shows no clear monotonic decay trend indicative of novelty wearing off; the final days are similar to the start. No obvious fading pattern to flag strictly from numbers.

The primary error is using session-level metrics for a user-randomized test without accounting for the correlation or differing session counts, which biases the variance and potentially the mean if assignment affects session frequency.

ERRORS: DENOM
DECISION: HOLD
