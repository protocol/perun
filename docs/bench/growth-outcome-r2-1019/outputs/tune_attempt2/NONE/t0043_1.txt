**SRM Check**: Total users = 37,274 + 37,342 = 74,616. Expected per arm = 37,308.
Difference = |37,274 - 37,308| = 34.
Standard Error ≈ $\sqrt{74616 \times 0.5 \times 0.5} \approx 136$.
The difference (34) is well within 2 standard deviations (~272). The split is consistent with 50/50 randomization. No SRM.

**PEEK Check**: Planned duration was 21 days. The readout date (Nov 4) is only 9 days after the start (Oct 26). The test was stopped early, before the planned duration elapsed. This constitutes peeking/early stopping, which inflates false positive rates. **PEEK flagged.**

**POWER Check**: The smaller arm (Control) has 37,274 users.
Baseline = 5%, Target Lift = 5% (absolute 0.25%).
Using standard approximation for sample size $n \approx \frac{16 \sigma^2}{\delta^2}$:
$\sigma^2 \approx p(1-p) = 0.05 \times 0.95 = 0.0475$.
$\delta = 0.0025$.
$n \approx \frac{16 \times 0.0475}{0.0025^2} = \frac{0.76}{0.00000625} = 121,600$ per arm.
The actual sample size (~37k) is far below the required ~122k per arm to detect this lift with 80% power. The test is severely underpowered. **POWER flagged.**

**SIMPSON Check**:
Desktop Control Rate: $1234/15662 \approx 7.88\%$. Desktop Treat Rate: $1299/15691 \approx 8.28\%$. (Treat > Control)
Mobile Control Rate: $630/21612 \approx 2.92\%$. Mobile Treat Rate: $663/21651 \approx 3.06\%$. (Treat > Control)
Both segments show a positive lift, matching the pooled direction. No Simpson's paradox.

**DENOM Check**: Randomization was by user ID. The metric is order conversion rate (Orders/Users). The denominator matches the randomization unit. No DENOM error.

**NOVELTY Check**: Daily lift drops from 14.2% to -0.2% over 9 days. The team projects the current average (or final) lift over 12 months despite this clear fading trend. This ignores the novelty effect wearing off. **NOVELTY flagged.**

ERRORS: PEEK, POWER, NOVELTY
DECISION: HOLD
