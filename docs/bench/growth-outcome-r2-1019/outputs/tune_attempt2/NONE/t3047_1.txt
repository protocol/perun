**SRM Check**: Total users = 35,473 + 36,445 = 71,918. Expected per arm = 35,959.
Difference = |35,473 - 35,959| = 486.
Standard Error (SE) for 50/50 split ≈ $\sqrt{N \times 0.5 \times 0.5} = \sqrt{17,979.5} \approx 134$.
Z-score = $486 / 134 \approx 3.6$. A Z-score > 1.96 indicates a significant mismatch. The split is not 50/50 by chance; assignment or logging is broken. **SRM flagged.**

**PEEK Check**: Planned duration was 14 days. The readout date is Jan 18, start Jan 8. This is 10 days of data (inclusive). The test was stopped 4 days early. Stopping before the planned duration inflates false positives. **PEEK flagged.**

**POWER Check**: The smaller arm (Control) has 35,473 users.
Baseline rate = 5.0%, Target lift = 10% (absolute 0.5%).
Using standard approximation for sample size per arm: $n \approx 16 \times p(1-p) / \delta^2$.
$n \approx 16 \times 0.05 \times 0.95 / (0.005)^2 = 0.76 / 0.000025 = 30,400$.
The actual sample (35,473) exceeds the required ~30,400. The test is adequately powered. **POWER not flagged.**
