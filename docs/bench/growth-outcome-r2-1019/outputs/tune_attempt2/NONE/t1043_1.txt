**SRM Check**: Planned split is 50/50. Total users = 18,148 + 18,012 = 36,160. Expected per arm = 18,080.
Control deviation: (18,148 - 18,080) / 18,080 ≈ 0.38%.
Treatment deviation: (18,012 - 18,080) / 18,080 ≈ -0.38%.
This difference is well within standard chance variation for this sample size. No SRM.

**PEEK Check**: Started July 11, planned 14 days implies an end around July 25. Final readout is July 26. The test ran for the full planned duration (actually 15 days of data shown). No evidence of early stopping. No PEEK.

**POWER Check**: The test detected a massive lift (27.4% vs 10% target) with a p-value reported as 0.0. The sample size was sufficient to detect the effect. No POWER issue.

**SIMPSON Check**:
Control Desktop Rate: 505 / 7,524 ≈ 6.71%
Treatment Desktop Rate: 534 / 7,467 ≈ 7.15% (Lift positive)
Control Mobile Rate: 221 / 10,624 ≈ 2.08%
Treatment Mobile Rate: 233 / 10,545 ≈ 2.21% (Lift positive)
Both segments show a positive lift, consistent with the pooled result. No SIMPSON.

**DENOM Check**: Randomization unit is User ID. The metric is "order conversion rate."
Control: 726 orders / 18,148 users = 3.99%.
Treatment: 767 orders / 18,012 users = 4.26%.
However, the readout reports Control 3.094% and Treatment 3.941%.
Let's check sessions as the denominator:
Control: 726 / 23,461 ≈ 3.094%.
Treatment: 767 / 19,464 ≈ 3.941%.
The reported rates use **Sessions** as the denominator, but users were randomized by **User ID**. Since users can have multiple sessions, the analysis unit (session) does not match the randomization unit (user), violating independence assumptions. This is a DENOM error.

**NOVELTY Check**: Daily lift drops from 64.9% (Day 1) to 9.3% (Day 15). The trend is sharply fading. The team projects the current aggregate lift (heavily weighted by early high values) for the next twelve months. This ignores the decay trend, assuming a lasting effect despite evidence of novelty wearing off. This is a NOVELTY error.

ERRORS: DENOM, NOVELTY
DECISION: HOLD
