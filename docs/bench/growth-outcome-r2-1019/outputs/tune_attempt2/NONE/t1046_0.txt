**SRM Check**: Total users = 463,876. Expected per arm = 231,938.
Control deviation: $|233,567 - 231,938| = 1,629$.
Standard Error (SE) for binomial $n=463,876, p=0.5$: $\sqrt{463876 \times 0.5 \times 0.5} \approx 340$.
Z-score: $1629 / 340 \approx 4.79$. This exceeds the threshold (typically $|Z| > 2$), indicating a significant Sample Ratio Mismatch. Assignment or logging is likely broken.

**PEEK Check**: Planned duration was 21 days. The readout date (April 6) is only 12 days after the start (March 25). The test was stopped early, inflating false positive risk.

**POWER Check**: The smaller arm (Treatment, 230,309) is very close to the expected size. With a baseline of 4% and target lift of 5%, the required sample size per arm is roughly $(1.96+0.84)^2 \times (0.04 \times 0.96 + 0.042 \times 0.958) / (0.002)^2 \approx 215,000$. The actual sample sizes exceed this, so it is not underpowered based on the final counts, though the early stop complicates this. However, since SRM and PEEK are already flagged, this is secondary.

**SIMPSON Check**:
Desktop Control Rate: $6,361 / 102,918 \approx 6.18\%$. Treatment: $6,606 / 101,483 \approx 6.51\%$. (Lift positive)
Mobile Control Rate: $2,982 / 130,649 \approx 2.28\%$. Treatment: $3,097 / 128,826 \approx 2.40\%$. (Lift positive)
Both segments show positive lift; no reversal observed.

**DENOM Check**: Randomization was by user ID. The metric is "order conversion rate." The counts provided for the metric calculation (Orders / Users) align with the randomized unit. No obvious denominator mismatch in the summary stats provided.

**NOVELTY Check**: Daily lift drops from 13.2% to ~2.0% by day 11. The team projects the current aggregate lift (5.3%) for 12 months despite this clear fading trend. This is a Novely effect error.

Multiple critical errors exist: SRM invalidates the randomization assumption, PEEK invalidates the p-value, and NOVELTY invalidates the long-term projection.

ERRORS: SRM, PEEK, NOVELTY
DECISION: HOLD
