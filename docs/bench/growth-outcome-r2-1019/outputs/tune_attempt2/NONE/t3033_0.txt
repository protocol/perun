**SRM Check**: Total users = 34,539 (Control) + 34,723 (Treatment) = 69,262. Expected per arm = 34,631.

Z-score = $92 / 131.6 \approx 0.7$. This is well within chance limits (typically $|Z| > 1.96$). No SRM.

**PEEK Check**: Planned duration was 14 days. The readout date is 2026-08-24, and the start date was 2026-08-14. This is exactly 10 days of data. The test was stopped 4 days early. Stopping before the planned duration based on observed significance inflates false positives. **PEEK flagged.**

**POWER Check**: The smaller arm (Control) has 34,539 users. With a 5% baseline and 10% target lift, standard power calculations usually require ~30k-40k users per arm for 80% power at $\alpha=0.05$. Since the observed sample size exceeds typical requirements for these parameters, and the result is significant, underpowering is not the primary error evident here.

**DENOM Check**: Randomization was by user ID. The metric is "order conversion rate." The counts provided for the calculation imply orders per user ($1,727 / 34,539 \approx 5.0\%$? Wait, the reported rate is 3.795%).
