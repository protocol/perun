**SRM Check**: Total users = 36,074 (Control) + 37,146 (Treatment) = 73,220. Expected per arm = 36,610.
Difference = 37,146 - 36,610 = 536.
Standard Deviation $\approx \sqrt{73220 \times 0.5 \times 0.5} \approx 135$.
Z-score $\approx 536 / 135 \approx 3.97$. A Z-score > 2 indicates a significant mismatch. The split is not 50/50 by chance; assignment or logging is likely broken. **Flag SRM.**

**PEEK Check**: Planned duration was 21 days. The readout date (Sept 9) is only 14 days after the start (Aug 26). The test was stopped 7 days early. Stopping before the planned duration inflates false positives. **Flag PEEK.**

**POWER Check**: The test detected a significant result (p=0.0153). While the sample sizes are slightly uneven, the effective sample size is large enough to have detected the target lift (evidenced by the significant p-value). No underpowering error is demonstrated by the outcome.

Assuming "conversion rate" implies orders per user (standard for user-randomized tests), the denominator matches the randomization unit. If it were orders per session, it would be an error, but the data provided (users vs orders) supports the standard interpretation. No clear evidence of mismatch.
