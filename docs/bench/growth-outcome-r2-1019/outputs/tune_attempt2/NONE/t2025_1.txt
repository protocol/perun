First, I check for Sample Ratio Mismatch (SRM). The total user count is 74,724 (control) + 74,454 (treatment) = 149,178. The expected split is 50%, so 74,589 per arm. The observed difference is |74,724 - 74,589| = 135 users. The standard error for the difference in proportions is $\sqrt{N \cdot 0.5 \cdot 0.5} \approx \sqrt{37294} \approx 193$. The deviation (135) is less than 2 standard deviations (386), so the split is statistically consistent with 50/50. No SRM.

Next, I check for PEEK (early stopping). The test started June 13 and ended July 1. This is 18 days of data. The planned duration was 28 days. Stopping at day 18 instead of day 28 constitutes early stopping before the planned duration, which inflates false positive rates. This is a clear PEEK error.

Then, I check POWER. The sample size per arm is ~74,500. With a baseline of 5% and target lift of 5% (absolute difference 0.25%), standard power calculations suggest ~64,000 users per arm are needed for 80% power at alpha 0.05. Since 74,500 > 64,000, the test is adequately powered. No POWER error.

I check SIMPSON's paradox by calculating segment conversion rates.
Desktop Control: 2,315 / 28,788 ≈ 8.04%. Desktop Treatment: 2,426 / 28,684 ≈ 8.46%. Lift is positive.
Mobile Control: 1,421 / 45,936 ≈ 3.09%. Mobile Treatment: 1,489 / 45,770 ≈ 3.25%. Lift is positive.
Both segments show a positive lift, consistent with the pooled result. No SIMPSON error.

I check DENOM. The metric is order conversion rate. The randomization unit is user ID. The readout provides orders per users (e.g., 3,736 orders / 74,724 users). While sessions are listed, the conversion rate calculation implicitly or explicitly uses users as the denominator if calculated as orders/users. If calculated as orders/sessions, the denominator (sessions) is not the randomized unit (users), which would be a DENOM error. However, the reported control rate is 5.0%. 3,736/74,724 = 5.00%. 3,736/99,791 = 3.74%. Since the reported 5.0% matches the user-based calculation, the denominator matches the randomization unit. No DENOM error.

I check NOVELTY. The daily lift data shows fluctuations (4.6% to 6.0%) but no clear fading trend over the 18 days; the last few days are 5.0%, 5.5%, 6.0%. There is no evidence of fading. No NOVELTY error.

The only identified error is PEEK due to stopping 10 days early.

ERRORS: PEEK
DECISION: HOLD
