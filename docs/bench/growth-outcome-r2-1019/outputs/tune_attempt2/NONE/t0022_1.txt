**DENOM Check**: Randomization unit is "user id". The metric is "order conversion rate".
Control: 4,531 orders / 56,637 users = 8.00%.
Treatment: 4,846 orders / 56,323 users = 8.60%.
However, the readout reports: Control 6.258%, Treatment 8.436%.
Let's check sessions as the denominator:
Control: 4,531 / 72,408 sessions = 6.258%.
Treatment: 4,846 / 57,445 sessions = 8.436%.
The reported percentages use **sessions** as the denominator, but users were randomized. If treatment users generate fewer sessions (57k vs 72k), dividing by sessions inflates the rate artificially. This is a denominator mismatch. **DENOM** flagged.
