**SRM Check**: Total users = 259,699 (Control) + 259,899 (Treatment) = 519,598. Expected per arm = 259,799. Observed difference is only 200 users. This is well within random chance for this sample size. No SRM.

**PEEK Check**: Planned duration was 28 days. The readout date is 2026-08-30, and the start date was 2026-08-02. This covers exactly 28 days. The test ran for the full planned duration. No PEEK.

**POWER Check**: The smaller arm has ~260k users. With a 3% baseline and 5% target lift, standard calculators indicate ~30k–40k users per arm are needed for 80% power. The sample size is vastly larger than required. No POWER issue.

**SIMPSON Check**: Let's verify segment consistency.
Desktop Control Rate: 4,917 / 99,049 ≈ 4.96%
Desktop Treatment Rate: 5,180 / 99,126 ≈ 5.23% (Lift positive)
Mobile Control Rate: 2,874 / 160,650 ≈ 1.79%
Mobile Treatment Rate: 3,027 / 160,773 ≈ 1.88% (Lift positive)
Both segments show a positive lift. The aggregate lift is also positive. No reversal exists. No SIMPSON.

**DENOM Check**: Randomization unit is "user id". The metric is "order conversion rate".
Reported Control Rate: 7,791 orders / 259,699 users = 2.999% (~3.0%).
However, the readout reports "2.324%".
Let's check sessions as the denominator: 7,791 / 335,229 = 2.324%.
The reported metric divides orders by *sessions*, but users were randomized by *user id*. Sessions are not the randomized unit; a single user can have multiple sessions, violating the independence assumption if analyzed at the session level without correction. The denominator (sessions) does not match the randomization unit (users). This is a DENOM error.

**NOVELTY Check**: The daily lift starts high (29.6%–33.4%) in the first few days and steadily declines to single digits (4.6%–5.7%) by the end of the test. Despite this clear fading trend, the team projects the current aggregate lift (heavily influenced by early novelty) for the next twelve months. This ignores the decay pattern evident in the data. This is a NOVELTY error.

ERRORS: DENOM, NOVELTY
DECISION: HOLD
