**POWER Check**: Baseline 8%, target lift 10% (absolute diff 0.8%).
Sample size per arm ~23,400.
Using standard approximation, detecting a 0.8% lift from 8% baseline at 80% power/0.05 alpha requires roughly $16 \times p(1-p) / \delta^2$.
$16 \times 0.08 \times 0.92 / (0.008)^2 \approx 1.1776 / 0.000064 \approx 18,400$ users per arm.
Actual users (~23,400) > Required (~18,400). The test is adequately powered. No POWER error.

Mobile Control Rate: $650 / 15,240 \approx 4.27\%$.
