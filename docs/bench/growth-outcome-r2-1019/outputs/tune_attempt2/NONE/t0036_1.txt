**SRM Check**: The planned split is 50/50. Total users = 160,301 + 156,935 = 317,236. Expected per arm = 158,618.
Control deviation: (160,301 - 158,618) / 158,618 ≈ +1.06%.
Treatment deviation: (156,935 - 158,618) / 158,618 ≈ -1.06%.
With ~317k samples, a 1% deviation is statistically significant (standard error ≈ 0.18%, Z-score > 5). The assignment or logging is likely broken. **Flag SRM.**

**PEEK Check**: Planned duration was 21 days. The readout date is April 4, and data covers "day 1 to day 23". The test ran for 23 days, exceeding the planned 21. There is no evidence of early stopping; if anything, they overshot. **Do not flag PEEK.**

**POWER Check**: Baseline 3.0%, target lift 8% (detecting 3.24%). Both arms have >150k users. This sample size is easily sufficient to detect an 8% lift with 80% power at alpha 0.05. **Do not flag POWER.**

**SIMPSON Check**:
Control Desktop Rate: 3,230 / 61,168 ≈ 5.28%
Treatment Desktop Rate: 3,329 / 59,884 ≈ 5.56% (Lift positive)
Control Mobile Rate: 1,579 / 99,133 ≈ 1.59%
Treatment Mobile Rate: 1,627 / 97,051 ≈ 1.68% (Lift positive)
Both segments show a positive lift, consistent with the pooled result. No reversal observed. **Do not flag SIMPSON.**

**DENOM Check**: Randomization was by user id. The metric is order conversion rate (Orders / Users). The denominator matches the randomization unit. **Do not flag DENOM.**

**NOVELTY Check**: The daily lift starts at 13.2% and decays steadily to 0.3% by day 23. The team recommends rolling out based on the aggregate 5.3% lift and projecting it for twelve months. This ignores the clear fading trend, assuming a transient novelty effect is permanent. **Flag NOVELTY.**

DECISION: HOLD
