**SRM Check**: Total users = 146,340 (Control) + 146,746 (Treatment) = 293,086. Expected per arm = 146,543. The difference is roughly 200 users, which is well within random chance for this sample size. No SRM.

**PEEK Check**: Planned duration was 14 days; the readout is from day 8 (Oct 7 to Oct 15). The test was stopped early. The daily lift shows a sharp decay from 10.9% to 0.7%, suggesting the team may have peeked and stopped once significance was reached or momentum faded. This matches the PEEK definition.

**POWER Check**: With ~146k users per arm and a 6% baseline, the sample is large enough to detect a 5% lift with 80% power. No underpowering.

**SIMPSON Check**:
Control Rate Desktop: 5,841 / 57,398 ≈ 10.18%
Treatment Rate Desktop: 6,891 / 72,124 ≈ 9.55%
(Lift is negative here).

Control Rate Mobile: 2,940 / 88,942 ≈ 3.31%
Treatment Rate Mobile: 2,316 / 74,622 ≈ 3.10%
(Lift is negative here too).

Both segments show a negative lift (Treatment < Control), yet the pooled report claims a positive 4.6% lift. This is a clear reversal caused by the imbalance in device mix (Treatment has more high-converting Desktop users). This is Simpson's Paradox.

**DENOM Check**: Randomization was by user ID. The metric is order conversion rate. Assuming this is orders per user (8,781/146,340), the denominator matches the randomization unit. If it were orders per session, it would be an error, but standard "conversion rate" usually implies per user in this context unless specified otherwise. Given the clear Simpson's paradox, we focus on that. However, looking closely: 8,781/146,340 = 5.99% and 9,207/146,746 = 6.27%. The math holds for user-based denominators. No DENOM error.

**NOVELTY Check**: The daily lift decays rapidly (10.9% down to 0.7%). The team projects this transient lift over 12 months. This assumes the effect is permanent despite the fading trend, fitting the NOVELTY error.

The analysis contains multiple critical errors: early stopping (PEEK), a complete reversal of trends in subgroups vs aggregate (SIMPSON), and projecting a fading effect as permanent (NOVELTY). The positive result is an artifact of these errors.

ERRORS: PEEK, SIMPSON, NOVELTY
DECISION: HOLD
