First, I check for Sample Ratio Mismatch (SRM). The total users are 56,320 (control) + 56,362 (treatment) = 112,682. The expected split is 56,341 per arm. The difference is only 42 users, which is well within random chance for this sample size. No SRM.

Next, I check for Simpson's Paradox (SIMPSON) by calculating conversion rates per device segment.
Desktop Control: 3,112 / 22,601 ≈ 13.77%
Desktop Treatment: 3,755 / 29,626 ≈ 12.67%
Here, the control performs better than treatment (13.77% > 12.67%).

Mobile Control: 1,394 / 33,719 ≈ 4.13%
Mobile Treatment: 1,017 / 26,736 ≈ 3.80%
Here, the control also performs better than treatment (4.13% > 3.80%).

However, the reported aggregate data shows:
Control Total: 4,506 / 56,320 ≈ 8.00%
Treatment Total: 4,772 / 56,362 ≈ 8.47%
The aggregate suggests the treatment is better, while every individual segment shows the control is better. This is a clear reversal caused by the uneven distribution of users across devices (treatment has more high-converting desktop users). This flags SIMPSON.

I check PEEK: The test ran from March 3 to March 25 (22 days), exceeding the planned 21 days. There is no evidence of early stopping based on the dates provided.

I check POWER: The sample sizes are large (~56k per arm), baseline is 8%, and target lift is 8%. With ~4,500 events per arm, the test is sufficiently powered to detect the target lift.

I check DENOM: The metric is order conversion rate. The denominator should be users (the randomization unit). The readout implies user-level conversion (orders/users), which matches the randomization unit. Even if calculated by session, the paradox exists at the user level counts provided.

I check NOVELTY: The daily lift fluctuates (4.7% to 7.0%) but shows no consistent fading trend over the 22 days; the final days are not systematically lower than the start.

The critical error is SIMPSON. Aggregating the data masks that the treatment actually underperforms in both desktop and mobile segments. Rolling this out would likely decrease overall conversion.

ERRORS: SIMPSON
DECISION: HOLD
