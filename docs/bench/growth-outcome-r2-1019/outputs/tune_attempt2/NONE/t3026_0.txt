**SRM Check**: Total users = 139,509 (Control) + 139,293 (Treatment) = 278,802. Expected per arm = 139,401.
Difference = 139,509 - 139,401 = 108.
Standard Error (SE) for binomial split ≈ $\sqrt{N \cdot 0.5 \cdot 0.5} = \sqrt{278802 \cdot 0.25} \approx 264$.
The difference (108) is less than 2 SEs (~528). The split is statistically consistent with 50/50. No SRM.

**PEEK Check**: Start date 2026-09-10, readout 2026-10-10. Duration = 30 days.
Planned duration was 28 days. The test ran *longer* than planned, not shorter. No PEEK.

**POWER Check**: The test detected a significant result (p=0.0) with ~139k users per arm. Since the effect was detected with high significance, the study was not underpowered for the observed effect. No POWER error evident from the outcome.

**SIMPSON Check**: Calculate segment conversion rates (Orders/Users):
Desktop Control: $4,432 / 56,065 \approx 7.90\%$
Desktop Treatment: $4,659 / 55,978 \approx 8.32\%$ (Lift positive)
Mobile Control: $2,544 / 83,444 \approx 3.05\%$
Mobile Treatment: $2,674 / 83,315 \approx 3.21\%$ (Lift positive)
Both segments show positive lift, matching the pooled positive lift. No reversal. No SIMPSON.

**DENOM Check**: Randomization unit: User ID. Reported metric: Order conversion rate.
Calculation check: Control Orders/Users = $6,976 / 139,509 \approx 5.00\%$.
However, the readout reports Control conversion as **3.444%**.
Let's check Sessions as denominator: $6,976 / 202,544 \approx 3.444\%$.
The reported metric uses **Sessions** as the denominator, but users were randomized. If a user generates multiple sessions, the independence assumption is violated, and the denominator does not match the randomization unit. This is a DENOM error.

**NOVELTY Check**: Daily lift starts at 18.2% and trends downward to ~3-6% by the end (days 28-30).
The team projects the **reported** aggregate lift (10.2%) for the next twelve months. Since the aggregate includes the high early novelty lift, projecting this average forward ignores the clear fading trend visible in the daily data. This overstates long-term value. This is a NOVELTY error.

ERRORS: DENOM, NOVELTY
DECISION: HOLD
