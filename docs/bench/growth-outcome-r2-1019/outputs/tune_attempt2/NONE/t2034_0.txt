**SRM Check**: Total users are 76,123 (Control) and 76,269 (Treatment). Total = 152,392. Expected per arm = 76,196.
Difference = 73 users.
Standard Deviation for binomial split $\approx \sqrt{152392 \times 0.5 \times 0.5} \approx 195$.
The difference (73) is well within 2 standard deviations ($< 390$). The split is consistent with 50/50 randomization. No SRM.

**PEEK Check**: Start date 2026-02-25, end date 2026-03-25. This is exactly 28 days (accounting for 2026 being a non-leap year, Feb has 28 days: 3 days in Feb + 25 in March = 28 days). The test ran for the planned duration. No PEEK.

**POWER Check**: The test detected a significant result (p=0.0) with a large sample size (>76k per arm). The observed lift (14.6%) exceeded the target (8%). The test was clearly powerful enough to detect the effect. No POWER issue.

**DENOM Check**: Randomization was by user ID. The metric is "order conversion rate." The readout provides user counts and order counts. Typically, conversion rate is Orders/Users or Orders/Sessions.
If Orders/Users: Control $3,045/76,123 \approx 4.0\%$. Treatment $3,220/76,269 \approx 4.2\%$.
However, the reported rates are ~3.0% and ~3.4%.
Let's check Orders/Sessions: Control $3,045/101,641 \approx 2.996\%$. Treatment $3,220/93,806 \approx 3.433\%$.
The reported numbers match the session-based calculation. Since users were randomized but the denominator is sessions, and session counts differ significantly between arms (101k vs 93k) despite equal user counts, the metric denominator (sessions) is not the unit of randomization (users). This violates the unit of analysis assumption if session volume is affected by the treatment. Flag DENOM.

**NOVELTY Check**: Daily lift starts at 27.7% and trends downward to 6.4% by day 28. There is a clear decay pattern. The team projects the current aggregate lift (which includes the high early days) for the next 12 months. This ignores the fading effect, assuming the initial spike persists. Flag NOVELTY.

ERRORS: DENOM, NOVELTY
DECISION: HOLD
