**Direct Answer to Your Questions**

1.  **Does the absence of a real-time provider disqualify the session?**
    Yes, for standard psychotherapy codes (e.g., CPT 90832–90838), "interactive complexity" and direct therapeutic intervention by a qualified healthcare professional are mandatory requirements. These codes bill for the *provider's time and skill*, not the software usage. If a patient uses MindVR at home without a therapist present via telehealth or in-person, there is no billable provider service to attach the code to. Insurance pays for the clinician's treatment, not the patient's self-administered tool.

2.  **Are there specific modifiers or new codes for autonomous digital therapeutics?**
    There is currently no universal CPT code that reimburses a patient directly for using autonomous VR software without provider oversight.
    *   **Remote Therapeutic Monitoring (RTM):** Codes like 98975–98977 allow reimbursement for monitoring non-physiologic data (like engagement with a therapeutic device), but these still require a provider to interpret the data and manage the care plan. They do not cover the software session itself as a standalone product.
    *   **Digital Therapeutics (DTx):** While the FDA has cleared some "prescription digital therapeutics" (PDTs), coverage is inconsistent. Some private payers cover specific FDA-cleared DTx products via a unique HCPCS code or a temporary pass-through, but this requires a specific prescription and often still involves some level of provider management. It is not an automatic right for any VR app.
    *   **Modifiers:** Modifiers generally indicate *how* a service was performed (e.g., via telehealth), but they cannot create a billable event where the core requirement (provider presence) is missing.
