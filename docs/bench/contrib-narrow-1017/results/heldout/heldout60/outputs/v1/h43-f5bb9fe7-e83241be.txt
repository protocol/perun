**Direct Answer to Your Uncertainty**
You are unsure if random data reflects real gains. **It does**, provided the *statistical properties* (data volume, type distribution, and complexity) match your internal scenario. Performance improvements in algorithmic logic (like your 15% gain) usually stem from reduced complexity or better memory access patterns, which will manifest on synthetic data of equivalent size and shape. You do not need real customer values to prove the algorithm is faster; you only need data that stresses the code in the same way.
