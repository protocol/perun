*   **Actual Bug Behavior:** The third occurrence shifts by one hour (e.g., appearing at 02:30 or 00:30) because the library fails to re-evaluate the offset for the new date.

**2. Test Implementation Structure**
Write the test to assert the *wall-clock time* consistency. Do not assert UTC timestamps directly, as the bug manifests as a mismatch between local time and UTC conversion.

```javascript
it('should maintain consistent wall-clock time across DST boundary', () => {
  // Arrange: Synthetic event starting just before DST spring-forward
  const event = {
    title: 'Synthetic Weekly Recurrence',
    start: '2023-03-12T01:30:00', // 1:30 AM EST
    timeZone: 'America/New_York',
    rrule: 'FREQ=WEEKLY;COUNT=3'
  };

  // Act: Generate occurrences

  // Assert: All occurrences must happen at 01:30 local time
```
