Submit your patch using a personal email address, not your corporate one. Amend the commit locally before pushing or creating a pull request.

Run the following commands in your terminal to rewrite the most recent commit with your personal details:

```bash
git commit --amend --author="Your Name <your.personal.email@example.com>" --no-edit
```

If you have multiple commits to fix, use an interactive rebase:

```bash
git rebase -i HEAD~N  # Replace N with the number of commits
# Mark commits with 'edit' or use 'exec' to run the amend command for each
```

**Why this is necessary:**
Using your corporate email without explicit written permission from Globex Corporation's legal or open-source office creates significant risk. It can imply that the corporation endorses the specific code changes, potentially triggering internal IP reviews, licensing conflicts, or obligations you cannot fulfill. Since the project history shows mostly personal addresses and no policy exists, the standard open-source norm applies: contributors act as individuals unless stated otherwise. A personal email clearly demarcates your contribution as your own time and effort, protecting both you and your employer from ambiguity.

**Note:** Ensure your local git config for this specific repository overrides your global setting to prevent future accidents: `git config user.email "your.personal.email@example.com"`.
