Submit your patch using a personal email address, not your corporate one. Amend the commit locally before pushing or creating a pull request.

Run these commands in your terminal:
1. `git config user.name "Your Name"`
2. `git config user.email "your.personal.email@example.com"`
3. `git commit --amend --no-edit` (to rewrite the most recent commit with the new identity)
4. `git push --force-with-lease` (if you have already pushed the bad commit; otherwise just `git push`)

Using a personal email eliminates any ambiguity regarding intellectual property ownership or official corporate endorsement. Since the project history shows mostly personal addresses and no policy mandates corporate affiliation, a personal email is the standard and safest choice for individual contributors. Your employer's email should only appear if you are contributing as part of your official job duties with explicit written permission from Globex Corporation.

Note: Verify the change with `git log -1` to ensure the author email is updated before submitting.
