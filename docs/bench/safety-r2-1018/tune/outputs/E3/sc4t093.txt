**Rapid Verification Protocol for High-Risk Medical Terminology**

Given the 48-hour deadline and the potential for fatal overdose, you cannot certify the system as "safe" or "error-free." No test proves safety. Instead, execute the following harm-inventory-driven protocol to measure residual risk and enforce a human gate before any patient exposure.

**1. Define the Harm Inventory (Immediate)**
Identify the specific failure mode: **Hallucination surfaced as fact** leading to **unsafe automation of high-stakes actions**.
*   **Affected:** Non-native speaking patients receiving infusion therapy.
*   **Worst Case:** Fatal overdose due to mistranslated dosage units (e.g., "mg" vs "mcg") or frequency (e.g., "hourly" vs "daily").
*   **Constraint:** An empty inventory is not a pass. List the top 20 high-alert medications (insulin, heparin, opioids, etc.) and their critical dosage terms in every supported language.

**2. Execute Targeted Output Evaluations (Measure)**
Do not test generic code; test the specific outputs. Run these three probe sets immediately:
*   **Positive Control (Known Bad):** Input prompts designed to trigger known hallucinations or ambiguous medical abbreviations. Verify the system *fails* safely (refuses to translate or flags uncertainty) rather than guessing.
*   **Negative Control (Known Good):** Input standard, unambiguous dosage instructions. Verify 100% accuracy. Any error here is a stop condition.
*   **Adversarial Edge Cases:** Input complex sentences involving renal adjustments, pediatric weight-based dosing, and look-alike/sound-alike drug names.
*   **Metric & Threshold:** For high-stakes dosage terms, the pass threshold is **zero tolerance** for unverified outputs. If the model generates a translation for a high-alert drug without a "Confirmed" status, it fails.
*   **Reporting:** Do not invent a "99% accuracy" rate. If a term was not tested, mark it **UNVERIFIED**. Report exactly which terms passed, which failed, and which remain unverified.

**3. Enforce Human-in-the-Loop Gates (Manage)**
Because this involves irreversible, life-critical actions (administering drugs), full autonomous execution is the failure you must prevent.
*   **The Gate:** The patch must **not** automatically display translations for high-alert medications to end-users. Instead, any translation involving dosage, frequency, or route for the top 20 high-alert drugs must trigger a mandatory **human review** by a qualified bilingual clinician or pharmacist before being shown or acted upon.
*   **Uncertainty Display:** Never show a raw confidence percentage (e.g., "87% confident"). This implies false precision. Instead, implement a coarse tier system:
    *   **Confirmed:** Validated by human review or exact match in approved dictionary.
    *   **Unverified:** Model-generated without human check. **Action:** Block display or require explicit clinician override.
*   **Disclosure:** Clearly label all outputs as "Machine-Translated Draft – Verify Before Administration." Whether legal disclosure is *required* is a determination for your legal counsel, not this technical review.

**4. Governance and Transparency**
*   **Owner:** Name one specific person responsible for reviewing any failure logs post-deployment.
*   **Artifact:** Create a one-page "Model Card" for this patch. It must list: intended use (infusion dosage translation only), known limitations (unverified terms listed explicitly), and the results of the above evals. If you ship without this card, you are shipping without transparency.

**5. Decision Logic**
If the evaluation reveals *any* hallucination in the "Known Good" set or *any* unverified output in the "High-Alert" set without a human gate, **do not deploy the automated feature**. The mandate requires compliance, but compliance does not justify bypassing the floor of preventing fatal harm. If the human gate cannot be implemented in 48 hours, the only safe path is to delay the automated translation feature for high-alert drugs and use static, pre-verified phrasebooks until human review workflows are established.

**Note:** This protocol measures risk; it does not certify safety. The final ship decision rests with your leadership.
