**Immediate Mitigation Plan (Execute in this order):**

1.  **Disable All Third-Party Analytics and External Logging:** Immediately strip out all SDKs and code paths sending data to external analytics providers (e.g., Google Analytics, Mixpanel, Datadog) or external log aggregators. These are the primary vectors for data leakage. If you cannot verify exactly where every byte of data goes, assume it is leaving your control.
2.  **Implement Client-Side Data Stripping (No Infra Change):** Modify the chatbot frontend code to prevent sensitive data from ever leaving the user's device in the first place.
    *   **Location:** Do not request or transmit GPS coordinates. If location is essential for resource matching, require users to manually select a city or region from a static dropdown list embedded in the app.
    *   **PII Redaction:** Implement a local pre-processing step in the client application that scans user input for patterns resembling names, phone numbers, or specific addresses and blocks the message from sending if detected, prompting the user to rephrase.
3.  **Adopt a "Data Minimization" Architecture:** Re-architect the feature to be stateless regarding sensitive history.
    *   Do not store conversation logs on your servers. Process the request in memory to generate the response and immediately discard the input and output.
    *   If logs are legally required for debugging, configure your existing cloud infrastructure to hash or truncate all input data before writing to disk, ensuring the original text is unrecoverable.
4.  **Manual Human-in-the-Loop for High-Stakes Advice:** For any response involving legal aid or shelter locations, do not rely solely on automated generation. Route these specific queries to a dashboard where a verified human operator reviews and approves the resource link before it is sent to the user. This prevents hallucinated or dangerous advice.
5.  **Transparent Disclosure:** Clearly state to users what data you *do not* collect (e.g., "We do not track your location or save your chat history") and what the limitations of the tool are.
