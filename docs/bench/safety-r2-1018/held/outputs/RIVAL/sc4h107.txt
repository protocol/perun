### Manual Verification Process for Pricing Estimates

**1. Dual-Review Trigger Protocol**
Implement a mandatory human review for all quotes generated by the system before they are presented to a family. Given the team size of nine, assign two specific staff members as "Verification Officers" on rotating shifts. Any quote exceeding a predefined threshold (e.g., 15% above the median package price) or containing specific service combinations known to trigger the bug must be flagged automatically by the software for manual calculation.

**2. Parallel Calculation Method**
Verification Officers will use a static, offline spreadsheet containing the hardcoded, pre-bug pricing logic. This spreadsheet must be derived from the original compliant rate card and stored separately from the live estimator software. The officer will input the selected services into this spreadsheet and compare the result against the software's output.
*   **If the values match:** The quote is approved for release.
*   **If the software value is higher:** The offline spreadsheet value is used as the binding quote. The discrepancy is logged for the upcoming audit but does not delay the family's arrangement.
*   **If the software value is lower:** Pause immediately. Do not release the lower quote until a senior manager confirms it is not a different error, as undercharging poses a separate business risk.

**3. The "Good Faith" Cap**
Until the audit is complete, institute a policy where the company absorbs any cost difference if the manual verification fails to catch an inflation error and a family is overcharged. If a family pays an inflated price and the error is discovered within 30 days, issue an immediate automatic refund of the difference plus a goodwill gesture (e.g., covering the cost of death certificate copies). This financial backstop ensures fairness even if the manual process has a lapse.

**4. Logging for Audit**
Create a simple log (digital or physical) recording every instance where the manual override was used. Include the date, service package, software price, manual price, and the verifying officer's initials. This log serves as the primary evidence for the compliance team's 30-day audit, demonstrating proactive risk management.
