### Safety Evaluation Plan: Proctoring AI Behavioral Bias Audit

**Objective:** Quantify false positive rates across neurodivergent behavioral patterns using the existing model and identify non-training configuration adjustments to mitigate bias before deployment.

#### Phase 1: Synthetic Behavioral Baseline (Weeks 1-2)
Since live student testing is ethically restricted and budget is unavailable, construct a "Synthetic Behavioral Corpus" using video fixtures or simulated input streams that represent specific behavioral archetypes. Do not use real student data.

**Test Categories to Simulate:**
1.  **Stimming/Self-Regulation:** Repetitive hand movements, rocking, or fidgeting.
2.  **Gaze Patterns:** Avoidance of direct eye contact, looking away while thinking, or rapid eye movement.
3.  **Postural Dynamics:** Frequent position changes, standing while working, or non-standard seating positions.
4.  **Verbal/Vocal Tics:** Low-volume muttering, throat clearing, or self-talk.
5.  **Control Group:** Neurotypical "suspicious" behaviors (e.g., looking at a phone) and "normal" behaviors to establish baseline precision/recall.

**Execution Method:**
*   Feed these fixed video streams or sensor inputs into the current proctoring pipeline.
*   Record the system's output: Flag type, confidence score, and timestamp.
*   Calculate the **False Positive Rate (FPR)** for each category against the Control Group.

#### Phase 2: Configuration Stress Testing (Week 3)
Analyze the current configuration files for adjustable thresholds. Most proctoring systems allow tuning without retraining.

**Variables to Adjust & Test:**
*   **Confidence Thresholds:** If the system flags behavior at >60% confidence, test increments (70%, 80%, 90%) to observe the trade-off between missed cheating (False Negatives) and biased flagging (False Positives).
*   **Temporal Windows:** Adjust the duration required to trigger a flag. (e.g., Is a 2-second gaze aversion flagged vs. a 10-second aversion?). Increasing the required duration often filters out transient neurodivergent traits.
*   **Region of Interest (ROI):** If configurable, limit motion detection to the desk surface rather than the upper body/face to ignore hand stimming.
*   **Multi-Modal Correlation:** If the system uses audio + video, check if flags require simultaneous triggers. Decoupling these may reduce false positives caused by vocal tics alone.

**Action:** Run the Synthetic Corpus through each configuration variant. Select the configuration that maximizes the gap between "Cheating" detection and "Neurodivergent Trait" flagging.

#### Phase 3: Human-in-the-Loop Protocol Design (Weeks 4-5)
Since algorithmic perfection is unattainable without retraining, modify the *workflow* rather than just the software.

**Proposed Operational Changes:**
1.  **Tiered Alert System:** Configure the system to categorize flags as "Low Confidence/Review Later" vs. "High Confidence/Immediate Action." Route all flags related to motion/gaze (high bias risk) to the low-priority queue.
2.  **Contextual Metadata:** If possible, inject a "flag reason" code. If the code corresponds to "excessive movement" or "gaze aversion," automatically append a disclaimer to the human reviewer: *"High probability of neurodivergent trait; verify before marking."*
3.  **Opt-Out/Declaration Mechanism:** Implement a pre-exam process where students can self-identify known behavioral patterns. While this doesn't change the AI, it instructs human reviewers to disregard specific automated flags for those candidates immediately.

#### Deliverable: The Bias Impact Report
Compile findings into a report containing:
*   FPR tables per behavioral category for the default vs. optimized config.
*   Recommended threshold settings.
*   A mandatory "Human Review Checklist" for proctors that explicitly lists behaviors known to trigger false positives in this specific deployment.

**Note:** This plan relies entirely on synthetic data to avoid privacy violations during testing. Immediate deployment without the "Human-in-the-Loop" protocol is strongly discouraged given the identified bias risks.
