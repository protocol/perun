This ensures no life-saving message is suppressed without human review, satisfying the safety floor while you build evidence.

**1. Harm Inventory (MAP)**
*   **Harm:** False Positive Blocking (Critical Information Suppression).
*   **Affected:** Disaster victims, relief coordinators, and first responders in Jakarta.
*   **Worst Case:** A request for rescue or a warning about rising floodwaters is classified as "spam" and deleted, leading to preventable loss of life or property.
*   **Status:** High-stakes, irreversible action without a gate is a failure condition.

**2. Measurement Plan (MEASURE)**
Since large-scale simulation is impossible, execute a **targeted adversarial audit** using your team of ten over the next 5 days:
*   **Probe Set Construction:** Manually curate 50 "Known-Good" critical messages (e.g., "Need boat at [Location]," "Bridge collapsed at [Street]") and 50 "Known-Bad" spam/misinformation samples. Include edge cases: mixed language (Bahasa Indonesia/local dialects), urgent tone with typos, and images with text.
*   **Test Execution:** Run these 100 samples through the bot.
*   **Metric & Threshold:**
    *   **Metric:** False Positive Rate on "Known-Good" set.
    *   **Threshold:** **Zero tolerance** for blocking "Known-Good" messages in autonomous mode. If *any* critical message is blocked, autonomous launch is prohibited.
    *   **Stop Condition:** If the bot blocks >0 critical messages, revert to HITL-only mode until the model is retrained or rules are adjusted.
*   **Reporting:** Report the result as **UNVERIFIED** for general safety if the sample size is small. Do not claim "99% accurate." State: "Tested against 50 critical scenarios; X failures observed. Residual risk remains for untested phrasing."

**3. Risk Management (MANAGE)**
*   **The Gate:** Configure the system so that any content flagged as "spam" or "misinformation" is **quarantined**, not deleted. A human operator must review and approve the deletion within 5 minutes. This turns an irreversible error into a reversible delay.
*   **Uncertainty Display:** If the bot outputs a confidence score internally, do not show this to users or operators as a precise percentage (e.g., "87% spam"). Instead, use defined tiers: **"High Confidence Spam"** (auto-quarantine), **"Uncertain"** (flag for immediate human review), and **"Safe"** (pass).
*   **Disclosure:** Clearly label the channel: "Messages are filtered by an automated system to remove spam. Critical alerts are prioritized."

**4. Governance (GOVERN)**
*   **Owner:** Assign one specific engineer as the "Safety Owner" responsible for reviewing any blocked message complaints daily during the monsoon.
*   **Re-review Trigger:** Any reported missed rescue request triggers an immediate pause on autonomous filtering and a model update.
