### Testing Protocol for VR Motion Sickness Triggers

**Objective:** Identify specific visual and locomotion triggers causing motion sickness and falls within fixed hardware constraints to enable targeted refinement before deployment.

**Phase 1: Baseline & Segmentation**
*   **Pre-Screening:** Administer a Motion Sickness Susceptibility Questionnaire (MSSQ) to all test participants. Segment testers into "High," "Medium," and "Low" susceptibility groups to ensure diverse data coverage.
*   **Physiological Baseline:** Record resting heart rate and self-reported comfort levels (0–10 scale) prior to headset donning.

**Phase 2: Isolated Trigger Matrix (The "Micro-Test" Approach)**
Do not test the full simulation initially. Break the experience into isolated 60-second modules to pinpoint exact causes. Test each module sequentially with a 5-minute rest period between trials.
1.  **Locomotion Mechanics:** Test teleportation vs. smooth locomotion vs. vignette-tunneling. Measure latency between user input and visual update.
2.  **Visual Flow & FOV:** Test peripheral motion density. Isolate high-contrast moving textures (e.g., conveyor belts, flashing lights) which often trigger vestibular conflict.
3.  **Acceleration Profiles:** Test constant velocity vs. acceleration/deceleration curves. Sudden changes in virtual gravity or speed are primary nausea inducers.
4.  **Frame Stability:** Since dynamic frame rate adjustment is impossible, test specific static scenes for "judder" or micro-stuttering that occurs even within spec, focusing on complex geometry rendering.

**Phase 3: Measurement & Stop Conditions**
*   **Metrics:**
    *   **Time-to-Onset:** Seconds elapsed before the user reports discomfort.
    *   **SSQ Score:** Administer the Simulator Sickness Questionnaire immediately upon termination of a trial.
    *   **Postural Sway:** Observe and record any loss of balance or reaching for support (fall precursor).
*   **Hard Stop Conditions:** The test ends immediately if the user reports a comfort score ≤ 4, exhibits visible pallor/sweating, requests removal, or loses balance.
*   **Data Logging:** Correlate every symptom report with the specific timestamp and active visual module to create a "Heat Map" of distress triggers.

**Phase 4: Iterative Mitigation & Validation**
*   **Design Fixes:** Apply countermeasures strictly to failed modules (e.g., add a static cockpit reference frame, reduce peripheral field-of-view during movement, smooth acceleration curves, replace high-frequency textures).
*   **Re-Test:** Run the modified module against the "High Susceptibility" group first. The module passes only if the average Time-to-Onset increases by >50% and no postural instability is observed.
*   **Integration Test:** Once individual modules pass, re-integrate them into a 5-minute sequence to check for cumulative fatigue effects.

**Safety & Governance Controls**
*   **Physical Environment:** All testing must occur in a padded area with a spotter physically present to prevent injury from falls. Users must be seated for high-risk modules.
*   **Human-in-the-Loop:** No user proceeds to the next intensity level without explicit verbal confirmation of full recovery from the previous trial.
*   **Disclosure:** Clearly inform all industrial trainees that this is a diagnostic test for physical side effects, not a final training evaluation, to manage expectations and reduce anxiety-induced symptoms.

**Deliverable:** A "Trigger Heat Map" document listing every failed module, the specific visual cause, the severity of reaction observed, and the verified design fix applied.

*Note: Given the severity of reported falls, consider pausing standing tests until seated stability is proven. Consult legal counsel regarding liability waivers for physical injury during testing.*
