**Immediate Guardrails and Escalation Strategy**

**1. Hard Stop Trigger (The "Do No Harm" Gate)**
Implement a deterministic keyword and sentiment filter that immediately halts all career-related generation upon detecting signals of severe distress (e.g., "suicide," "hopeless," "hurt myself," "can't go on"). When triggered, the system must bypass the LLM entirely. Do not rely on the model to decide when to stop; use rigid code rules to intercept these inputs before they reach the generative engine.

**2. Static Crisis Response Protocol**
Replace dynamic advice with a fixed, pre-written response for flagged users. This message must:
*   Explicitly state the AI cannot provide mental health support.
*   Display local, verified emergency contacts prominently (e.g., **Lifeline Australia: 13 11 14**, **Beyond Blue: 1300 22 4636**, **000** for immediate danger).
*   Offer a single, safe option: "Would you like to pause this session?"
*   **Constraint:** Do not generate *any* new text, resume tips, or interview advice in this state. The output must be static to eliminate hallucination risk.

**3. Human-in-the-Loop for Ambiguous Cases**
For inputs that are concerning but do not meet the "hard stop" threshold (e.g., mild anxiety about an interview), flag the conversation for asynchronous human review. Since you lack mental health experts, assign a founding team member to review these logs daily. If a user is flagged twice within a session, escalate automatically to the hard stop protocol.

**4. Mandatory Disclosure and Uncertainty Tiers**
Update the UI to clearly label all outputs as "AI-Generated Career Guidance, Not Professional Advice." Implement a visible confidence tier for advice:
*   **Verified:** Standard resume/interview facts based on your curated database.
*   **Unverified/General:** Broad suggestions where the model lacks specific context.
*   **Never display numerical confidence scores** (e.g., "87% sure") as this creates false precision and encourages over-reliance.

**5. Data Minimization and Privacy**
Do not store chat logs containing distress signals longer than necessary for the immediate session unless explicit consent is given for safety follow-up. Ensure your privacy policy explicitly states that crisis interactions are handled differently than standard career coaching.

**6. The "Unverified" Metric**
Do not claim a "0% risk" of harmful advice. Instead, publish an internal "Harm Inventory" acknowledging that while hard stops cover known keywords, edge cases remain **UNVERIFIED** until tested. Create a simple evaluation set with adversarial prompts (e.g., subtle expressions of despair) to test your filters before launch. If a test case slips through, the hard stop logic must be updated immediately.

**7. Escalation Path Summary**
*   **Level 1 (High Risk):** Hard stop → Static crisis resources → Session pause.
*   **Level 2 (Medium Risk):** Standard advice + Disclaimer + Flag for human review.
*   **Level 3 (Low Risk):** Standard advice + Disclaimer.
