### Fixed
- `parity_differ.py` now loads agentic-delivery's `focus_gate.py` on every Python it supports. `_focus_gate()` ran the module without registering it in `sys.modules`, so its dataclasses failed to build on Python 3.12 and 3.14 (the two versions checked) and the loader returned `None`, while 3.15 loaded it. The accept-file owner check therefore took the inline `git log` fallback on 3.12 and 3.14 but `focus_gate`'s commit-authorship trust on 3.15: trust semantics, including whether `--accept-rev` is required, changed with the interpreter. The loader now registers the module before executing it, reuses an already-loaded `focus_gate` only when it is the same file, and drops the entry when the import fails; a missing or broken `focus_gate.py` still falls back as before. Test: `scripts/test_parity_differ_focus_gate.py` (`RealFocusGateLoad`) calls the real `_focus_gate()` from a fresh-interpreter state and runs the owner-trusted, agent-authored and no-owner cases through it; it fails on the previous loader under 3.12 and 3.14 and passes on 3.12, 3.14 and 3.15.
