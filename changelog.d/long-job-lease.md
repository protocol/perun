### Added
- `job_lease.py run [--name N] [--timeout S] -- CMD` (tests: `scripts/test_job_lease.py`, registered in `scripts/ci-tests.d/job-lease.sh`): a per-repo lease for long jobs (ship scripts, QA runs, merge trains). It is a kernel flock (`serial_gate.py run`) on `<git-common-dir>/perun-job-lease/N/lock`, shared by every worktree, so the owner and every agent queue instead of colliding; the kernel frees it when the holder dies. The child gets `PERUN_RUN_SUFFIX`, and `job_lease.py suffix` prints a fresh `<pid>_<6 hex>` suffix, safe in database, container and directory names. The child also gets `PERUN_JOB_LEASE` (the held lease names), so a nested `job_lease.py run` of the same name runs under the holder's lease instead of deadlocking on it. The lease belongs to the wrapper process: it frees when the wrapper dies, even if the child lives on. Fails closed (exit 2, command never runs) outside a git repo. Field cause (#1574): two long QA runs, one owner and one agent, collided on one database name. `multi-session-coordination.md` names it in its script list.
- A waiter on a lock now prints a queue line at least every 2 minutes (`PERUN_QUEUE_NOTE_SECS`, default 120; a non-integer or non-positive value falls back to 120; `serial_gate.py` accepts a positive float and shows the holder for slot waits too): `train_land.sh` while it waits for the exclusive heavy lease (`queued Ns: another gate holds the exclusive heavy lease; Ns of wait left`), `_lock.sh` `lock_take` (`waiting on lock held by pid ...` repeats instead of printing once), and `serial_gate.py run` (`queued Ns on <lock dir>; holder <owner record>`). Field cause (#1574): hooks and trains sat 17+ minutes on a lock with no progress line; the lease wait in `train_land.sh` was silent for up to `LEASE_WAIT_SECS` (30 minutes by default).

### Verified, no change
- `heavy_gate.py` admits against `host_probe.decide` (load average, free RAM) and the machine-wide lease count, so it already looks at real system load; its denies return at once and never queue. Only `train_land.sh` takes a lease today; `train_flake.sh`, `merge_train.py` and repo ship or QA scripts do not, and can adopt `job_lease.py run` as they are touched.
