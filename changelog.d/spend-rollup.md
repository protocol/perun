### Added
- `token_report.py --rollup DIR` (tests: `scripts/test_spend_rollup.py`, registered in `scripts/ci-tests.d/spend-rollup.sh`): per-project spend across every session in a transcript directory (a `~/.claude/projects/<project>` dir), split main vs lanes. Prints one summary line for status updates (`spend: $X across N sessions, M lanes (main $A, lanes $B)`) plus the costliest sessions (`--top`, `--since`, `--json`). Dollar figures price the merged per-model totals once under the dated default rates; a model with no rate is named `UNPRICED` and never estimated, and an all-unpriced project reads `UNPRICED`, not `$0`; an empty project or window reads `$0.00`, and unreadable lane transcripts are counted in the line and the JSON (`unreadable_lanes`). Before this, a project total meant running the tool once per session and adding by hand.
