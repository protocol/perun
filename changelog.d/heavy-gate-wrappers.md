### Fixed
- `heavy_gate.py` unwraps `timeout [opts] DURATION`, `nohup`, `env [-u NAME]`, `nice [-n N]`, `stdbuf`, `xargs [opts]` and `bash|sh|zsh -c 'STRING'` (any option cluster holding `c`, such as `-lc`) before the heavy check, so `timeout 600 pytest`, `nohup npm test &`, `xargs pytest` and `bash -c "pytest"` are held like a bare run. Path-qualified wrappers (`/usr/bin/env`), `sudo -u USER`, `exec -a`, `time -f`, `uv run --with`, `setsid`, `ionice`, `doas`, `caffeinate -t`, `arch -arch`, `xargs -I{}` and BSD `xargs -J %`, a `--` after the wrapper and value-taking shell options (`bash -o pipefail -c`) are unwrapped too. A `-c` string that does not parse is heavy (fails closed); an unlisted launcher still passes light. `ceo_altitude_guard.py` shares the same unwrapping.
