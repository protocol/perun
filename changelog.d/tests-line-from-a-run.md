### Changed
- The commit-tier gate row in agentic-delivery's `references/roles.md` now asks for a `Tests: X/X` count only when a suite printed it on the staged tree. When the suites run later, in a merge train or in CI, the line reads `Tests: none (<where they run>)`: a count copied from an older tree, another branch or the suite's size is an over-claim. The hand-back check (`handback.py`) reads such a line, a `Tests: none (<place>)` with a non-empty parenthetical, as a stated no-run, so that one line is enough; a bare `Tests: none` still fails, and digits inside the parenthetical are no count. A new eval, `tests-line-only-from-a-run`, pins the rule.
