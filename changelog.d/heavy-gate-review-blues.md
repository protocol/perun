### Fixed
- `agentic-delivery/scripts/heavy_gate.py`: a `grype` target whose name only starts with a subcommand (`grype db:latest`, `grype help.json`, `grype version:latest`) read as the light `grype db|version|help` form and was never held, because the lookahead used `\b` and `:` or `.` is a word boundary. The lookahead now needs the subcommand to be a whole word. A bare `grype` that reads an SBOM from stdin (`syft . -o json | grype`, `(cat sbom.json)|grype`, a pipe followed by a newline, `grype < sbom.json`) is now held, because it scans; a bare `grype` with no pipe or redirect into it stays light.
- `heavy_gate.py`: `npm ci --package-lock-only` was read as light through the lockfile-only exemption, yet `npm ci` removes `node_modules` first, so it is now held. `npm install --package-lock-only` stays light. A bare `npm install --package-lock-only` without `--ignore-scripts` can still run the project's own lifecycle scripts; that ceiling is recorded in a `ponytail:` comment beside `LIGHT_FLAGS`.
- `heavy_gate.py`: `uv tool run`, `yarn dlx`, `bun x` and `npm exec` are now unwrapped like `npx`, `uvx`, `bunx` and `pnpm exec`, so `uv tool run semgrep scan .` or `yarn dlx trivy fs .` is classified by the tool behind the launcher instead of passing light.
- `heavy_gate.py`: a backslash-newline continuation (`semgrep \` newline `scan .`) is joined before the command is classified. The tokenizer used to turn it into a separator, which split `semgrep` from `scan`, so the continued form passed light. The same join applies to `ceo_altitude_guard.py`, which reads commands through `heavy_gate.tokens` and `heavy_gate.segments`. A `#` comment line is left whole, because bash ends a comment at its newline even after a trailing backslash: `# note \` followed by `pytest -q` is still two lines, and `pytest -q` is held. A comment that follows a command on the same line (`echo hi # note`) still swallows the newline after it, so a heavy command on the next line reads light; that was already so before the join and is not changed here.
- `command -v pytest`, `command -v jest`, `command -v vitest` and `command -v playwright` are now pinned as light presence checks in `scripts/test_heavy_gate_scanners.py`; before, only the mutation test for `strip_wrappers` held that early return.

Tests: new tables and cases in `scripts/test_heavy_gate_scanners.py`. The rows that change behaviour fail on the previous `heavy_gate.py`; the stay-light rows (`command -v TOOL`, bare `grype` without stdin, `npm install --package-lock-only`) pin existing behaviour and pass on both.
