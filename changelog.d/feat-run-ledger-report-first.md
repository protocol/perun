### Added
- Operating layer: `run_ledger.sh`, a report-only teardown list for what earlier runs recorded creating. `run_ledger.sh record-worktree PATH` and `record-pid PID` append to the current run's own ledger file (run id from `PERUN_RUN_ID` or `CLAUDE_SESSION_ID`; recording without one is refused; directory `PERUN_LEDGER_DIR`, default `~/.local/state/perun/runs`). A bare `run_ledger.sh` reads every ledger except the current run's and prints the exact owner-run `git worktree remove` and `kill` lines for what is finished: a worktree must pass `clean_finished.sh`'s own checks (PR merged or closed, or handed back; no unpushed commits; not held by a process) and have no uncommitted or untracked files, since a fresh worktree whose HEAD is in `origin/main` is not finished; a pid must be alive and match its recorded command, cwd and start age (`reap_own.sh`'s helpers); a still-running server recorded by a concurrent run is listed with its run id, so check it before acting. It removes, kills and writes nothing; unrecorded paths and pids are never listed. `clean_finished.sh` gains `REPORT=1` (read-only) and `ONLY=<file>` (consider only those worktrees; it exits 2 without `REPORT=1`, and the janitor always sets it); `reap_own.sh` can be sourced for its helpers with `REAP_OWN_SOURCE_ONLY=1`. `session_brief.py` adds the leftover count to its hygiene line (fixture: 3 before, 0 after the owner runs the printed lines). Tests: `scripts/test-run-ledger.sh` (run in CI).
