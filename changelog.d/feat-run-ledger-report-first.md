### Added
- Operating layer: `run_ledger.sh`, a report-first teardown for what a run itself created. `run_ledger.sh record-worktree PATH` and `record-pid PID` write a per-machine ledger (`PERUN_LEDGER`, default `~/.local/state/perun/run-ledger.tsv`); a bare `run_ledger.sh` lists the recorded worktrees that are finished (HEAD in `origin/main`, or the PR is merged or closed, no unpushed commits, clean tree, nothing holding it) and the recorded dev servers still alive (a reused pid never matches: start time, command and cwd are compared), prints the exact owner-run `git worktree remove` and `kill` lines, and changes nothing. `--remove` acts only on recorded rows, never uses `--force`, and refuses empty, relative, main-checkout and unrecorded paths and pids. `session_brief.py` adds the leftover count to its hygiene line, so leftovers show at session start (fixture: 3 before, 1 after `--remove`, the one left being a dirty worktree). Complements `clean_finished.sh` and `reap_own.sh`, which sweep by root and cwd. Tests: `scripts/test-run-ledger.sh` (run in CI).
