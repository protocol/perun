### Fixed
- `scripts/bench_check.py` rule e: each `<sha256>  <path>` line in a bench's `SHA256-frozen.txt` must name an existing file that still hashes to it. A driver edited after the freeze now fails the gate, and so does a missing listed file or a malformed line. Paths resolve from the repo root, then the bench dir; a `../` path resolves from the bench dir only. `--changed` (the CI mode) runs every check on new bench dirs and, for a dir that already landed, fails when the diff edits its `SHA256-frozen.txt` or a listed file inside the dir. Notes, ledger appends and results can still be added. Committed benches that list changed or missing files still fail a direct `python3 scripts/bench_check.py <dir>` run.
