### Fixed
- `pre-push-verify.sh` fast gates now match CI's order on an unlanded tree: `regen-unlanded.sh` runs on a throwaway detached worktree of the pushed commit (the user's tree is never touched), then `size-ratchet` runs there, so growth of a regenerated `.claude/skills/INDEX.md` or any skill file asks for its `size-budget-raise:` marker locally instead of only in CI. When `scripts/bench_check.py` exists it also runs `bench_check.py --changed <base>`, the check `scripts/ci-tests.d/bench-check.sh` runs in CI. The throwaway worktree and its mktemp dir are removed on EXIT, INT and TERM and when `git worktree add` fails (previously a failed add leaked the mktemp dir and a killed hook leaked the worktree). Tests: `scripts/test-prepush-ci-parity.sh` (planted unlanded growth, the marker that clears it, user tree untouched, worktree removed, planted bench dir without a ledger, worktree-add failure and TERM mid-run leave no leftovers); registered via `scripts/ci-tests.d/prepush-ci-parity.sh`.
