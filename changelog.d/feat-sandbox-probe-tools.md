### Added
- `sandbox_probe.py` now probes gh, a headless Chromium launch, a Postgres client connect and tsx at runtime (nine checks). A tool that is absent, or a failure that is not a sandbox block (not logged in, no server listening), prints `SKIP` and never fails; nothing is installed. Each real failure names the `sandbox_preflight.py` rule (`gh`, `browser`, `db`, `tsx`) and the `sandbox.excludedCommands` entry that clears it, and the probe still exits 1 on any failure. `perun_doctor.py` shows a skipped probe as INFO. Tests: `scripts/test_perun_doctor.py` (run in CI). The `autonomy-advisor` roadmap item is marked shipped.
