### Added
- `scripts/run-ci-tests.sh --affected [BASE]` runs the privacy gate and the trigger lint, then only the `scripts/ci-tests.d` tests a changed file can reach. Changed files are BASE (the argument, else `RUN_CI_BASE`, else the pre-push hook's `BASE_SHA`, else merge-base with `origin/main`) versus the working tree plus untracked files, read NUL-delimited with unquoted names (renames count as a delete plus an add; a changed path that is not a file, symlink or deletion fails closed). With no resolvable base it prints `affected: NOT RUN (no base)` and exits 0, so it never blocks a push. A test is picked when its own text, or a `scripts/test-*.sh` / `test_*.py` it invokes (one level), names a changed file as a whole name (`SKILL.md`, `ci.yml`, `README.md`, `INDEX.md` and `CHANGELOG.md` need the repo-relative path). A changed `.sh`/`.py` no test names gets one reverse-dependency hop (scripts that source or import it, then the tests naming those); if still none it prints `UNCOVERED: <file> (no test names it; CI only)`. `scripts/test-ci-gates.sh` is left to CI (it runs sharded there; `test-ci-gates: left to CI`) unless it or `scripts/ci-gates.sh` changed. Privacy scans only the changed files, or the whole tree when a `.banlist*.txt`, `scripts/ci-gates.sh` or `scripts/secret_scan.py` changed (the tree holds ~90k fixture files and CI scans all of it). It prints `affected: N of M tests (selected by: file→test)`, runs nothing when no file changed, exits non-zero on any failure, and never records the last-known-good pointer (a partial run proves nothing about HEAD). The repo `.githooks/pre-push` now defaults `DCR_PREPUSH_CMD` to this command (the env override is kept), so a sibling test broken by a change is caught before CI.
