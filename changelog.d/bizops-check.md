### Added
- Business-ops: new `.claude/skills/business-ops/scripts/bizops_check.py`, a stdlib-only runnable check for the arithmetic the skill already states: runway (cash / net burn), LTV:CAC (LTV = price x margin / churn), payback (CAC / (price x margin)) and margin. Input is one flat JSON object bound by key name; every limit (`min_runway_months`, `min_ltv_cac`, `max_payback_months`, `min_margin`) comes from the input, none is built in. A check with no stated limit prints SKIP, all-SKIP prints INCONCLUSIVE and exits 3, any FAIL exits 1, bad input prints `ERROR <reason>` and exits 2. Each output line quotes the verbatim `SKILL.md` sentence it mechanizes. Arithmetic is exact (`Fraction`), so a limit met exactly passes. Routed from `SKILL.md` with one run-this-when line. Tests: `scripts/test_bizops_check.py` (registered in `scripts/ci-tests.d/bizops-check.sh`). `docs/capability-matrix.md` no longer says business-ops has no scripts.
