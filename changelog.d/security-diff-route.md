- deep-code-review: a security review of a small diff now reads only `references/appsec-verify.md`, starting at a new section 0 (a one-paragraph sink sweep), instead of the full map and the 28 KB AppSec playbook. Findings cite the new-file line (hunk `+start` plus offset), never a line number inside the patch text, and each finding is cited at the line a fix would change. With the harness fixes below, on 10 blind held-out diffs Perun ties the rival (8/8 recall each, Wilson 95% interval 0.68 to 1.00, precision 0.80 each, 0/2 decoys) at 1.39x the rival's cost, down from about 4x in the first run (`docs/bench/security-seeded-1023/README.md`). The bench cannot separate the skill's share of the gain from the harness's.
- `scripts/security_bench_score.py` reports recall with a Wilson 95% score interval and `n` instead of a percentile bootstrap, which collapsed to [1, 1] at full recall.
