### Added
- `scripts/perf_compare.sh [--runs N] [--base REF] [--json FILE] -- CMD`: a hyperfine A/B of CMD in a detached worktree of the base (default: the merge-base with `origin/main`) against the current tree. It prints one verdict line (means, sd, ratio; `within noise (ranges overlap)` when the mean plus or minus sd ranges overlap) and keeps the raw export in `<git-common-dir>/perf-compare-last.json`. A missing hyperfine fails visibly (`NOT CHECKED: hyperfine`, exit 1), and the temporary worktree is removed on exit and on signals. `heavy_gate.py` now holds it like the other heavy entrypoints (`scripts/test_heavy_gate_perf.py`); `scripts/test-perf-compare.sh` covers refusals, the verdict math, cleanup and one real hyperfine run (skipped visibly when hyperfine is absent).
- `scripts/app_pentest.sh --load [--vus N] [--secs N] URL`: a k6 smoke run (default 5 VUs for 15 s, hard caps 20 VUs and 60 s, refused rather than clamped) behind the same target rules as the scanners, alone (not with `--active` or `--openapi`). The JSON carries `load` with p50, p95 and error rate; every request failing is status `error`, and a missing k6 is `skipped` with `NOT CHECKED: k6`. `scripts/test-app-pentest-load.sh` uses a fake k6 plus real k6 runs against a local `python3 -m http.server` on 127.0.0.1 (skipped visibly when k6 is absent). All three tests are wired in `scripts/ci-tests.d/perf-tools.sh`.
- `references/tool-hub.md` Perf tools rows (hyperfine and k6, flags verified against `--help` on 2026-10-30), a Load smoke section in `references/app-pentest.md`, and one routed line in `references/performance-latency-depth.md`.
