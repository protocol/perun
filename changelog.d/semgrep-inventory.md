### Added
- Bundled semgrep rules for exposed debug and management surfaces (OWASP API9:2023 improper inventory management) in `templates/semgrep-taint/inventory.yml`: `perun.js.swagger-ui-ungated` (NestJS `SwaggerModule.setup`, swagger-ui-express), `perun.js.graphql-introspection-playground` (`introspection`, `playground`, `graphiql` set to a literal `true`), `perun.js.status-monitor-ungated` (express-status-monitor), `perun.py.debug-toolbar-urls-ungated` (Django debug_toolbar URLs), `perun.py.fastapi-docs-ungated` (FastAPI created with docs and OpenAPI on, the default; skipped when `openapi_url=None`, both docs URLs are None, or a docs URL is set by a conditional), `perun.py.flasgger-swagger-ungated` (flasgger `Swagger(app)`), `perun.yaml.actuator-expose-all` and `perun.generic.actuator-expose-all` (Spring `management.endpoints.web.exposure.include=*` in YAML and properties). JS and Python rules skip a surface inside an `if` that reads `process.env` or DEBUG; config rules skip `*-dev`, `*-local` and `*-test` profile files. Django/Flask `DEBUG = True` was already covered by `perun.py.debug-enabled` and is not repeated. Tested by scripts/test_semgrep_inventory.py with seeded bad fixtures and env-gated clean twins.
