### Changed
- The repository moved to https://github.com/protocol/perun (a transfer: history, issues and PRs came with it, and the old URL redirects); every in-repo URL, the install fallback remote and the contribution self-repo now point there. `perun_auto_update.py` treats the old home (`remigiusz-antczak/deep-code-review`) as a legacy alias: an install whose marker or cache-clone remote is the old URL is fetched from the new one, and the update re-records the new remote. Any other remote is still not accepted as canonical. Tests: `scripts/test_auto_update_move.py`.
- Perun is now described as a suite (deep code review, token and cost tools, gated agentic delivery, an idea critic, and product, growth, positioning, business-ops and output-safety specialists) in the README, the plugin manifests and the install docs.
- **Plugin renamed `deep-code-review` to `perun`** (Claude, Codex and Gemini manifests and the marketplace entries; commands are now `/perun:review`, `/perun:deliver`, `/perun:cost-retro`). Plugin users must run `/plugin uninstall deep-code-review@perun`, then `/plugin install perun@perun`; old `enabledPlugins` entries do not update on their own. `install.sh` users are unaffected. The skill keeps its name, `deep-code-review`.
