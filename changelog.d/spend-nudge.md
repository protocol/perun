### Added
- Agentic-CEO / Agentic-Delivery: `token_report.py --nudge` prints ONE line, or nothing: the top `--advise` finding of a session with its at-stake USD and the exact `--fix-plan` (or `--advise`) command to run, so the advice reaches the user without `/cost-retro`. Silent when no rule fires or the lever's settings key is already set. After a `--apply` backup (`<settings>.bak` plus the empty `<settings>.bak.perun` marker only `--apply` writes, so a `.bak` from another tool is ignored; within 14 days) it appends a did-it-work receipt, `since applying <keys>: input-eq/turn -N% (n turns before, m after)`, comparing input-equivalent per deduped main turn either side of the backup's mtime, over every project transcript within 14 days before it (so an `--apply` in an earlier session still reports; each file under the 128 MB cap and all together under 256 MB read within 30 s, else the receipt is dropped and the advise line stays); below 20 main turns on either side it prints `unknown`, never a guess. The `session_brief.py` SessionStart hook shows it from the newest prior transcript of the project: it reads a cache keyed by the transcript, the settings mtimes and sizes, and the UTC date, and a miss starts a detached `--nudge --nudge-cache` refresh (transcripts over 128 MB are skipped; one refresh per 90 s behind a `<cache>.lock`; a 60 s watchdog caches the line so far (an empty one if unfinished) and exits, and a failure caches an empty line, so a bad transcript is not retried until it changes), so the hook never parses a transcript and adds only an import of `token_report.py` and a few stats (hook median 456 ms before and 457 ms after, nine runs, on the project whose newest transcript is 417 MB). A cached line is shown only while the settings are unchanged and the cache is under 14 days old, so an applied lever stops being advertised at once. The line sits after the priority line, so it is the first cut when the three-line cap bites. Lane evidence names file stems, never the free-text lane description, and the unused-MCP evidence gives a count, not server names. Fail-silent, no network; reads usage, timestamps, model ids, tool names and settings keys only. Policy key `spend_nudge=on|off` (default `on`; `install.sh --policy spend_nudge=off` or `perun_policy.py set spend_nudge off`) mutes it, like `statusline`. Tests: `scripts/test_spend_nudge.py` (registered in `scripts/ci-tests.d/spend-nudge.sh`).
