### Changed
- The real-hub CI job now also runs real tflint 0.66.0, kics 2.1.20, cppcheck 2.13.0-2ubuntu3 and DevSkim CLI 1.0.100 through `review_checks.sh`, each on a fictional canary file; the job fails unless the tool ran and reported its expected rule on that file with no not-run or NOT CHECKED line. Pins: tflint and kics by sha256 from each release `checksums.txt` (tflint uses its bundled terraform ruleset, no `--init`; the kics release tarball ships no queries, so the queries come from the release commit fetched by its full sha and verified); cppcheck as an exact version from the signed Ubuntu noble archive (the job now runs on `ubuntu-24.04` instead of `ubuntu-latest` so that version stays installable); DevSkim by the nupkg sha512 from the nuget.org catalog `packageHash`, installed from the downloaded file.
- Not added: syft, an inventory the hub never counts as ran, so a canary could not assert a run.
