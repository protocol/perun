### Added
- `.claude/skills/agentic-delivery/scripts/reclaim_disk.sh` lists (dry run by default) linked worktrees that are unlocked, have no modified, untracked or ignored files, have a HEAD reachable from origin/main or another branch, and whose last reflog move is older than `RECLAIM_MIN_AGE_HOURS` (default 24), plus local branches merged into that base. `--apply` runs `git worktree remove` (never `--force`) and `git branch -D --` on the listed items; one that git refuses is reported as a skip. Protected branch names, the main checkout, the current worktree, hidden index changes (a skip-worktree entry whose file is absent, as in a sparse checkout, hides nothing) and unfinished rebases or merges are skipped with a reason. Inherited repo-local `GIT_*` variables (`GIT_DIR`, `GIT_INDEX_FILE`, ...) are unset first, so a hook's `GIT_DIR` cannot make an unpushed lane look reachable. `perun_doctor.py` gains a `disk free` row: WARN under 50 GiB, FAIL under 10 GiB (`PERUN_DISK_WARN_GB`, `PERUN_DISK_FAIL_GB`), with a hint naming the script; under `DCR_NO_PROBE=1` (tests, offline) it is INFO and never moves the exit code.
