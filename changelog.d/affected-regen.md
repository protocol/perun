### Fixed
- `scripts/run-ci-tests.sh --affected` (the pre-push default) now runs `scripts/regen-unlanded.sh origin/main` before the suites, the same ref CI rebuilds against before any gate, so a PR that adds a script no longer fails `low-context-index.sh` locally on a stale committed INDEX. After the suites, on any early exit, and on a TERM or INT (deferred until the rebuild ends, so the rebuild cannot write after the restore), it restores exactly the files the rebuild changed to their pre-run bytes: an already-dirty file keeps its edit, a file the rebuild created is removed, and a file edited after the rebuild is kept with a note. Selection, the privacy scan and the receipt tree hash use the tree as it was before the rebuild, and `--list-affected` stays dry. Test: five new cases in `scripts/test-run-ci-tests-affected.sh`, including a TERM sent during the rebuild.
