### Added
- Bundled semgrep rules (`templates/semgrep-taint/js.yml`, `py.yml`, run by `review_checks.sh` when the repo has no semgrep rules of its own): `perun.{js,py}.hardcoded-credential-compare` (WARNING) flags a variable, property, subscript or `.get("...")` named like pass, password, secret, token or API key that is compared with `==`, `===`, `!=` or `!==` to a non-empty string literal, and `perun.{js,py}.hardcoded-basic-auth` (ERROR) flags a base64-decoded value (`Buffer.from(..., "base64")`, `atob`, `base64.b64decode`) compared to a literal, including after `.split(":")` or destructuring. Also flagged: `.toLowerCase()`/`.trim()`/`.strip()`/`.lower()`-wrapped names and `compare_digest(x, "literal")`. Not flagged: empty or single-character literals, scheme and sentinel literals (bearer, basic, none, null, undefined, true, false), a bare `pwd`/`PWD` name, env reads (`process.env.X`, `os.environ`, `os.getenv`), JWT header fields (`alg`, `typ`, `kid`) in the decoded-Basic rule, and test, fixture, mock and e2e paths. Template literals are not matched.
