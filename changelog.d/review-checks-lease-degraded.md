### Fixed
- `review_checks.sh`: when the heavy lease is still full after `REVIEW_LEASE_WAIT`, the heavy scanners (gitleaks, osv-scanner, semgrep, trivy, grype, checkov, gosec) now run degraded instead of being skipped, which left a security coverage hole on a busy host. They run under `nice -n 19` without taking the lease, with `--jobs 1` for semgrep and `--parallel 1` for trivy (the other tools have no single-worker flag and run as-is). The "analyzers ran" summary names them, for example `semgrep (degraded: lease full, nice 19, 1 worker)`. `REVIEW_LEASE_FULL=skip` restores the old skip. `supply_chain_check.sh` does not use the lease and is unchanged. New test `scripts/test-review-checks-lease-degraded.sh`.
- `review_checks.sh` degraded mode hardening: the perl timebox used on stock macOS (no `timeout`) now exits 127 when the scanner cannot be exec'd instead of exiting 0 with empty output, which read as a clean scan for every caller (such a tool is now reported not run). Degraded mode probes `nice -n 19 true` once and runs without nice, and without the `nice 19` label, when nice is missing or warns (sandbox `setpriority` EPERM). A degraded semgrep `--jobs 1` or trivy `--parallel 1` that exits non-zero is retried once without the flag; a good retry drops the `1 worker` label. The test now runs on a restricted PATH of stubs plus the system binaries it needs.
