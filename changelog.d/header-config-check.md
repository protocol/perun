### Added
- `.claude/skills/deep-code-review/scripts/header_config.py`, run by `review_checks.sh --full` as tool `header-config` and skipped when no supported web app is found: it reports each of Content-Security-Policy, X-Content-Type-Options, Referrer-Policy and X-Frame-Options that none of the files it reads names (JS/TS, `vercel.json`, `netlify.toml`, `_headers`, nginx `.conf`), as a `header-not-found` row. A header middleware import (helmet, `@fastify/helmet`, `koa-helmet`) suppresses every row, and a CSP `frame-ancestors` suppresses the X-Frame-Options row. A row is a lead to confirm with `dynamic_probe.py` on a running instance, not a finding, because a host, CDN or proxy may set the header.
