### Added
- semgrep-taint: new `llm-supply.yml` (OWASP LLM03/LLM04) flags Python hub downloads by id without `revision=` (`from_pretrained`, `hf_hub_download`, `snapshot_download`), `trust_remote_code=True`, `torch.load` with `weights_only=False` (ERROR) or with no `weights_only=` argument (WARNING as `perun.py.llm-torch-load-default`: torch 2.6 and later default it to True, older torch unpickles), and `pickle.load` / `joblib.load`. New `llm-output.yml` (OWASP LLM05) adds taint rules from an OpenAI, Anthropic, Gemini or Vercel AI SDK `generateText` completion result to eval/exec/Function, innerHTML/dangerouslySetInnerHTML, subprocess/shell and raw SQL sinks, for Python and JS/TS. Every rule carries `cwe` and `owasp-llm` metadata. Test: scripts/test_semgrep_llm_rules.py.
