### Added
- semgrep-taint: new `llm-supply.yml` (OWASP LLM03/LLM04) flags Python hub downloads by id without `revision=` (`from_pretrained`, `hf_hub_download`, `snapshot_download`), `trust_remote_code=True`, `torch.load` without `weights_only=True`, and `pickle.load` / `joblib.load`. New `llm-output.yml` (OWASP LLM05) adds taint rules from an OpenAI, Anthropic, Gemini or Vercel AI SDK `generateText` completion result to eval/exec/Function, innerHTML/dangerouslySetInnerHTML, subprocess/shell and raw SQL sinks, for Python and JS/TS. Every rule carries `cwe` and `owasp-llm` metadata. Test: scripts/test_semgrep_llm_rules.py.
