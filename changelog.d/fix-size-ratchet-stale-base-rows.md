### Fixed
- The size ratchet (`ci-gates.sh size-ratchet`) now measures a raise from the larger of the file's real size at the base ref and its `size-budgets.tsv` row there. Lanes no longer commit rows, so after any landed PR grew a budgeted file the base rows were stale and every later PR failed with a raise it did not make. On a landed tree the row equals the size (or is a hand-kept budget above it), so nothing changes there. A `size-budget-raise:` marker names that larger base value as its old value. `scripts/size_ratchet_stale_base_test.sh` (4 cases, run through `scripts/ci-tests.d/`) covers an untouched file with a stale row, real growth, and a marker built on the stale row.
