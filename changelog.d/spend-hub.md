### Added
- agentic-ceo: `scripts/spend_hub.py` answers "where did the spend go" in one command: spend per day, project, model and session over `~/.claude/projects`, then the top savings levers, each with its measured share of input-equivalent tokens and the setting or behaviour to change. Spend comes from ccusage (MIT, `ccusage claude daily --json --offline`, documented output shape only) when it is on PATH and the default log directory is read, with a parity line against `token_report.py`; otherwise, or when ccusage fails or prints another shape, from `token_report.py`'s own reader. A model with no rate row stays UNPRICED (never $0) and a transcript that cannot be read is counted: both are printed (`unpriced: <models>`, `unreadable: N sessions`) and make the `token_report.py` total a lower bound, so the parity line is skipped. Sessions are ranked by USD, unpriced ones last and flagged. Waste is `token_report.py`'s `lever_ranking` summed over the biggest sessions by USD in the window (cache pin, auto-compact, lane tool cap, Bash output cap), printed as upper bounds that overlap and are not additive, with the subagent share; the orchestrator tier is listed apart as an exposure (not a saving, not additive). Lever state comes from the user-level settings and the environment only (a project's own settings would mute a lever for every project): a lever whose key is set is skipped, and with unreadable user settings it is shown as state unknown. Transcripts whose main and lane files together exceed `--max-mb` (default 128) are counted as not measured and the spend coverage is printed. Reads usage, timestamps, model ids and tool-result sizes only; never message text; writes nothing. Hermetic tests in `scripts/test_spend_hub.py` use the frozen synthetic token-lever fixture, generated synthetic sessions and a ccusage shim. The tools read to choose ccusage are logged in `docs/standards-index.md`.
