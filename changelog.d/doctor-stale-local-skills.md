### Added
- `perun_doctor.py`: new "stale local skills" row. WARNs when a repo-local `.claude/skills/<perun skill>/SKILL.md` has an older `version:` than the global copy (the local copy shadows the newer one, so the stale one silently wins), naming both versions and paths with the fix hint "remove or update repo-local copy"; plugin skills are namespaced and coexist with repo-local ones, so they are not compared; a missing side, unparsable version (`1.2` equals `1.2.0`), repo equal to home or a symlinked skills dir shows INFO n/a. New test `scripts/test_doctor_stale_local_skills.py`.
