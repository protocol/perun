### Added
- New `agentic-delivery/scripts/flake_ledger.py` (stdlib only): a per-test pass/fail ledger keyed by tree SHA. A test with at least one fail and one pass on the same tree is a flake; after N distinct flake trees (default 3) `quarantine` lists it with an owner-reviewed expiry date (default 14 days). A quarantined test is reported and non-blocking until its expiry, after which it blocks again until `renew`; `quarantine` never extends an entry. A test that fails consistently on a tree (two or more fails, no pass) is never quarantined, and a quarantined test that fails consistently on the checked tree is blocking again (`check`). `train_flake.sh` records its `FLAKE`/`REAL` verdicts into the ledger when `FLAKE_LEDGER_DIR` is set (best-effort, verdicts and exit codes unchanged); the landing logic in `train_land.sh` does not read the quarantine list yet. Routed from the "Fix a red gate or union" row of `agentic-delivery/SKILL.md`. Tests: `scripts/test_flake_ledger.py` (10 cases, including the `train_flake.sh` hook).
