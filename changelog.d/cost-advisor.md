### Added
- `token_report.py --advise [--project DIR]` (tests: `scripts/test_cost_advice.py`, registered in `scripts/ci-tests.d/cost-advice.sh`): a table of 10 rules, each one measured signal from the transcript usage fields, model ids, tool names and settings keys, one recommendation, and a link into `docs/token-cost-tips.md` or `model-tiering.md`. Rules: top tier on mechanical lanes, lane consults, cache writes above reads with and without model switches, many short lanes, repeated context drops, a long context with no auto-compact window, large per-turn context jumps, unused MCP servers, and `ENABLE_TOOL_SEARCH=false` with MCP servers configured. A lever the user, project or local settings or the environment already set is never recommended, and an unreadable settings file counts every setting as set. At-stake dollars are the priced spend of the flagged items under the dated default rates, `UNPRICED` when no rate exists. No message or tool-result text is read. `/perun:cost-retro` now runs `--advise`.
- `cost_statusline.py` (tests: `scripts/test-cost-statusline.sh`): a `statusLine` command that prints the session cost estimate, context fill and prompt-cache hit ratio from the stdin JSON Claude Code documents. The operating layer writes it to `.claude/settings.local.json` only when no user, project or local settings file sets `statusLine` (an invalid settings file counts as set); the install marker records it and uninstall removes only that value. Machine settings are never written.
- `docs/token-cost-tips.md`: tip 11 (compact on your schedule, `/autocompact`) and tip 12 (keep MCP tool definitions out of every turn); `docs/standards-index.md`: eleven Claude Code docs pages verified on 2026-10-19.
