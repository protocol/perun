### Added
- `agentic-delivery/scripts/heavy_gate.py` now holds whole-repo security scanners, JS dependency installs and Perun's own scan and CI entrypoints on a busy host, so audit runs and the scanner hub pass the same machine-wide admission check as test runners and builds. Held: `semgrep` (`scan`, `ci`, `--config`), `trivy` (`fs`, `repo`, `image`, `config`, `rootfs`, also behind a global flag such as `--cache-dir DIR`), `osv-scanner`, `grype`, `checkov`, `gitleaks` (`detect`, `git`, `dir`), `trufflehog` (`git`, `filesystem`, `github`), `npm`/`pnpm`/`yarn`/`bun` `ci`, `i` and `install`, also behind `npx`, `uvx`, `bunx` or `pnpm dlx`, and `review_checks.sh`, `run-ci-tests.sh` and `app_pentest.sh` (as `bash PATH`, `./PATH` or a bare path, including a quoted `"$DIR/..."` path). Still light: `--version`, `--help`, `command -v TOOL` presence checks, db-only and lockfile-only runs (`--download-db-only`, `--download-java-db-only`, `--package-lock-only`), `osv-scanner`, `grype` or `checkov` with no argument, `grype db`, `grype version`, `grype help`, `zizmor`, `actionlint`, `shellcheck`, `hadolint`, single-file `bandit` and `ruff`, and the new `--list-affected` dry form of `run-ci-tests.sh`. Regression tests are in `scripts/test_heavy_gate_scanners.py` (pattern tables plus the hook on a busy and an idle machine).
- Known ceilings, also recorded in a `ponytail:` comment beside the patterns: the tool list is fixed and a launcher outside the unwrap list (`docker run`) or `bash -x PATH` still passes light; an unquoted `$VAR/script.sh` entrypoint is not matched because the tokenizer splits at `$`; `semgrep -f`/`-c`, bare `semgrep .`, `npm add`, bare `yarn`, `npm --prefix DIR ci` and the rarer `trivy`/`trufflehog` subcommands are not held.

### Changed
- `npm install` is no longer classed as light: it is a dependency install and is held like `npm ci`. `ceo_altitude_guard.py` counts build and test commands through the same pattern set, so the wider set also counts toward its per-turn threshold.
- The auto-wired `heavy_gate.py` line in `agentic-delivery/references/full-map.md` now says tests, builds, scans and JS installs.
- The busy-host deny text now says to wait and retry or narrow the command (one test file, a `-k` filter, a smaller scan path); "run a narrower test" misled for scans and installs.
