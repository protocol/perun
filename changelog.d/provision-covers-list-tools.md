### Added
- provision_tools.sh now covers all 55 external tools that `review_checks.sh --list-tools` prints (56 rows in its table; slither and scorecard added). pipx, gem, npm, NuGet, Packagist and Hex installs carry version pins, and skillspector is pinned to a commit SHA; pins unverified (not re-fetched), see tool-hub.md. `uv` is a brew row so the skillspector line works in one owner run. A tool whose toolchain (dotnet, composer, mix) is absent is reported as `BLOCKED (needs <toolchain>)` instead of printing an install line that would fail. opengrep has no Homebrew formula and its upstream installer is an unpinned script, so the dry run prints `BLOCKED  opengrep (<reason>)` and no install line.
- The gem install line honors `DCR_USER_BIN` instead of a hardcoded `~/.local/bin`.
- The installed-tool probe in provision_tools.sh, and the PATH set up by review_checks.sh, also include `~/.dotnet/tools`, the composer global `vendor/bin` and `~/.mix/escripts` when they exist (an empty `DCR_USER_BIN` still disables all extra dirs).
- scripts/test-provision-covers-list-tools.sh fails when an external `--list-tools` name has no provision row and is not on an explicit no-install list with a reason; scripts/test-provision-toolchain-dirs.sh covers the extra tool dirs, the gem install dir and the opengrep blocker line.
- `--print` installs every brew formula, pipx package, gem and npm/other row on its own and prints `FAILED <name>` for a failure, so one bad name does not stop the rest; casks (codeql) install through a macOS-only `brew install --cask` call. The gem line falls back to plain `gem` when brew is absent, sobelow installs with `--force`, and tool-hub.md marks every pin and Homebrew name `unverified` (tflint has no core formula).
