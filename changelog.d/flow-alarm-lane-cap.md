### Added
- Opt-in per-lane stop-starting cap in `.claude/skills/agentic-delivery/scripts/flow_alarm.py`: with `PERUN_STOP_STARTING_LANES` set (for example `web=web/*,docs/*;api=`, lanes split by `;`, each `name=glob,glob`, whole-path fnmatch, first match wins, a lane written with no globs is the fallback), `PERUN_STOP_STARTING_READY` applies per lane instead of repo-wide, so a full merge train no longer denies new work for an idle one. Only where the global count already denies, and before the throughput judgement, the hook takes the new PR's lane from the files GitHub lists for it (`gh api repos/{owner}/{repo}/compare/<base>...<branch>`, run in the command's directory; the local diff reads the local `origin/<base>` and lists more than the PR when that base was not fetched) and counts the ready PRs in that lane from a second `gh pr list --limit 500` call that also returns each PR's files. The count is used only when that call's own ready total is at least the cap, so it confirms the first read. A lane with room passes with no ledger entry and no denial record. A PR whose file list is missing or cut short, whose `changedFiles` is missing or null, or whose files match no lane when there is no fallback, counts in every lane. Every failure keeps the deny: a malformed map, a command or branch not judged, a compare list that is empty or at GitHub's 300-file limit, files in no lane, a call that fails or times out, a recount that does not confirm the first read, 500 PRs back. Each of the two calls gets what is left of a 15 second budget counted from the hook's start and is skipped when under 2 seconds are left, and the command is judged once per hook call. With the variable unset, behavior and the denial record are unchanged.
- With the variable set, the denial record adds `lane` and `lane_ready` (null when unknown) and the deny message names the lane and its count. The module docstring documents the syntax, every failure that keeps the deny and the residuals (a renamed file counts by its new path only; local git calls are not budgeted, so a slow git can still run the hook past its timeout); `.claude/skills/agentic-delivery/references/flow-guards.md` carries a three-line summary.
- Tests: `python3 scripts/test_flow_alarm.py` goes from 69 to 86 tests; the test environment now also drops `PERUN_STOP_STARTING_*`, and the fake `gh` serves a canned compare list and can fail the compare call or the recount list call on its own. The new `Lanes` class covers lane room and fullness, a lane taken from the compare and not from a superset local diff, a compare that fails, is empty or lists 300 files, first-match order and the fallback, whole-path globs, unknown lanes counting everywhere (a missing `changedFiles` too), malformed maps, an unjudged branch, a recount that is empty, short or fails, 500 PRs back, red and draft PRs not counting, one judging per hook call, the per-call time budget, the base and quoted branch in the compare path, the throughput grant in a full lane, and the unchanged record when the variable is unset.
