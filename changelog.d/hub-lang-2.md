### Added
- review_checks.sh routes sobelow (Elixir Phoenix apps, local source, `--private` so no update check) and pmd (Java source, PMD 7, the bundled security ruleset) through the tool hub. Each is NOT CHECKED with an install hint when missing and not run on a crash, empty or whitespace output, wrong-shape output, or an exit that disagrees with the report. Non-JSON log lines are skipped. SpotBugs with find-sec-bugs (needs compiled classes) and semgrep Secrets (needs a platform login and license) are not routed; tool-hub.md records why. Sources fetched 2026-11-12 are logged in standards-index.md.
