### Fixed
- `scripts/ci-gates.sh size-ratchet` no longer demands a `size-budget-raise:` line for a generated skill `INDEX.md`. Lanes never commit `INDEX.md` and CI regenerates it from reference files that are ratcheted themselves, so every PR that added or grew a reference failed on the derived index. Any other file still needs the marker, the silent-row-deletion check is unchanged, and the `RATCHET FAIL` message now prints the exact `size-budget-raise: <path> <old>→<new> <reason>` line to paste into `changelog.d/<slug>.md`. Self-tests in `scripts/test-ci-gates.sh` cover both cases.
