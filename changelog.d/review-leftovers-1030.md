- `comms_lint.py` `audit-pr`: the first `---` rule or `🤖` line after the last heading hid everything to the end of the body, so detail after a closing rule (a file:line inside the last `Not fixed`) was never checked, and a rule inside the last `Changes by area` made later files read as "not named". A `---` rule or `🤖 Generated` line now starts the footer only when every line after it is footer-shaped (blank, `---`, `🤖 Generated ...`, `Generated with/by ...`, `Co-Authored-By: ...`); any other text after a rule is checked like the rest of its section. A compliant footer still passes. Test: `scripts/test_audit_pr_footer_rule.py`.

The test now runs under an empty `DCR_CACHE_ROOT`. Test: `scripts/test-review-checks-scan-summary-hermetic.sh` runs it with a warm snapshot in the inherited cache root.
