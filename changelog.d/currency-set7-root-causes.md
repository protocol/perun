### Fixed
- Currency detector, five set-7 misses: a GitHub release tagged with a bare major (`v6`) no longer hides newer point-release tags (one `git ls-remote` per repo); Dropwizard coordinates feed the end-of-life check; `gradle-wrapper.properties` is a Gradle runtime pin; the same Gradle module at two versions in a build file and a version catalog is a drift row (not when one file itself declares two versions, such as two catalog aliases); `review_checks.sh` hands `PKG-INFO` to the detector, so a vendored Python package (no package.json-style manifest) gets its vendored row. The sixth set-7 miss (Go `github.com/mattn/go-sqlite3`) was a truth error, not a detector miss: the Go proxy's `@latest` is v1.14.x, while the set-7 truth recorded v2.0.3+incompatible. The detector takes a Go module's latest from the proxy's `@latest` (the authority, whether or not it is `+incompatible`), and regression tests pin both cases.
