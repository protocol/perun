### Fixed
- `scripts/ci-gates.sh privacy` now scans in chunks of 1,000 files instead of passing every path to one `grep`. On a large tree the single argv overflowed ARG_MAX: macOS failed closed with exit 126 at about 15,500 files, and bench lanes had started packing raw outputs into JSON lines to stay under the limit, which hides line-anchored text from the line-based banlist patterns. A match in any chunk still blocks, and any grep error still fails closed. Two regression tests in `scripts/test-ci-gates.sh` scan a 30,000-file tree: one with a planted hit in the last file (must block and name it) and one clean (must pass).
