### Added
- Bench: `scripts/review_cost_per_recall.py` computes review cost per real bug caught and false alarms per case for Perun against rival arms from committed bench artifacts only (no model call, no spend). The 22-case patch-only set is recomputed from raw outputs through `score_review.py`-based crediting and `rival_eval.boot` CIs; the other sets are transcribed from cited files and print `unmeasured` where a source does not publish a field. Results and five flagged number disagreements (for example a README $0.20 against the bench file's $0.136) are in `docs/bench/review-cost-per-recall/README.md`. Tests: `scripts/test_review_cost_per_recall.py` (run in CI).
