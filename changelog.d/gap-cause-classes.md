### Changed
- `audit_sweep.py`: every `GAP` and `ENVGAP` row now names its cause. The file column is the first sorted file among that tool's rows of the kind, and the rule column is `<n> not-checked: <class> <k>, ...` with every class present, sorted. Classes come from the closed `CAUSES` list built from the not-checked messages of `review_checks.sh` and the Python scanners; unmatched text is `other`. Only class labels are printed, never message text, so the no-finding-text contract holds.
- `audit_sweep.py`: the `invisible-chars` partial-read row and the `committed-data` one-file container and partial-read rows are `ENVGAP` rows (full match, file required, a per-file size limit a rescan cannot close). The invisible-chars output cap, `unreadable` rows, collapsed containers, timeouts, crashes and `exit N` rows stay blocking `GAP` rows.
- `invisible_chars.py`: skips a symlink or a non-regular path (a submodule folder, a FIFO, a dangling link) before the open, as `committed_personal_data.py` does, and a regular file that cannot be read now gives one `unreadable: <reason>` not-checked row instead of a silent pass.
