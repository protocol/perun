### Added
- deep-code-review `supply_chain_check.sh`: each osv row for an npm package gets a reach tag. `imported` (a JS/TS/Vue/Svelte/Astro/MDX source file outside node_modules and .git, and outside a root-level .venv, venv or vendor, imports or requires it), else `dev-only` (npm `dev: true` on every occurrence of that name@version, or, when the lockfile does not list it, an osv dev/build/test group), else `transitive`. Rows that are not `imported` print `(reach: <tag>)` and stay in the severity counts. Only `dev-only` rows skip the `--fail-on` gate (unless `SUPPLY_CHAIN_STRICT=1`) and a summary line counts them; `transitive` rows still gate because a direct dependency may reach them. Unknown reach (unreadable file, a lockfile without a `packages` map such as lockfile v1, non-npm ecosystem, PyPI without a dev group) is treated as imported. This replaces the earlier dev-only cap at moderate. The osv API fallback now includes the ecosystem so it gets the same tags. Tests: `scripts/test_supply_chain_reach.py`.
