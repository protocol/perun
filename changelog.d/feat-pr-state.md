### Added
- `agentic-delivery/scripts/pr_state.py <n>`: one command prints a PR's head sha, base, mergeable and merge state, commits behind base, labels, a check-runs summary with the failing names, the review decision and merge-train membership (when `<git-common-dir>/merge-train.json` exists), then a verdict; exit 0 green, 1 red, 2 pending, 3 could not read. It makes three `gh api` reads instead of the usual `gh pr view` / `gh pr checks` round: one batched GraphQL query for the PR-level fields, `surface_check.check_checks` for the per-name latest check-run verdict, and one REST compare for the behind count. Stdlib only; routed from the agentic-delivery `SKILL.md`, tested against a stubbed `gh` in `scripts/test_pr_state.py`.
- `ci-gates.sh fragments`: a changelog fragment's `size-budget-raise:` lines must be exactly the marker `size-ratchet` greps (`<path> <old>→<new> <reason>`, the path a row of `size-budgets.tsv`) and it may not hold a `## ` heading. A malformed marker used to fail only on the release commit. The check now runs in `land-release.sh` before it stamps, in the new `.githooks/pre-commit` on the staged blobs, in the pre-push fast gates and in CI; `scripts/test-changelog-fragments.sh` covers it.
