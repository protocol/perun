### Added
- `ci_cost_advisor.py` (deep-code-review scripts) prices a repo's GitHub Actions. It reads `.github/workflows`, the repository's visibility and its git history, and estimates runs, minutes and dollars per push/PR and per month from each workflow's triggers, matrix and jobs, at the per-minute rates and included minutes that docs.github.com publishes (fetched 2026-10-16, logged in `docs/standards-index.md`). A public repo on standard runners is reported as free and gets no plan. For a private repo it prints before and after numbers for a local-first plan (run the full gate locally before the push, keep only a cheap required check in Actions, trim the rest) and a unified diff to review and `git apply`. It never edits a workflow. Every assumption is printed (job minutes default to 5, three pushes per PR) and `--job-minutes`, `--prs` and `--pushes-per-pr` take measured numbers.
- The patch only makes edits that cannot strand a required check: per-PR `concurrency` with cancel-in-progress (push and schedule runs never share a group), `push` limited to the default branch or dropped under strict protection, and, once `--required` names the required workflows and a local pre-push gate exists, gate workflows moved to `workflow_dispatch` and a docs `paths-ignore` that would have skipped 50% or fewer of the last 30 days of PRs. A required workflow never gets a path filter or `[skip ci]`: GitHub leaves a skipped required check Pending and blocks the merge.
- Policy key `ci` (`local-first|cloud|auto`, default `auto`) in `.perun/policy.json`. `perun_policy.py ci` prints the effective mode; `auto` is local-first when `github_actions` is off, otherwise the verdict of `ci_cost_advisor.py --decide` (a public repo, or a private one inside its free minutes, stays cloud; a private one using half its included minutes goes local-first; a missing or failing advisor means cloud). On local-first, lanes run every gate locally before the push and push each PR once (lane preamble, `operating-discipline.md`, `docs/for-fleets.md`), and `pre-push-verify.sh` prints a warning when a push re-pushes a branch that already exists on the remote.
- `scripts/test_ci_cost_advisor.py` covers pricing, trigger run counts, matrices, doc-only path filters, public versus private, a patch that applies with `git apply` and loads in a real YAML parser, the policy key, the lint route and the pre-push notice; it runs in `ci.yml`. Two evals (deep-code-review, agentic-delivery).

### Changed
- `ci_cost_lint.py` shares its workflow loader (`load_workflows`) with the advisor, accepts `--advise` to run the advisor after its findings, and prints a hint pointing to it when it has findings.
- The `install.sh --with-gates` checklist and `host-enforcement.md`, `domain-k.md` and `operating-discipline.md` point to the advisor and the `ci` key.
