### Added
- `scripts/council_bench.py`: an offline harness that scores the idea-critic council (`veche.py`) on the evil-twin corpus. Each case (default: the R2 cases) goes to `veche.py` as a packet under a throwaway root, and the hidden key never reaches a seat (the seats run in a directory that holds only the proposal). It prints, per case kind, how often the council blocks (HOLD or REVISE) or holds the proposal, with bootstrap intervals, and with `--judge` the R2 judge's recall and false-kill on the council deliverable. One `--records` directory holds a configuration's records and replays offline with identical numbers. A live run needs `--cap-calls`, checked before every council and judge call. No live run is committed, so the council and evil-twin rows of the scoreboard stay UNMEASURED. Test: `scripts/test_council_bench.py` (stub seats and judge, real `veche.py`).
- `council.md` points to the harness from its kill-criterion section.
