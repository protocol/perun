### Added
- Operating layer: `handback_cap.py` (the SubagentStop hook) now also checks for background test or build work. When a lane hands back from a linked worktree while a runner (`pytest`, `jest`, `vitest`, `playwright`, `make`, `npm test`, `cargo test`, `go build`, a `*test*.py` script, and similar) still has its cwd inside that worktree, it names the pid and command: `warn` (default) sends the owner a `systemMessage`, `block` exits 2 so the lane waits, released after the same 30-minute bound as a live push. Set it with the new policy key `background_guard` (`off|warn|block`) or env `PERUN_BACKGROUND_GUARD`. The scan reuses `lane_liveness.cwd_pids`, excludes the hook's own pid, ancestors and descendants, ignores dev servers and shared checkouts, and fails open (`COULD_NOT_CHECK`). No new hook script, so settings template, doctor and install list are unchanged. Tests: `scripts/test_background_work_guard.py` (run in CI).
