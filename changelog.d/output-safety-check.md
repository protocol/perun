### Added
- Product-output-safety: new `.claude/skills/product-output-safety/scripts/output_safety_check.py`, a stdlib-only deterministic checker for a product's LLM-output handling. Input is one JSON object bound by key name; it enforces only rules quoted verbatim from the skill (non-empty harm inventory with affected, worst case and owner; re-review on feature, model and data; human gate on high-stakes actions; no stated rate that was not measured; one complete test row per harm with an owner-set threshold and stop condition; injection, leakage and excess-agency sweeps; no certification words; no bare confidence percentage; defined tiers and an override; a complete model and data card; disclosure recommended; legal questions routed to counsel; the three regimes named with no date or version). Each result line cites its rule. Every limit comes from the input, none is built in: an absent key prints SKIP, all-SKIP prints INCONCLUSIVE and exits 3, any FAIL exits 1, bad input prints ERROR and exits 2. Tests: `scripts/test_output_safety_check.py`.
