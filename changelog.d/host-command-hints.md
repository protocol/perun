### Added
- `context_nudge.py` names the running agent host's own session commands. Past the context threshold (250k tokens by default, again per 50k of growth) a known host gets a second line with its commands for compaction, a new chat, usage or cost, resume and model/effort switching: Claude Code `/compact` `/autocompact` `/clear` `/context` `/usage` (alias `/cost`) `/resume` `/model` `/effort`; Codex CLI `/compact` `/clear` `/new` `/status` `/usage` `/resume` `/model`; Gemini CLI `/compress` `/clear` `/stats` `/resume` `/model`; Copilot CLI `/compact` `/clear` `/context` `/usage` `/resume` `/model`; Cursor CLI `/summarize` `/clear` `/resume` `/model`; OpenCode `/compact` `/new` `/sessions` `/models`, `opencode stats` and `ctrl+t`; Qwen Code `/compress` `/clear` `/context` `/stats` `/resume` `/model` `/effort`. Each command was checked against the vendor's docs on 2026-10-16 (`docs/standards-index.md`); a control those docs do not show is not listed (no separate effort command for Codex CLI, whose `/model` covers effort, nor for Gemini CLI or Cursor CLI; no usage view for Cursor CLI).
- The host is read from env, never guessed. `PERUN_HOST` (`claude-code`, `codex`, `gemini`, `copilot`, `cursor`, `opencode`, `qwen`) wins; otherwise exactly one host's documented marker must be set (`CLAUDECODE`, `GEMINI_CLI` or `GEMINI_SESSION_ID`, `CURSOR_VERSION`, `QWEN_PROJECT_DIR`). Codex CLI, Copilot CLI and OpenCode document no such variable, so set `PERUN_HOST` in their hook config. No marker, or the markers of two hosts, is an unknown host and gets the handoff line only.
- A prompt that opens with a mechanical step (rebase, cleanup, apply a patch, a changelog fragment, a done-sweep) or names a hard one (security review, threat model, P0, race condition, data integrity, design or architecture decision, harness artifact) prints one line with the model tier and effort from `model-tiering.md` "Route delivery lanes by work type and stage" (cheapest/low, mid/medium, top/high then switch back) plus the host's model switch command, only when that work kind changes. On Claude Code from 50k tokens up the line also says that a model switch re-reads the context uncached. `scripts/test-host-command-hints.sh` pins each host's commands, the two-line cap, and that the script's tier table equals the doc's.

### Changed
- `context_nudge.py` prints at most two lines, and its handoff line no longer says auto-compact re-injects the handoff on hosts other than Claude Code. Known limits: the context size is read from Claude Code transcripts only, Gemini CLI hooks must print JSON only, Copilot CLI drops `userPromptSubmitted` hook output and Cursor's `beforeSubmitPrompt` accepts only `continue` and `user_message`, so on those hosts the text must be forwarded. `references/operating-discipline.md` describes the new output.
