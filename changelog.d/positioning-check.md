### Added
- Positioning: new `.claude/skills/positioning/scripts/positioning_check.py`, a stdlib-only runnable check of a drafted positioning statement or message house, read as JSON from a file or stdin and bound by key name. It enforces only rules quoted verbatim from `SKILL.md` or `references/full-map.md`: a statement that starts with Hypothesis, generic segment ("teams") and alternative ("the competition"), `[ASSUMED]` tags and no invented number or quote on unsupplied statement elements, differentiator and pillar proof or `UNVERIFIED — needs proof`, exactly one core message, no market fact the user did not supply, an explicit `name_cleared_by_professional` boolean (false fails; any non-blank `name_clearance` text fails unless it is true, with no wording match), no brand system or messaging bible pre-PMF, and no buyer reaction without a source. Every output line cites the rule text it enforces. It holds no limits of its own: a check whose input keys are absent prints SKIP, all-SKIP prints INCONCLUSIVE and exits 3, any FAIL exits 1, bad input prints `ERROR <reason>` and exits 2. Routed from `SKILL.md` with one run-this-when line. Tests: `scripts/test_positioning_check.py` (registered in `scripts/ci-tests.d/positioning-check.sh`), which also fails if a cited rule text drifts from the skill. `docs/capability-matrix.md` no longer says positioning has no scripts.
