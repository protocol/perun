- review_checks.sh `--fuzz` (or env `REVIEW_FUZZ=1`) runs each Go native fuzz target (`func FuzzXxx(*testing.F)`) for min(10, remaining-5)s, at most `REVIEW_FUZZ_MAX` (default 5) targets and `--timeout` seconds in total, in its own process group, and emits one `go-fuzz-crash` row per crasher naming its `testdata/fuzz/<Target>/<hash>` path. The crasher file is deleted after the row (only an untracked, plain `testdata/fuzz/<Target>/<hex>` path) so the audited tree is left as found. Fuzzing executes repo test code, so it is never implied by `--full` or `--full-history`. A missing go, go older than 1.20, an over-cap target and a spent time budget are named `not run` lines. atheris, cargo-fuzz and jazzer targets are `fuzz-target-inventory` rows under `--full` (detected, not run).
