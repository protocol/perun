### Added
- `scripts/test_review_load_bytes.py` (registered in `scripts/ci-tests.d/review-load-bytes.sh`) measures deep-code-review's must-load bytes per DIFF size tier offline and fails if the small-diff fast path (SKILL.md alone, at most 300 changed lines, no blast-radius flag) grows past 3000 bytes, loses its route to `references/full-map.md`, or stops being 10x smaller than the large-diff load. No skill text changed: the fast path already shipped, so the remaining cost gap is not skill-load bytes.
