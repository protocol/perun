### Fixed
- review_checks.sh: on a host with neither timeout(1) nor gtimeout (stock macOS), the perl timebox fallback now forks the tool into its own process group and sends SIGTERM to the whole group at the deadline, as timeout(1) does, so a grandchild that holds the output pipe cannot keep the run waiting. The old fallback kept a SIGALRM across exec, which Go binaries (gh, gosec, actionlint) ignore, so the history scan's `gh repo view` visibility probe could hang a run; it now gives up after 10 s and the visibility counts as unknown. The slither gate's `solc --version` probe uses the same timebox, so a working solc is no longer reported missing when timeout(1) is absent. Test: scripts/test-review-checks-hub-no-timeout.sh.
- semgrep-taint: perun.js.unsafe-api-consumption hands string-built SQL to perun.js.raw-sql-concat only for the receivers that rule matches by name (db, knex, pool, client, prisma and the rest of its list). API response data reaching `database.query(...)` or `repo.query(...)` is reported by unsafe-api-consumption again, instead of by neither rule. Test: scripts/test_g1_api10_a.py.
- secret_exposure_triage.py: with public or unknown visibility, a secret reachable from a tag or a remote-tracking branch now ranks P0 (assume compromised), since those refs are as public as the default branch. A secret only on a local side branch stays P3. Test: scripts/test_secret_exposure_triage.py.
