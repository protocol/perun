### Changed
- `route_auth_map.py` reads NestJS routes declared with ts-rest (`@Api(server.route.x)`, `@TsRest(contract.x)`, `@TsRestHandler(c.x)`): each member is one row with the same guard evidence as a plain Nest member, and METHOD and path come from the scanned `x.router({...})` contract (with `pathPrefix`). A contract entry it cannot read statically (a nested router, a non-literal path, a name defined twice, a contract not in the scanned tree) prints as `contract:<key>` instead of being guessed. The lookup is by contract name, so a same-named contract from an unscanned package binds to the scanned one. On one ts-rest monorepo the handler count went from 560 to 770.
- A new stderr line, `coverage: N file(s) with route-like decorators this scan skipped`, names the JS/TS files that have a `@Get(`-style or ts-rest decorator with no row.
