### Fixed
- `review_checks.sh`: when the `p/default` registry pack hangs until the timeout (for example behind a proxy that denies semgrep.dev) or errors, semgrep now reruns that 200-file chunk with the bundled taint rules alone instead of dropping to zero coverage, and says so: `review_checks: not run: semgrep p/default pack (timeout 60s); bundled rules only` on stderr, `semgrep(bundled-only)` under `analyzers ran`, `semgrep p/default pack (timeout 60s)` under `NOT RUN` (never `none`) and a `not-checked` row in the JSON, so a bundled-only run cannot read as a full clean. The fallback carries over to the later chunks only while no registry run has succeeded; once one has, each later chunk tries the pack again. If the bundled rerun fails too, semgrep is `NOT RUN` as before. Test: `scripts/test-semgrep-registry-timeout.sh` (stub semgrep and trivy, so it stays offline).
