### Changed
- `review_checks.sh`: CodeQL now runs only with `REVIEW_CODEQL=1`, because its license allows OSI-licensed code only and default-on would breach it in private repos. Without the env a Python or JavaScript/TypeScript change gets one not-checked row ("off by default (license: OSI-licensed code only); set REVIEW_CODEQL=1") and the binary is never run. osv-scanner exit 128 ("No package sources found") is now a skipped row "no package sources" instead of a bare "not run". Tests: `scripts/test-review-checks-codeql-optin.sh`; `test-review-checks-supply-chain.sh` sets `REVIEW_CODEQL=1` for its codeql cases.
- `review_checks.sh` kics: adds `-q DIR` (the brew `share/kics/assets/queries` dir beside the resolved binary) only when that dir exists; brew kics otherwise exits 126 "unable to find queries" when the working directory is not its install dir. Test: `scripts/test-review-checks-kics-queries.sh`.
