# Skills index

Single entry point, generated in the Perun source repo by `scripts/skill_index.py` (never hand-edit it). Paths are relative to this directory. Open only what a line points to.

## Skills

Read `<skill>/SKILL.md` when its line matches. `<skill>/INDEX.md` lists its `references/` (each with a read-when trigger); large script tables are in `INDEX-scripts.md`.

- agentic-ceo: Use at the START of any multi-step or multi-skill session, and whenever choosing a skill.
- agentic-delivery: Use when implementing a feature, migration or end-to-end change: build, add, ship, deliver, fix a ticket.
- business-ops: Use for money and compliance questions going to market.
- communication-structure: Use BEFORE sending any human-facing message (PR body, issue/PR comment, status update, reply) or producing a report…
- contribution: Use to send a fix or lesson from private work upstream.
- deep-code-review: Use when reviewing, auditing, hardening, red-teaming or quality-gating a repo, PR, branch or diff, even without the…
- growth-analytics: Use when deciding what to measure once building or shipping: North Star metric, AARRR funnel (retention first), event…
- idea-critic: Use BEFORE asking the owner anything or presenting a new plan, architecture, process, agent, skill or unsolicited "we…
- positioning: Use when shaping how a product is positioned to its market: value proposition, segment, differentiation, messaging…
- product-discovery: Use when deciding whether something is worth building, what to build first, what not to build, or whether what shipped…
- product-output-safety: Use when designing or shipping a feature whose OWN AI outputs or automated decisions reach end-users and could harm…
